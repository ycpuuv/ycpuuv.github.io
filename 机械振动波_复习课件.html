观察生活中的振动现象

二、机械振动核心知识点

1. 简谐运动定义

简谐运动是最基本、最重要的振动形式。当物体所受的回复力与位移大小成正比、方向相反时，物体做简谐运动。

动力学特征：F = -kx

运动学特征：x = A cos(ωt + φ)

2. 简谐运动的重要公式

  • 位移方程： x = A cos(ωt + φ)
  • 速度方程： v = -Aω sin(ωt + φ)
  • 加速度方程： a = -Aω² cos(ωt + φ)
  • 周期公式： T = 2π√(m/k) (弹簧振子)
  • 单摆周期： T = 2π√(L/g)
  • 角频率关系： ω = 2π/T = 2πf

记忆要点

  • 平衡位置：F回=0，a=0，v最大
  • 最大位移处：|F回|最大，|a|最大，v=0
  • 简谐运动的能量：E总=E_k+E_p不变

例题1：简谐运动的基本参数

一弹簧振子的振动方程为：x = 0.1cos(4πt + π/3) (m)，求：振幅、周期、频率、初相位。

解析：对比标准式x=Acos(ωt+φ)，可得：

  • 振幅A = 0.1 m
  • 角频率ω = 4π rad/s
  • 周期T = 2π/ω = 2π/(4π) = 0.5 s
  • 频率f = 1/T = 2 Hz
  • 初相位φ = π/3 rad

三、单摆专题

1. 单摆的构造条件

  • 细线不可伸长
  • 细线质量远小于小球质量
  • 小球体积远小于摆长
  • 最大偏角小于5°（近似为简谐运动）

2. 单摆重要公式

  • 周期公式： T = 2π√(L/g)
  • 说明：T只与摆长L和重力加速度g有关，与摆球质量、振幅无关（小角度条件下）

例题2：单摆的周期变化

在地球上测得某单摆的周期为T₀，若将其移到月球上（月球表面重力加速度约为地球的1/6），其他条件不变，则该单摆在月球上的周期为多少？

解析：根据T = 2π√(L/g)，T与√(1/g)成正比

所以T月/T地 = √(g地/g月) = √(g地/(g地/6)) = √6

因此，T月 = √6 T₀

四、机械波核心知识点

机械波传播演示

1. 机械波的形成与传播

  • 形成条件：波源 + 介质
  • 传播特点：传播振动形式和能量，介质质点不随波迁移
  • 分类：横波（质点振动方向⊥传播方向）和纵波（质点振动方向//传播方向）

2. 波的描述物理量

  • 波长λ：相邻两个振动情况相同的质点间的距离
  • 周期T：各质点振动的周期
  • 频率f：各质点振动的频率，由波源决定
  • 波速v：波在介质中的传播速度，由介质性质决定
  • 基本关系： v = λf = λ/T

关键理解

波速由介质决定（v=√(E/ρ)，其中E为弹性模量，ρ为密度）， 频率由波源决定， 波长由波速和频率共同决定。

五、波的图像分析

1. 振动图像 vs 波的图像

项目 振动图像 波的图像
坐标轴 纵轴：位移；横轴：时间 纵轴：位移；横轴：空间位置
表示对象 单一质点的振动规律 某时刻所有质点的位置
物理意义 质点位移随时间的变化 某时刻各质点的空间分布
周期性 时间上的周期性 空间上的周期性（波长）

例题3：波动图像的分析

已知一列简谐横波沿x轴正方向传播，t=0时刻的波形图如图所示，此时x=2m处的质点P恰好开始向上振动，已知波速v=2m/s。求：

  1. 这列波的波长、振幅和周期
  2. t=1.5s时x=4m处质点的振动方向

解析：从波形图读出λ=4m，A=0.1m

由v=λ/T得：T=λ/v=4/2=2s

因为波沿x轴正方向传播，x=4m处质点在t=0时刻位于波峰，位移为正值。经Δt=1.5s=3T/4，根据"同侧法"，该质点的振动方向向下。

六、常考题型及解题方法

1. 振动周期的比较

方法：利用周期公式的适用条件，注意影响因素

  • 弹簧振子：T = 2π√(m/k)，与g无关
  • 单摆：T = 2π√(L/g)，与m无关

2. 波形图与振动方向的关系

常用方法：

  • 上下坡法
  • 带动法
  • 同侧法

3. 振动与波动的关联

关键是：振动是波动的源头，波动是振动的传播

已知振动方程可推波函数，已知波函数可得某点振动方程

七、课堂练习

练习题1

一个水平放置的弹簧振子，振幅为A，周期为T，平衡位置为O点。当振子第一次到达A/2位置时开始计时，则振子第三次经过A/2位置的时间为（ ）

  1. A. T/6
  2. B. T/3
  3. C. 5T/6
  4. D. 7T/6

解答：答案是C。画出简谐运动的位移-时间图像或旋转矢量图，可以看出从A/2位置到再次到达A/2位置，对应的角度变化为2π/3或4π/3。第一次经过A/2是在t=0，第三次经过A/2是在t=5T/6。

练习题2

一列简谐横波沿直线传播，某时刻的波形如图所示，波速v=12m/s。则（ ）

  1. A. 质点a此刻向-y方向运动
  2. B. 波沿+x方向传播
  3. C. 此波的频率为2Hz
  4. D. 经过0.25s，质点b经过的路程为10cm

解答：根据波形图，如果已知波沿+x方向传播，则质点a的振动方向可用"上下坡法"确定。波长λ=6m，周期T=λ/v=6/12=0.5s，频率f=1/T=2Hz，选项C正确。质点b在一个周期内路程为4A，0.25s=T/2，路程为2A=10cm，选项D也正确。

八、高考常考点总结

高频考点清单

  • 简谐运动的动力学特征 F=-kx
  • 简谐运动的运动学方程 x=Acos(ωt+φ)
  • 单摆周期公式及其应用
  • 弹簧振子周期公式
  • 波长、频率、波速的关系 v=λf
  • 振动图像和波动图像的区别与联系
  • 波的传播方向与质点振动方向的判断
  • 波的干涉、衍射现象（扩展）
  • 多普勒效应（扩展）

易错点提醒

  • 混淆波速和质点振动速度
  • 搞不清振动周期和波动周期的关系
  • 判断波传播方向时弄反质点振动方向
  • 计算路程时未考虑振幅
  • 忽视单摆的小角度条件

九、课堂小结

今天我们系统复习了机械振动和机械波两个模块：

  1. 机械振动：以简谐运动为核心，掌握其动力学和运动学特征
  2. 机械波：理解波的形成、传播机制和描述方法
  3. 联系：振动是波动的源头，波动是振动的传播
  4. 应用：熟练运用相关公式解决实际问题

核心公式汇总

主题 公式 适用条件
简谐运动 F = -kx 回复力与位移成正比反向
简谐运动 x = Acos(ωt+φ) 任何简谐运动
弹簧振子 T = 2π√(m/k) 弹簧振子系统
