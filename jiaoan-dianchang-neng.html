电场中能的性质 · 高考综合

高三一轮复习教案　｜　2 课时（90 min）　｜　人教版必修三 第十章
这节课只讲一件事：所有"能"的题，都从一本账出发。
WAB = qUAB = EpA − EpB = −ΔEp
其余全是它的变形。学生做不出题，往往不是公式没背熟，而是"谁做功、对谁做功、能量去了哪"这三问答不上来。

一、教学目标

  1. 能默写 W、q、U、Ep、φ 五个量之间的四条换算关系，不查书。
  2. 能用两个判据（做功正负、沿场线电势降低）解决任意两点的电势高低与电势能增减。
  3. 能读懂 φ–x、Ep–x、E–x 三类图像，说出斜率和面积各代表什么。
  4. 能把"电场＋重力"化为等效重力场处理，并迁移到圆周运动。

重点 / 难点

重点：W = qU 的符号处理；图像斜率与面积的物理意义。

难点：负电荷的电势能判断（不能套结论，必须带符号算）；φ–x 图像为什么可以"回折"。

三、环节一：起点诊断（8 分钟）

三个问题，不许讨论，30 秒内写在纸上。目的不是考，是把错误先逼出来。

问 1　正电荷从 A 移到 B，电场力做正功。A、B 哪点电势高？
问 2　负电荷放在电势高的地方，它的电势能大还是小？
问 3　φ–x 图像上某点切线斜率为正，该点场强指向哪个方向？
标准答案与错误率预判

问 1：B 点电势高。
常见错误：答"B 点电势能高"——把电势能当成电势。正电荷电势能减少，但电势是降低的：电场力做正功 → 沿场方向移动 → 电势降低。

问 2：小。Ep = qφ，q 为负，φ 越大 Ep 越小。

问 3：指向 −x 方向。因为 E = −Δφ/Δx，斜率正 → 场强为负方向。

设计意图　三题错在同一处：符号，不是概念。先打符号，再建体系，后面才立得住。

四、环节二：立账本（12 分钟）

1. 一次推导，导出全部

从功的定义出发，只推一次：

WAB = F·d = qE·d = q(φA − φB) = qUAB

再由功能关系 WAB = EpA − EpB，与上式并列。

2. 一条链（板书左侧，从右往左推）

功　→　电势能　→　电势　→　电势差　→　场强

3. 四条必须默写的关系

编号关系式用在哪
①WAB = qUAB = EpA − EpB一切功与能的换算
②UAB = φA − φB由电势求电势差
③Ep = qφ判断电势能增减
④U = Ed（匀强场，d 沿场方向）场强与电势差互求

4. 账本模型（板书右侧，三行）

收入　电场力做正功 → 电势能减少

支出　克服电场力做功 → 电势能增加

结余　Ek + Ep电 + Ep重 = 常量（只有电场力和重力做功时）

一句话立住全课：电场力做正功，电势能一定减少——不管电荷正负，不管电势高低。

五、环节三：四个判断（15 分钟）

判断什么看什么注意
电势能增还是减只看 W 的正负与电荷正负无关
电势哪点高沿场线方向降低最快"最快"三个字别丢
正负电荷的差别Ep = qφ 带符号算不要背"高电势大电势能"
场强指向哪电势降低最快的方向与 E = −Δφ/Δx 一致
口诀　能做正功，能就少；场线所指，电势低。

当堂练（口答，30 秒）：把一电子从 A 移到 B，电场力做负功。问：φA 与 φB 谁高？电子在 A、B 哪点电势能大？

答案

电场力做负功 → 电势能增加 → B 点电势能大。
Ep = qφ，q < 0，EpB > EpA → φB < φA，即 A 点电势高。

六、环节四：图像三张脸（20 分钟）

图像斜率代表面积代表易错
φ–x−E无斜率正 → 场强指向 −x
Ep–x−qE（即 −F电）无负电荷时形状与 φ–x 相反
E–x无U（电势差）横轴上下面积要带符号相减

φ–x 图的三种典型形状

① 直线——匀强电场。斜率处处相同，E = |Δφ/Δx| 为常数。

② 双曲线型——点电荷。靠近电荷处斜率陡，说明场强大。

③ 闭合曲线——这是一个必须单独讲的例外：当 x 轴穿过一条曲线（如圆周），同一个 x 对应两个点，图会"回折"闭合。这时它不是函数图像，是参数曲线。

课堂追问（容易卡住全班）　φ–x 图上，同一个 x 出现两个 φ，是不是画错了？
不是。因为圆上那个 x 位置有上下两个点，两点的电势不相同。图像"回头"正是这个原因。

配套动画：圆周上各点电势与 φ–x 图像（可拖场方向 β，看椭圆如何旋转、如何在 β = 0 时退化成直线）。

七、环节五：三道综合（25 分钟）

例 1　直线运动 × 功与能

题　水平向右的匀强电场中，一质量 m = 1.0×10−3 kg、电荷量 q = +1.0×10−6 C 的小球，从 A 点由静止释放，沿与水平方向成 37° 的直线斜向下运动到 B 点，A、B 间距 L = 1.0 m。
（g = 10 m/s²，sin37° = 0.6，cos37° = 0.8）

(1) 求场强 E 的大小；(2) 求到 B 点的速度；(3) 求 UAB；(4) 求电势能的变化量。

问题链（先停，别急着讲）
① 它凭什么能沿直线运动？
② 合力由哪两个力构成？指向哪？
③ 从 A 到 B，电场力和重力各做正功还是负功？
解答

(1) 直线运动 → 合力与速度共线，即沿 AB。水平分量与竖直分量之比：

qE : mg = cos37° : sin37° = 4 : 3 qE = 4mg/3 = 1.33×10−2 N E = qE/q = 1.3×104 V/m

(2) 合力 F = mg/sin37° = 1.67×10−2 N，a = F/m = 16.7 m/s²：

v = √(2aL) = √33.3 ≈ 5.8 m/s

(3) 沿场方向的位移 d = L·cos37° = 0.8 m：

UAB = E·d = 1.07×104 V

(4) W电 = qUAB = 1.07×10−2 J > 0，所以电势能减少：

ΔEp = −W电 = −1.07×10−2 J

账本验算（讲完必做）：W电 + W重 = 1.07×10−2 + 0.60×10−2 = 1.67×10−2 J，而 ½mv² = 1.67×10−2 J，两边相等。

易错　学生常把重力做负功。位移是斜向下，重力与位移同向，做正功。

例 2　图像：等量异种点电荷连线上的 φ–x

题　x 轴上，+Q 固定于 x = −a，−Q 固定于 x = +a，取无穷远为零势点。

(1) 定性画出 x 轴上电势 φ 随 x 的变化；(2) 哪一段场强最大？(3) 把电子从 x = −3a 移到 x = −2a，电场力做正功还是负功？电势能怎么变？

问题链
① 靠近 +Q 时 φ 冲向哪里？靠近 −Q 呢？
② x = 0 处 φ 等于多少？那里的场强是不是也为零？
③ 斜率最大的地方在哪？
解答

(1) φ = kQ(1/|x+a| − 1/|x−a|)：

  • x < −a：φ > 0，随 x 增大而升高，在 x → −a 时趋于 +∞；
  • −a < x < a：φ 从 +∞ 单调降到 −∞，x = 0 处过零；
  • x > a：φ < 0，随 x 增大而升高，趋于 0。

(2) 斜率 |Δφ/Δx| = E，在 x = ±a 两侧最大——点电荷附近场强最大。

(3) 在 x = −3a 到 −2a 这段，φ 由 0.25kQ/a 升到 0.67kQ/a（升高）。
该段场强指向 −x，电子受力指向 +x，位移向右 → 电场力做正功，电势能减少。

变式：换成质子，受力指向 −x、位移向右 → 做负功，电势能增加。同一段路，正负电荷结论相反。

易错　"x = 0 处 φ = 0，所以场强也为零"——错。两电荷在 x = 0 处产生的场强同向叠加，不为零。电势为零与场强为零是两件事。

例 3　等效重力场 × 圆周运动

题　长 L = 0.4 m 的绝缘细线一端固定于 O，另一端系一质量 m = 0.2 kg、电荷量 q = +2.0×10−4 C 的小球。空间存在竖直向下的匀强电场 E = 1.0×104 V/m。把小球拉至细线水平（A 点）后由静止释放。

(1) 求等效重力加速度；(2) 求最低点 B 的速度；(3) 求 B 点细线张力。

问题链
① 电场力和重力方向相同还是相反？
② 能不能直接把两个力"合成"成一个"更重的重力"？
③ 这样替换之后，这道题变成了哪道熟悉的题？
解答

(1) 电场力与重力都竖直向下，方向一致，可以直接合并：

g′ = g + qE/m = 10 + (2.0×10−4×1.0×104)/0.2 = 10 + 10 = 20 m/s²

(2) 从水平位置到最低点，下降高度 L：

v = √(2g′L) = √(2×20×0.4) = 4.0 m/s

(3) 最低点：T − mg′ = mv²/L

T = mg′ + mv²/L = 0.2×20 + 0.2×16/0.4 = 4 + 8 = 12 N

结论：答案就是普通单摆题的 T = 3mg′，只是把 g 换成 g′。

这一问的价值　不是多算一道题，是让学生看见：复合场问题的解法，是把两个场"叠"成一个场。以后遇到"电场＋重力"的圆周运动、类平抛，都是这一招。
边界提醒　只有电场力与重力方向共线时，才这么简单地合成。若电场力水平（与重力垂直），合力方向倾斜——那叫"等效重力方向偏转"，g′ 要按矢量合成，圆周的最高点、最低点位置也会跟着转，不能再套"最低点"。

八、环节六：易错清零（8 分钟）

六条，逐条对号，学生举手承认的才讲。
  1. 把"电势能减少"说成"电势降低"——两者方向一致与否取决于电荷正负。
  2. W = qU 里的 U 用成了"到零势点的电势"，应该用两点间的电势差。
  3. 负电荷直接套"高电势大电势能"——必须回到 Ep = qφ 带符号算。
  4. φ–x 图斜率符号搞反——记住 E = −Δφ/Δx，前面有负号。
  5. E–x 图求面积忘了带符号，横轴下方的面积要算负的。
  6. 只有电场力做功时才写 Ek + Ep = 常量；有重力、摩擦、弹簧，都要加进账本。

九、板书设计

左侧（一条链）：功 → 电势能 → 电势 → 电势差 → 场强

中间（四条关系）：① W = qU = −ΔEp　② UAB = φA − φB　③ Ep = qφ　④ U = Ed

右侧（账本三行）：收入 / 支出 / 结余

下沿（一句口诀）：能做正功，能就少；场线所指，电势低。

C 层（挑战）
例 3 变式：电场改为水平向右，重求最低点位置与最大速度。（提示：等效重力方向偏转，圆周的"最低点"跟着转。）
