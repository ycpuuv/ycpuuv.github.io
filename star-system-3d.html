双星系统ξ = 1 · 各自质量都能求

两星始终在质心两侧，角速度相同。间距 L = r₁ + r₂。彼此的万有引力提供各自所需的向心力 —— 注意引力式里用的是 L，而向心力式里用的是各自的 r。

G m₁m₂ / L² = m₁ω²r₁ = m₂ω²r₂

把左边的式子分别对两颗星写开，会得到 r₁/r₂ = m₂/m₁；再用 ω = 2π/T 换掉 ω：

m₁ + m₂ = 4π²L³ / (G T²)　即　ω² = G·M总 / L³
m₁ = 4π²L²r₂ / (G T²)　　m₂ = 4π²L²r₁ / (G T²)

关键结论：方程两边除以被绕星质量 m 后，m 就被约掉了 —— 这正是「环绕法」永远只能称出中心天体质量的原因。想要两颗星各自的质量，只剩双星法这一条路。

这里 ξ = 1（见规律总结），拖 k 滑块会发现周期一动不动 —— 因为 T 只由 M总 与 L 决定。

三星等边三角形ξ = 1 · 拉格朗日解

三星各占等边三角形的一个顶点，边长 L 始终保持不变。每颗星受另外两星的引力，两力夹角 60°，合力沿角平分线指向质心（但不一定指向三角形的几何中心）。

F合 = 2 · (G m_i m_j / L²) · cos30° = √3 G m_i m_j / L²

这个解对任意三个质量都成立，只是质心不再落在几何中心 —— 质量大的一侧半径小。第 i 颗星到质心的距离：

R_i = L·√(m_j² + m_j m_k + m_k²) / (m₁+m₂+m₃)　（i, j, k 轮换）
ω² = G(m₁+m₂+m₃) / L³　　T = 2π√( L³ / (G·M总) )

注意 T 里根本没有 k！拖 k 滑块你会看到：三星的轨道半径此消彼长（k=10 时 R侧/R中 = 6.08），速度分配也变了，但公转周期纹丝不动 —— 它只由总质量和边长决定。

三星共线ξ = (4k+1)/[4(2+k)] · 欧拉解

两侧星质量均为 m、中星质量为 km，相邻间距都是 L。中星受两侧对称的引力 —— 大小相等、方向相反，合力为零，所以它停在质心不动，两侧星轨道半径都是 L（不是 L/2）。

外侧星受两个指向圆心的引力：来自中星 kGm²/L²，来自对面外侧星 Gm²/(2L)² = Gm²/(4L²)：

(k + 1/4) G m² / L² = m ω² L　⟹　ω² = (4k+1)/4 · G m / L³

换成「总质量固定」的说法（m = M总/(2+k)）：

ω² = (4k+1) / [4(2+k)] · G·M总 / L³

k = 1（等质量）时系数 = 5/12 ≈ 0.4167，正是教材标准情形。拖 k 你会看到：总质量不变，中星越重转得越快（k 从 0.1 到 10，ξ 从 0.167 涨到 0.854）—— 和等边三角形的「周期纹丝不动」正好相反。

四星正方形ξ = 0.6768 · 三力叠加

每颗星受三个引力：两个相邻星（边长 L，两力夹角 90°）和一个对角星（距离 √2 L）。

F合 = 2·(G m²/L²)cos45° + G m²/(2L²) = (√2 + ½) G m² / L²

到质心距离 R = L/√2，注意 R 和 L 的差别要单独处理：

ω² = (√2 + ½)·√2 · G m / L³ = 2.707 G m / L³

把「相邻边的 90° 夹击」和「对角线的远距离牵引」分开算再合成，是多星问题通用的叠加法。四星取等质量，M总 = 4m，故 ξ = 2.707/4 = 0.6768。

四星：等边三角形 + 圆心一星ξ = 2.049 · 转得最快

外侧三星构成边长 L 的等边三角形（外接圆半径 a = L/√3），第四颗星正放在圆心 —— 也就是质心上。

中心星：来自三个顶点的引力关于圆心完全对称，合力为零；它又正好在质心上（R = 0），所需的向心力也是零。两个条件同时满足，所以它始终静止。

外侧星：受三个引力 —— 中心星（距离 a，指向圆心）、另两个顶点（各距离 L，夹角 60°）：

F合 = G m²/a² + 2·(G m²/L²)·cos30° = (1 + 1/√3) G m² / a²

用 L 表示（a = L/√3）：

ω² = (1 + 1/√3)·3√3 · G m / L³ = 8.196 G m / L³

半径只有 L/√3 = 0.577L（比正方形的 0.707L 更靠近质心），再加上圆心那颗的额外牵引 —— 它是六种构型里转得最快的。

四星共线ξ = 0.3213 · 内宽外窄

先试最自然的想法：四星等距排成一行。逐星验证就会发现做不成 —— 外侧星算出的 ω² 是 3.06，内侧星算出的却是 −1.69（负号表示它受到的是向外的合力），根本转不起来。

真正的解不等距：位置严格满足 −1 : −0.475 : 0.475 : 1（相对值），即

相邻间距之比 = 0.788 : 1.425 : 0.788　（中间最宽，两端最窄）

以「平均相邻间距」L = 总跨度/3 作单位（此时外侧星半径 = 1.5L）：

ω² = 1.285 G m / L³　　T = 5.542 √(L³ / G m)

ω² 系数（1.285）比三星共线（1.25）还略小，加上外侧星半径大，所以它是六种构型里转得最慢的。这说明多星问题里「间距相等」往往只是特例，必须回到"对每颗星分别列合力方程"这条通法。

一句话结论

六种构型的几何系数对比 n = T ÷ √(L³/(G·M总))，纯几何量 · 越小越快

质量分配律 双星 / 三星：质量怎么分，半径就怎么分

求解思路 变轨问题的三条铁律

铁律① 同一位置，加速度一定相同a = GM / r²

加速度（连同它决定的万有引力）只由该点到地心的距离 r 决定，与卫星此刻在哪条轨道上、往哪个方向飞，全都无关。

a = G M / r²　（M 为中心天体质量）

所以在 P 点：轨道Ⅰ上的卫星与轨道Ⅱ上的卫星，加速度完全相同（因为 r 相同）。同理在 Q 点，轨道Ⅱ与轨道Ⅲ的加速度也相同。

a_P(Ⅰ) = a_P(Ⅱ) = GM/r₁²　　a_Q(Ⅱ) = a_Q(Ⅲ) = GM/r₃²

高频陷阱：题目说"在 P 点加速，所以加速度变大"——错。加速改变的是速度，加速度只认 r。

铁律② 速度比较：v近 > v圆(低) > v圆(高) > v远v_ⅡP > v_Ⅰ > v_Ⅲ > v_ⅡQ

（一）圆轨道之间（考得最多）：由 GMm/r² = mv²/r 直接得

v = √(GM/r)　　⟹　r 越大，v 越小

所以 v_Ⅰ > v_Ⅲ（近地轨道比同步轨道快）。同理 ω = √(GM/r³)、 a = GM/r² 也随 r 增大而减小，只有 T = 2π√(r³/GM) 增大 —— r 增大时"三减一增"。
检验：近地 r = 1R、同步 r ≈ 6.6R，则 v 之比应为 √6.6 ≈ 2.57 —— 7.92 ÷ 3.08 = 2.57 ✓

（二）同一位置、不同轨道（P 点或 Q 点）：由 vis-viva 方程（能量守恒的直接结果）

v² = G M ( 2/r − 1/a )

在 P 点：轨道Ⅱ的 r 与Ⅰ相同，但半长轴 a₂ > r₁，所以 v_ⅡP > v_Ⅰ（这正是"加速"的含义）。
在 Q 点：轨道Ⅱ与Ⅲ的 r 相同，但 a₃ > a₂，所以 v_Ⅲ > v_ⅡQ（第二次加速）。

v_ⅡP > v_Ⅰ > v_Ⅲ > v_ⅡQ

两条尺子不要混：比"同一位置的两个速度"用 a半长轴；比"两条圆轨道的速度"只用 r。

铁律③ 轨道越高，机械能越大E = − GMm / (2a)

每次点火加速，发动机做正功，机械能台阶式上升：

E = − G M m / (2a)　（a 为半长轴）
E_Ⅰ < E_Ⅱ < E_Ⅲ

反过来说：只要能判断能量的增减，就能判断是加速还是减速。同一位置（r 相同）时动能越大则机械能越大 —— 这就是"同一点比速度"这一招的由来。

一句话结论
衔接下一讲：掌握了"轨道高低 ↔ 速度快慢"，就能回答更刁的追问 —— 两条轨道上的卫星，什么时候追到、什么时候最远？这正是专题二 · 追及与相遇要解决的问题。

四个关键位置的速度对比 v_ⅡP > v_Ⅰ > v_Ⅲ > v_ⅡQ（同一点比速度是解题关键）

求解思路 两步走：角度关系 → 时间关系

第 1 步 · 写角度关系Δθ = (ω₁ − ω₂) t

从"两星同时经过地面同一点的正上方"（初始同相位）开始计时。t 时刻两星转过的圆心角分别是 θ₁ = ω₁t、θ₂ = ω₂t，于是夹角

Δθ = θ₁ − θ₂ = (ω₁ − ω₂) t

关键判断："相距最近/最远"指的是圆心角的关系，不能用弧长相等去凑 —— 两星在不同半径的轨道上，弧长与角度的关系根本不统一。

第 2 步 · 把"最近 / 最远"翻译成 Δθ 的取值Δθ = 2nπ 或 (2n−1)π

相距最近：两星与地心重新共线且落在同一侧 —— Δθ = 2π、4π、…

Δθ = 2nπ　⟹　t = 2nπ/(ω₁ − ω₂) = n T₁T₂ / (T₂ − T₁)

相距最远：两星与地心共线但分居两侧 —— Δθ = π、3π、…

Δθ = (2n − 1)π　⟹　t = (2n − 1) T₁T₂ / [ 2(T₂ − T₁) ]

取 n = 1，就是教材给出的两条常用结论：

相邻一次最近：t = T₁T₂/(T₂ − T₁)　　相邻一次最远：t = T₁T₂/[2(T₂ − T₁)]

为什么"最远"的时间正好是"最近"的一半相位 π 与 2π

因为 Δθ 是匀速增长的：转过 π 所花的时间，正好是转过 2π 的一半。

t_最远 = t_最近 / 2

由此可得一个易错点的正解：从同相位出发，两星一定先"最远"、后"最近"（因为 π < 2π）。 教材里 (n−1) 与 (2n−1) 这两套系数，本质上是同一个匀速追及问题的两个相位条件。

受力分析 本讲最关键的一个分岔

分岔① 卫星：万有引力 全部提供向心力GMm/r² = mv²/r

近地卫星、同步卫星都只受万有引力这一个力，而它恰好全部用来提供绕地心做圆周运动的向心力：

GMm/r² = m v²/r = m ω²r = m (4π²/T²) r = m a

于是四个量"一串到底"：
v = √(GM/r)　ω = √(GM/r³)　 T = 2π√(r³/GM)　a = GM/r²

这就是"卫星全家桶"公式 —— 只要给出 r，四个量全部确定。

分岔② 地表物体：随地球自转，不能用卫星公式ω = ω自转，是给定的

赤道上的物体跟着地球一起转，它的角速度被地球自转锁死：

ω = 2π / 24 h = 7.27 × 10⁻⁵ rad/s　（不是由 √(GM/r³) 算出来的！）

此时万有引力被"一分为二"：重力 mg + 提供自转所需的向心力 mω²R。

GMm/R² = mg + mω²R　⟹　mg ≈ GMm/R² （向心力只占 0.345%）

结论：地表物体不能用 GMm/r² = mω²r 去求角速度或线速度。 它的 v、a 只能用 v = ωR、a = ω²R 来算。

高频陷阱："同步卫星和地表物体角速度相同，所以线速度也相同" —— 错。 ω 相同只是起点，v = ωr 里 r 差了 6.62 倍，所以 v 也差 6.62 倍。

分岔③ 三个物体怎么排序先分组，再比较

第一步：按"同一规律"分成两组
· 组 A（卫星组）：近地卫星、同步卫星 —— 都用 √(GM/r) 那一套；
· 组 B（自转组）：地表物体 —— 用 v = ωR、a = ω²R。

第二步：跨组比较要"搭桥"
地表物体 ↔ 同步卫星：ω 相同（都是 24 h 一圈），所以可比； 地表物体 ↔ 近地卫星：r 相同（都 ≈ R），所以可比。

v：近地 7.92 > 同步 3.08 > 地表 0.465（km/s）
a：近地 9.8 > 同步 0.224 > 地表 0.034（m/s²）
ω：近地 > 同步 = 地表　　T：近地 < 同步 = 地表

记忆锚点：近地卫星是"三最"——v 最大、ω 最大、a 最大、T 最小； 同步卫星与地表物体"同步"，但半径更大 → v 更大、a 更大。

一句话结论
四个最容易错的判断
① 地表物体的向心力 ≠ 万有引力（重力占了绝大部分）；
② 不能用 √(GM/r) 算地表物体的速度；
③ ω 相同 不 意味着 v 相同；
④ 近地卫星"轨道低"因此速度大，不是小。
回到专题一：把这里的 v = √(GM/r) 用在两条圆轨道上， 就得到变轨题里"圆轨道越高、速度越小"这条最高频的结论 —— 而同步卫星正是靠"近地圆轨道 → 转移椭圆 → 同步圆轨道"三步爬上去的。

v 与 a 的对比 注意：横轴为对数刻度 —— 三个量相差最多 290 倍

卫星的变轨 · 规律总结

高三物理一轮复习 ｜ 天体运动中的三类热点问题 · 题型一

▎总纲：一句话抓住变轨题的全部考点

同一点看 加速度（只认 r）　·　同一点比 速度（看能量）　·　轨道越高 能量越大

变轨题的一切判断都能落到两把尺子上：加速度只由位置（r）决定；速度由所在轨道（半长轴 a）决定。把这两把尺子分清，形形色色的"快慢、大小、能量"比较题就都成了送分题。

变轨的四种情形加速外扩 · 减速内收

点火只是在一瞬间改变速度，改变不了位置 —— 所以变轨发生在同一位置。

  1. 在低轨上加速（在 P 点点火）：v 变大，所需向心力 mv²/r 超过了万有引力 GMm/r²，引力"拉不住"，卫星做离心运动，轨道外扩成椭圆。新轨道的近地点仍是 P 点。
  2. 在远地点再加速（在 Q 点点火）：使 Q 点从"远地点"变成新圆轨道上的一点，椭圆被"撑圆"成高圆轨道。
  3. 在高轨上减速：v 变小，引力大于所需向心力，卫星做近心运动，轨道内缩成椭圆，该点变成椭圆的远地点。
  4. 在近地点再减速：椭圆被"收圆"成低圆轨道，完成一次降轨。

口诀：点火加速 → 在该点"够不着"圆周轨道 → 向外；点火减速 → 在该点"跑不动了" → 向内。变轨后，点火点总是新椭圆的一个端点。

三大结论（必背）考场直接调用

  1. 同一位置，加速度一定相同。
    a = GM/r²，只与 r 有关，与在哪条轨道、往哪飞无关。
    ⟹ a_P(Ⅰ) = a_P(Ⅱ)，a_Q(Ⅱ) = a_Q(Ⅲ)。 "加速了所以加速度变大"是典型错误。
  2. 速度比较：
    v_ⅡP > v_Ⅰ > v_Ⅲ > v_ⅡQ
    （同一位置比速度靠 vis-viva；圆轨道之间"半径越大速度越小"）。
  3. 能量比较：
    E = −GMm/(2a)，E_Ⅰ < E_Ⅱ < E_Ⅲ。
    每次点火加速，机械能台阶式上跳（发动机做正功）；降轨则逐级减小。

周期关系：T₁ < T₂ < T₃（由开普勒第三定律 a³/T² = 常量，椭圆轨道的 a 介于两圆轨道半径之间）。

圆轨道之间的比较 —— 变轨题里考得最多的一类只要 r 定了，四个量全定

变轨题里最容易失分的不是复杂的椭圆，而是圆轨道与圆轨道的直接比较。 因为圆轨道上 万有引力 = 向心力 最干净，四个量能"一串到底"：

GMm/r² = mv²/r = mω²r = m(4π²/T²)r = ma
物理量表达式r 增大时口诀
线速度 vv = √(GM/r)减小越高越慢
角速度 ωω = √(GM/r³)减小越高越慢
向心加速度 aa = GM/r²减小越高越小
周期 TT = 2π√(r³/GM)增大越高越长

"三减一增"：r 增大时 v、ω、a 同时减小，只有 T 增大。 唯一例外是机械能：E = −GMm/(2r) 随 r 增大而增大， 所以"高轨道速度小但能量大"，两个结论并不矛盾。

重点模型 · 同步卫星的发射（霍曼转移）圆 → 椭圆 → 圆

同步卫星不能一步到位。它先在近地圆轨道上入轨，再沿一条转移椭圆爬高， 最后在远地点"撑圆"成同步圆轨道（r ≈ 6.62 R ≈ 3.6 万 km 高，T = 24 h）。

阶段动作速度（km/s）为什么
① 近地圆轨道 Ⅰ随火箭入轨v₁ = 7.92第一宇宙速度，贴着地面（r ≈ R）
② P 点点火加速 Δv₁ = +2.52v_P = 10.44所需向心力超过引力 → 做离心运动，进入转移椭圆
③ 转移椭圆远地点 Q自由滑行v_Q = 1.58开普勒第二定律：远地点最慢；T = 10.5 h
④ Q 点点火加速 Δv₂ = +1.50v₃ = 3.08把 Q 点变成新圆轨道的点，椭圆被"撑圆"

两个必须看清的反差：
· v₃(3.08) > v_Q(1.58) —— 第二次点火是加速，对；
· 但 v₃(3.08) < v₁(7.92) —— 圆轨道越高速度越小。两次都是加速，最终的圆轨道速度却比出发点小！ 奥秘在于：加速是在同一个点上发生的（同 r 比半长轴 a），而圆轨道之间是不同 r（直接比 r）。

一眼看懂：两条尺子怎么用同一点 vs 不同点

比较对象用什么判断结论为什么
P 点的 a（Ⅰ vs Ⅱ）先看 r相同同在 P 点，r 相同，a = GM/r²

解题模板：看到"变轨"先圈出点火点的位置，再问自己一句 —— "要比较的这两个量，是同一个 r（→ 比加速度），还是同一个位置但不同轨道（→ 比速度）？" 分清这一层，几乎所有变轨选择题都能秒杀。

天体的"追及"与"相遇" · 规律总结

高三物理一轮复习 ｜ 天体运动中的三类热点问题 · 题型二

▎总纲：所有追及问题都归结为一个"匀速追及"

Δθ = (ω₁ − ω₂) t　　⟹　　最近 Δθ = 2nπ　·　最远 Δθ = (2n−1)π

两星绕同一个中心天体同向转动，角速度不同、且恒定不变，所以它们的夹角 Δθ 是匀速增长的。这样，"天体追及"就变成了最朴素的匀速追及问题 —— 只需盯住 Δθ 这一个量。

大前提（三条）：① 同一平面内；② 同向转动；③ 从"两星同时位于某条射线上（同相位）"开始计时。缺一条，公式都要改写。

四步解法照做即可

  1. 找周期：由 r³/T² = 常量 或 T = 2π√(r³/GM) 求出 T₁、T₂。半径小的周期小、角速度大。
  2. 转成角度：写出 θ₁ = ω₁t = 2πt/T₁、θ₂ = 2πt/T₂，夹角 Δθ = 2πt(1/T₁ − 1/T₂)。
  3. 翻译条件：最近 → 共线同侧 → Δθ = 2nπ；最远 → 共线异侧 → Δθ = (2n−1)π。
  4. 解出时间：代入化简，取 n = 1、2、3… 得到第一次、第二次……
t_最近 = n·T₁T₂/(T₂ − T₁)
t_最远 = (2n − 1)·T₁T₂/[ 2(T₂ − T₁) ]

三个易错点几乎每年都考

  1. 用圆心角，不用弧长。两星轨道半径不同，相同时间内走过的弧长不相等；"相距最近"说的是两星与中心天体的夹角，不是路径长度。
  2. "最近"与"最远"的先后顺序。从同相位出发，先到 π（最远），再到 2π（最近）。所以第一次"最近"的时间是第一次"最远"的 2 倍。
    t_最远 = t_最近 / 2
  3. 别把 T₂ − T₁ 写成 T₁ − T₂。约定 T₁ < T₂（内圈为 1 号），分母必须为正。两星周期越接近，分母越小，等待时间越长 —— 这也是本页右下图那条曲线急剧上翘的原因。

逆向问法也常见：给出时刻 t 求 n，或给出 n 求"还要多久"。处理方法完全一样，只是把未知量换个位置解方程。

条件 ↔ 公式 对照速查n = 1, 2, 3, …

问法相位条件通式第一次（n = 1）
相距最近（第 n 次）Δθ = 2nπt = n·T₁T₂/(T₂−T₁)t = T₁T₂/(T₂−T₁)
相距最远（第 n 次）Δθ = (2n−1)πt = (2n−1)T₁T₂/[2(T₂−T₁)]t = T₁T₂/[2(T₂−T₁)]
从最近到下一次最近Δθ 增加 2πΔt = T₁T₂/(T₂−T₁)同左（相邻两次间隔恒定）
从最远到下一次最近Δθ 增加 πΔt = T₁T₂/[2(T₂−T₁)]同左

延伸：如果把两颗卫星换成"地球与某颗行星"的会合周期，公式完全一样 —— 这就是会合周期 1/T会合 = |1/T₁ − 1/T₂| 的天体版表达。本页左下图（Δθ 随时间线性增长）把"匀速"这个前提画得非常直观： 斜率就是 Δω，直线每爬过一个 2π 台阶，就完成一次"最近"。

本页 Δθ 与各次相遇时刻由 Δθ = (ω₁ − ω₂)t 实时数值计算，与教材公式逐项吻合

双星 · 三星 规律总结

高三物理一轮复习 ｜ 天体质量与密度的求解方法 · 多星系统篇

▎总纲：一张公式管住全部六种构型

ω² = ξ · G·M总 / L³　　⟺　　T = (2π/√ξ) · √( L³ / (G·M总) )

L 统一取"相邻（特征）间距"，M总 统一取"系统总质量"，那么 ξ 就是一个纯几何因子 —— 它只由构型决定（三星还额外由质量分配决定），与 L、M 的大小无关。

这就是为什么下面六种构型的"快慢排序"可以事先算出来，也是双星与三星等边三角形能共用同一条公式的原因。

双星系统ξ = 1唯一能称出单星质量

两星绕共同质心转动，是整个多星体系里唯一"质量可完全求解"的情形。

  1. 三点始终共线：两星与质心永远在同一直线上，且分居质心两侧，L = r₁ + r₂。
  2. 同周期、同角速度：T₁ = T₂，ω₁ = ω₂ —— 这是双星问题的出发点，也是"两星永远面对面"的原因。
  3. 质心不动：不受外力时 m₁r₁ = m₂r₂，质心保持静止或匀速直线运动。
  4. 三个反比关系：r₁ : r₂ = v₁ : v₂ = a₁ : a₂ = m₂ : m₁。半径、线速度、向心加速度都与质量成反比 —— 质量大的离质心近、跑得慢、加速度小。
  5. 引力同时充当两星的向心力，必须对两星各列一次方程（这一步最容易漏）：
    G m₁m₂ / L² = m₁ω²r₁ = m₂ω²r₂
  6. 总质量公式（与"环绕法"完全一致）：
    M总 = m₁ + m₂ = 4π²L³ / (G T²)　⟺　ω² = G·M总 / L³
    T 只由 M总 与 L 决定，与质量如何分配毫无关系 —— 动画里拖 k 滑块，周期读数一动不动，就是这个道理。
  7. 单星质量公式（双星法独有）：把 r₁/r₂ = m₂/m₁ 与 r₁+r₂ = L 联立，
    m₁ = 4π²L²r₂ / (G T²)　　m₂ = 4π²L²r₁ / (G T²)
    所以只要再测出任意一颗星到质心的距离，两颗星的质量就都能算出来。
  8. 必踩的坑：想从 G m₁m₂/L² = m₁ω²r₁ 直接解 m₁ —— 两边同除 m₁，m₁ 被约掉了，你得到的其实是 m₂。"环绕法只能称中心天体"在这里再次出现，量 m 就是那个被约掉的量。

三星系统ξ 见下表只有两种刚性构型

三星比双星多了一个自由度，但"能整体转起来"的几何反而只剩两种。

  1. 刚性转动的三星只有两种构型：等边三角形（拉格朗日，1772）与共线（欧拉，1767）。任意画一个不等边的三角形，转动时形状必然变形，最终瓦解 —— 见下方"为什么只有两种"。
  2. 等边解对任意三个质量都成立（这是它最强的地方）：三角形边长 L 始终不变，但质心不再落在几何中心 —— 质量大的一侧半径小。
  3. 各星到质心的半径（等边解，i, j, k 轮换）：
    R_i = L · √( m_j² + m_j m_k + m_k² ) / ( m₁ + m₂ + m₃ )
    三质量相等时退化为 R = L/√3，即质心与几何中心重合。
  4. 等边解的周期只由总质量与边长决定：
    ω² = G(m₁+m₂+m₃) / L³　⟹　T = 2π√( L³ / (G·M总) )
    与三个质量怎么分配完全无关 —— 和双星是同一个公式。
  5. 共线解（两侧星质量 m、中星质量 km）：中星受两侧对称引力，合力为零，所以它静止在质心，两侧星轨道半径都是 L（不是 L/2）。
    ω² = (4k+1)/4 · G m / L³ = (4k+1) / [4(2+k)] · G·M总 / L³
    k = 1 时系数 = 5/12 ≈ 0.4167，就是教材的标准情形。
  6. 两种解的差别，用 k 滑块一看就明白：总质量固定时，等边解的周期一动不动，共线解的周期随质量分配改变（中星越重、转得越快）。这是因为共线解周期里含 k，等边解周期里不含 k。
  7. 最容易混的两个量：牛顿第二定律 F = mω²R 里的 R 是"该星到质心的距离"；引力式 Gm₁m₂/d² 里的 d 是"两星间距"。多星问题里这两者只有在双星中才恰好相等，其余构型必须分开算。

六种构型统一对照表ξ 与 n 都是纯数字，与 L、M 的大小无关

构型特征长度 Lξ = ω²L³ /(G·M总)n = T / √(L³/(G·M总))说明

怎么读这张表：n 就是"周期系数"，n 越小转得越快。规律是 构型越紧凑（各星到质心的半径越小）→ ξ 越大 → n 越小 → 转得越快。三星等边（R = 0.577L）与双星（R 由质量比决定）竟然算出同一个 n = 2π，这不是巧合，而是"ξ = 1"这个共同点带来的。四星三角形+圆心的 R 同样是 0.577L，但因为圆心多了一颗星提供额外引力，ξ 被抬到 2.049，于是它成了最快的。

为什么"不等边三角形"转不起来？三体问题第一条铁律

想让三星保持形状整体转动（刚性转动），必须对每一颗星同时满足两个条件：

  1. 合力方向必须严格通过质心（否则星会被甩向侧面，形状立刻变形）；
  2. 合力大小必须正比于它到质心的距离，而且比例系数 ω² 对三颗星都相同（否则三颗星各转各的周期，构型散架）。

拿一个随便画的不等边三角形去逐星验证，会发现这两个条件无法同时成立 —— 有的星要求 ω² 大、有的要求小，甚至出现负值（表示它受到的是向外的合力，根本无法做圆周运动）。

能同时满足这两条的几何只有两种：等边三角形与共线。这正是三体问题里最早被找到的两个精确解，也是本页动画只演示这几种构型的原因。
顺带一提：四星共线的"内宽外窄"、四星 3+1 的"中心星必须正好落在质心"，都是同一个要求在四体情形下的体现。

多星问题四步通法任何构型都能上手

两星靠"反比分配"、三星靠"矢量叠加"，其实都可以归到一套固定流程。考场上遇到陌生构型（比如"四星正四面体""五星一环一轴"）照这四步走：

  1. 定质心：先用 Σmᵢřᵢ = 0 定出质心位置，把每颗星的坐标改写成"相对质心"的形式，得到各自的半径 Rᵢ。这一步不做，后面必错。
  2. 逐星算合力：对每颗星，把与其余各星的引力逐对拆开，先算大小 Gmᵢmⱼ/dᵢⱼ²，再按方向做矢量合成。对称构型用"对称抵消"可大幅简化（中星合力为零）。
  3. 令合力 = 所需向心力：|F合| = mᵢω²Rᵢ。把所有星的 ω² 都算一遍，核对它们是否相等 —— 相等才说明这个构型真的能整体转动。
  4. 换成周期：用 ω = 2π/T 代入，整理成 T = n·√(L³/(G·M总)) 的形式，读出几何系数 n。

数值证据：本页右栏"牛顿第二定律实时校验"就是第 ③ 步的自动执行 —— 计算 |F合| ÷ (mω²R)，六种构型全部读出 1.000000。

地表物体 · 近地卫星 · 同步卫星 · 规律总结

高三物理一轮复习 ｜ 三体比较 —— 天体运动所有比较题的"母题"

▎总纲：先分组，再比较 —— 这两个组用的根本不是同一套公式

组 A（卫星）万有引力 = 向心力　│　组 B（地表）万有引力 = 重力 + 向心力

凡是"卫星"（近地、同步、任意轨道），都只受万有引力，且它全部充当向心力，于是 v=√(GM/r)、ω=√(GM/r³)、T=2π√(r³/GM)、a=GM/r² 全部成立。
而地球表面上的物体是"搭地球自转便车"的，它的 ω 被锁死在 2π/24h， 只能用 v=ωR、a=ω²R。 把这两组混为一谈，是三体比较题的唯一失分点。

分岔点：地表物体凭什么不能套卫星公式最容易错的一步

赤道上放一个物体，它跟着地球转，不是在"做圆周运动"而是"被地球带着转"。 万有引力在这里有两个去处：

GMm/R² = mg + mω²R

重力 mg 占了绝大部分，向心力 mω²R 只占 0.345%（≈ 0.034 ÷ 9.8）。所以 mg ≈ GMm/R²， 这也是为什么"重力≈万有引力"是个很好的近似。

  1. 不能用 GMm/R² = mω²R 反求地表物体的 ω。
    反求出来的会是"近地卫星"的 ω（17 倍大），不是地表物体的 ω。
  2. 不能用 v=√(GM/R) 求地表物体的线速度。
    那算出的是第一宇宙速度 7.92 km/s，而地表物体只有 0.465 km/s。
  3. 正确做法：地表物体先取 ω = 2π/24h，再用 v=ωR、 a=ω²R。

三组必考比较按"搭桥量"分类

搭桥量 = 两组对象共享的那个量，找到它就能比。

  1. 近地卫星 ↔ 同步卫星（搭桥量：都是卫星）
    走 √(GM/r) 一套。r：近地 < 同步
    ⟹ v、ω、a 都是近地大；T 是近地小。
    v 比 = √6.62 = 2.57　a 比 = 6.62² = 43.8
  2. 同步卫星 ↔ 地表物体（搭桥量：ω 相同，都是 24 h 一圈）
    ω 相同 ⟹ v = ωr、a = ω²r 都正比于 r。
    r 比 = 6.62 ⟹ v 比 = a 比 = 6.62。（这是最漂亮的一组）
  3. 近地卫星 ↔ 地表物体（搭桥量：r 相同，都 ≈ R）
    r 相同但规律不同 ⟹ 卫星快得多。
    v 比 = √6.62 ... 实际 = 17.0（等于 ω 比）， a 比 = 289.5。

三个"锚点"记牢：
① 近地卫星是"三最一少" —— v 最大、ω 最大、a 最大、T 最小；
② 同步卫星 = 地表物体的"高配版" —— 同样 24 h 转一圈，但半径 6.62 倍，所以 v 和 a 都大 6.62 倍；
③ 地表物体是唯一的"异类" —— 只有它不能用卫星公式，只有它的向心力远小于万有引力。

为什么"同步"卫星真的不动自锁的物理原因

同步卫星的周期被"调"成恰好 24 h（与地球自转相同）， 所以它相对地面静止——卫星天线可以固定指向它，这就是通信卫星、气象卫星（如"风云四号"）都放同步轨道的原因。

但要注意两个"必须"：

  1. 必须与赤道共面。若轨道平面与赤道成角，卫星会南北摆动，无法相对地面静止。
  2. 高度唯一。由 T=2π√(r³/GM) 取 T=24h，解得 r ≈ 6.62R ≈ 42340 km， 即离地约 3.6 万 km。这个高度是全球统一、唯一的。

常见题型与破题口诀一句话对号入座

  1. 问"哪个快"：先问"它们属于同一组吗？"
    同组（都是卫星）→ 用 r；跨组（卫星 vs 地表）→ 先找搭桥量（ω 同还是 r 同）。
  2. 问"地表物体"：立刻写下 ω = 2π/24h，用 v=ωR， 绝不用 √(GM/r)。
  3. 问"同步卫星"：立刻写下 T = 24h、r ≈ 6.6R， 其余用卫星公式。
  4. 问"重力与万有引力"：地表物体 mg = GMm/R² − mω²R； 卫星则完全失重。
  5. 问"比较 a"：卫星用 a = GM/r²；地表物体用 a = ω²R。 千万别对地表物体用 GM/R²。

一句口诀收尾： "卫星越低越快，地表最慢；同步与地面同步，半径大所以更快。"
