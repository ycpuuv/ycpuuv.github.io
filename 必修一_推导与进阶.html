📖 第一章 · 运动的描述（难点精讲）

加速度的理解与矢量性——这是第一章真正的难点，也是第二章的基石

1.4 加速度 · 深度理解

加速度的本质： 速度对时间的变化率 a = dv/dt（极限思想）
矢量性的核心： a与v同向→加速；a与v反向→减速（和a的正负号无关！）
常见误区： a>0不一定加速——因为v也可能为负！
📐 推导：从加速度定义到匀变速速度公式
定义：a = Δv/Δt = (v − v₀)/t
两边乘t：v − v₀ = at
移项：v = v₀ + at
这是匀变速直线运动的第一条基本公式——直接从加速度定义出发，没有任何假设
Q1. 【核心理解】一质点做直线运动，加速度a = -5m/s²，初速度v₀ = -3m/s。问该质点是加速还是减速运动？
Q2. 【易错】物体做加速度逐渐减小的加速运动，当加速度减小到0时，物体的速度____（最大/最小/为0）
Q3. 【逆向思维】一个做匀减速直线运动的物体，某时刻速度大小为v，经过t时间后速度大小仍为v，但方向相反。求这段时间内的加速度。
提示： Q1：a与v₀同号（均为负）→同向→加速！Q2：只要a与v同向，即使a减小，v仍增大，直到a=0时v最大。Q3：设初速度方向为正，则v₀=v，v=-v，a=(-v-v)/t = -2v/t

📖 第二章 · 公式体系全推导

从加速度定义出发，一步步推导出所有公式——理解才能灵活运用

2.1 四大公式 · 完整推导链

📐 推导一：v = v₀ + at（已证）
由加速度定义 a = (v − v₀)/t → v = v₀ + at
📐 推导二：x = v₀t + ½at²“（v-t图面积法）”
在v-t图像中，图线是一条斜线（匀变速）
位移 = 图线与t轴围成的梯形面积
梯形面积 = 矩形 + 三角形
矩形面积 = v₀·t
三角形面积 = ½·(at)·t = ½at²
总面积：x = v₀t + ½at²
⚠️ 这个推导必须掌握——v-t图面积=位移是运动学最重要的思想之一！
📐 推导三：v² − v₀² = 2ax（消t法）”
由 v = v₀ + at → t = (v − v₀)/a
代入 x = v₀t + ½at²
x = v₀·(v−v₀)/a + ½a·(v−v₀)²/a²
化简：x = (v₀v − v₀²)/a + (v² − 2vv₀ + v₀²)/(2a)
通分相加：x = (v² − v₀²)/(2a)
移项：v² − v₀² = 2ax
这个公式最大的优势是「不含时间t」，当题目不涉及时间时直接使用
📐 推导四：x = (v₀+v)·t / 2（平均速度法）”
由 x = v₀t + ½at²
将 at = v − v₀ 代入
x = v₀t + ½(v−v₀)t
x = v₀t + ½vt − ½v₀t
x = (v₀ + v)·t / 2
本质：匀变速直线运动的平均速度 = (v₀+v)/2
Q1. 【公式选择训练】一架飞机着陆时的速度为60m/s，以-5m/s²匀减速，问跑道至少需要多长？选择哪个公式最简便？为什么？
Q2. 【综合】一物体从静止开始做匀加速直线运动，第3s末的速度为6m/s，求第5s内的位移。
提示： Q1已知v₀,v,a，求x——用v²−v₀²=2ax（不含t最简便）；Q2先求a=v/t=2m/s²，再求前5s和前4s位移差——第5s内位移 = Δx = ½×2×25 − ½×2×16 = 9m

2.2 两个重要推论 · 完整推导

📐 推导一：Δx = aT²（连续相等时间位移差恒等）”
设物体以初速度v₀、加速度a做匀变速运动
第一个T内的位移：x₁ = v₀T + ½aT²
第二个T内的位移：x₂ = (v₀+aT)T + ½aT² = v₀T + aT² + ½aT²
两段位移差：Δx = x₂ − x₁
Δx = (v₀T + aT² + ½aT²) − (v₀T + ½aT²)
Δx = aT²
这个结论的妙处在于：它和初速度无关！无论v₀多大，相邻相等时间位移差都是aT²
📐 推论延伸：纸带逐差法原理”
如果T内取了6段位移：x₁, x₂, x₃, x₄, x₅, x₆
单用Δx=aT²——只用了x₂−x₁，浪费了其他数据
逐差法：a = [(x₄+x₅+x₆) − (x₁+x₂+x₃)] / (3T)²
即 a = [(x₄+x₅+x₆) − (x₁+x₂+x₃)] / 9T²
为什么除以9T²？因为x₄−x₁=3aT²，所以(x₄−x₁)+(x₅−x₂)+(x₆−x₃)=3×3aT²=9aT²
📐 推导二：中间时刻速度 = 平均速度”
前半段时间：从0到t/2，速度从v₀到vt/2
vt/2 = v₀ + a·(t/2) ——公式①
后半段时间：从t/2到t，速度从vt/2到v
v = vt/2 + a·(t/2) ——公式②
②-①：v − vt/2 = vt/2 − v₀
→ 2vt/2 = v₀ + v
vt/2 = (v₀ + v)/2
又因为 x = (v₀+v)t/2，所以 vt/2 = x/t = 平均速度
重要结论：匀变速直线运动中，中间时刻速度 = 平均速度。这是实验求瞬时速度的依据！
Q1. 【Δx=aT²应用】小球从斜面上滚下做匀加速直线运动，照相机每隔0.1s拍摄一次。测得第1段距离4.0cm，第3段距离8.0cm。求加速度a，以及第2段的距离。
Q2. 【中间时刻速度】一物体做匀加速直线运动，通过A点速度3m/s，通过B点速度7m/s，AB中点速度为v₁，AB中间时刻速度为v₂。比较v₁和v₂的大小。
Q3. 【综合★】做匀加速运动的物体，通过一段长x的位移所用时间为t₁，紧接着通过下一段同样长x的位移所用时间为t₂。求物体的加速度。（用x, t₁, t₂表示）
提示： Q1：Δx=aT²，第1段到第3段差2个Δx，即(8-4)=2a(0.1)²→a=200cm/s²=2m/s²；x₂=x₁+aT²=6.0cm。Q2：匀加速中v中=√[(v₀²+v²)/2]≈5.4m/s，v时=(v₀+v)/2=5m/s，所以v₁>v₂。Q3：用平均速度！v₁=x/t₁，v₂=x/t₂，a=(v₂−v₁)/[(t₁+t₂)/2]=2x(t₁−t₂)/[t₁t₂(t₁+t₂)]

2.3 自由落体 · 经典比例与高级应用

📐 推导：自由落体三大经典比例”
设t=0开始自由下落（v₀=0, a=g）
① 1T内、2T内、3T内...位移比：
h₁ = ½g(T)² = ½gT²
h₂ = ½g(2T)² = 2gT²
h₃ = ½g(3T)² = 4.5gT²
h₁ : h₂ : h₃ : ... = 1 : 4 : 9 : ...
② 第1T内、第2T内、第3T内...位移比：
hⅠ = h₁ = ½gT²
hⅡ = h₂ − h₁ = 1.5gT²
hⅢ = h₃ − h₂ = 2.5gT²
hⅠ : hⅡ : hⅢ : ... = 1 : 3 : 5 : ...
③ 下落h、2h、3h...所用时间比：
由 h = ½gt² → t = √(2h/g)
t₁ : t₂ : t₃ : ... = 1 : √2 : √3 : ...
Q1. 【比例法巧解】一石块从高处自由落下，通过前1m、前2m、前3m所用时间之比为______。
Q2. 【比例法巧解】自由落体第1s内下落5m，第3s内下落____m。
Q3. 【塔顶落石★】一石子从塔顶自由下落，最后1s下落的高度为塔高的9/25，求塔高h（g=10m/s²）。
Q4. 【穿越窗口★★】一个长L的杆子从高处自由落下，杆子下端经过高h的窗口所用时间为t，求杆子上端经过窗口所用的时间。
提示： Q1：1:√2:√3。Q2：1:3:5=5:15:25→第3s内25m。Q3：设总时间t，最后1s位移=½gt²−½g(t-1)²=9h/25，又h=½gt²，联立得t=5s，h=125m。Q4：下端经过窗口用时t₁=√[2(h+L)/g]−√(2h/g)，上端经过窗口用时t₂=√[2(h+2L)/g]−√[2(h+L)/g]

2.4 追及相遇问题 · 临界分析

核心思想：速度相等时是追及问题的临界点（距离最远或最近）
解题三步：①画示意图 ②列位移方程 ③令速度相等求临界
Q1. 【匀速追匀加速★】汽车A以20m/s匀速行驶，发现前方x₀=150m处汽车B以10m/s匀速行驶。A刹车做加速度大小为2m/s²的匀减速。问A是否会撞上B？
Q2. 【匀加速追匀速★★】当汽车B以10m/s匀速经过路口时，汽车A从静止开始以2m/s²启动追赶。求：①A追上B所需时间 ②追上时A的速度 ③追上前A、B间最大距离
Q3. 【匀减速追匀速★★】在平直公路上，A车以20m/s行驶，发现前方100m处B车以8m/s匀速行驶。A立即刹车做匀减速，问加速度至少为多大才不撞上？
提示： Q1：速度相等时v₀−at=10→t=5s，xA=75m，xB=50m，Δx=25m<150m→不撞。Q2：①½at²=vt→t=10s；②v=20m/s；③t=5s时距离最大，Δx=vt−½at²=25m。Q3：设a，速度相等时t=(20-8)/a=12/a，xA=20t−½at²，xB=8t。令xA−xB≤100→a≥0.72m/s²

2.5 竖直上抛运动 · 对称性分析（拓展）

特点：竖直上抛 = a=-g的匀减速直线运动（全过程统一处理）
对称性：上升和下降通过同一位置时速度大小相等、方向相反；上升和下降通过同一段距离所用时间相等
📐 推导：上升最大高度与上升时间”
取向上为正，v₀>0，a=−g
最高点 v=0：0 = v₀ − gt → t = v₀/g
最大高度：0² − v₀² = 2(−g)H → H = v₀²/2g
Q1. 【对称性应用】某物体竖直上抛，经4s落回原处，求初速度和最大高度（g=10m/s²）。
Q2. 【分段vs全程★★】某物体以20m/s竖直上抛，求：①第3s末的位置和速度 ②全程运动总时间（取向上为正，g=10m/s²）
Q3. 【双向可逆★★】一个从地面竖直上抛的物体，两次经过A点的时间间隔为Δt，求A点距地面的高度。（不计空气阻力）
提示： Q1：对称性→上升下降各2s，v₀=gt=20m/s，H=½gt²=20m。Q2：①x=20×3−½×10×9=15m，v=20-30=-10m/s（向下）；②t=4s。Q3：从最高点到A点的时间为Δt/2，最高点到地面t₀，h=½g(t₀²−(Δt/2)²)

📋 公式体系 · 推导逻辑图

一条推导链串起所有公式——理解了就再也不用死记硬背
加速度定义 a=Δv/Δt
→→→→ v = v₀ + at（消Δv）
→→→→ 代入x=v₀t+½at²的v-t图面积
→→→→ x = v₀t + ½at²
→→→→ 两式联立消t →→→→ v²−v₀²=2ax
→→→→ v=v₀+at代入x公式 →→→→ x=(v₀+v)t/2
→→→→ 比较相邻T位移差值 →→→→ Δx=aT²
→→→→ 前半/后半时间对称 →→→→ vₜ/₂=(v₀+v)/2
结论：所有公式都来自于加速度定义 + v-t图面积，一个推导链贯穿全部！
