2023 全国乙卷 25 题：圆盘与小球，碰几次？

一、原题

竖直固定的长直圆管内有一圆盘，圆盘质量 M = 3m（m 为小球质量），圆盘与管壁间的滑动摩擦力大小恒等于 Mg。圆盘上方有一质量为 m 的小球，从距圆盘 l 处由静止释放。小球与圆盘发生弹性碰撞，碰撞时间极短。第一次碰撞的位置距圆管下端口 19l。重力加速度为 g。求：

  1. 第一次碰撞后瞬间小球和圆盘的速度大小；
  2. 第一次碰撞到第二次碰撞之间，小球与圆盘间的最远距离；
  3. 圆盘在管内运动过程中，小球与圆盘碰撞的次数。

二、常规解法的困境

第(1)(2)问是常规题：小球下落 l 后速度 v₀ = √(2gl)。等质量相碰才会交换速度，而这里 M = 3m，代入弹性碰撞公式得

v₁′ = −v₀/2（向上），v₂′ = v₀/2（向下）

之后共速时相距最远，最远距离 v₀²/(2g) = l。

真正的困难在第(3)问：圆盘每碰一次速度就增加 v₀/2，而且逐段匀速。按常规思路，必须“碰一次、算一次、再加一次”，十几次下来极易出错。而次数本身就藏在“总位移不能超过 19l”这个条件里。

三、质心法：三步

第一步：质心做什么运动？

圆盘受摩擦力 Mg 向上，自身重力 Mg 向下，两者抵消；小球只受重力。系统合外力

F = (M+m)g − Mg = mg，所以 a_c = mg/(M+m) = g/4

整段过程里，质心始终以 g/4 匀加速下落——不管两者各自的速度怎么跳变。第一次碰前小球速度 v₀、圆盘静止，故质心初速度 v_c0 = mv₀/(M+m) = v₀/4。

第二步：碰撞发生在什么时刻？

取第一次碰撞点为原点、向下为正。碰后小球做匀加速（a = g），圆盘匀速。设经过 t 再次相遇：

x球 = −(v₀/2)t + ½gt²，x盘 = (v₀/2)t

令两者相等，得 ½gt² = v₀t，即 t = 2v₀/g。

而且弹性碰撞只让相对速度反向、大小不变（相对加速度恒为 g），所以每次碰撞间隔都等于 2v₀/g。碰撞时刻构成等差数列 tₙ = 2(n−1)v₀/g。

第三步：碰几次？

碰撞瞬间球与盘在同一位置，质心也必在该位置。于是只要算质心的位移：

x_c = (v₀/4)t + ½·(g/4)·t²

把 tₙ = 2(n−1)v₀/g 代入，并用 v₀² = 2gl 化简得

xₙ = l·n(n−1)

这个结果只跟 n 有关，与中间任何一次的速度无关。

管口在 19l 处，要求 xₙ < 19l：

n = 4 → x₄ = 12l ✓　　n = 5 → x₅ = 20l > 19l ✗

所以一共碰撞 4 次；第 4 次碰点距下端口 19l − 12l = 7l。

对比一下：常规解法要算 4 次速度、4 段位移再累加；质心法只写了一个二次式、比了一个数。

四、v-t 图怎么看

· 圆盘合力为零，做匀速运动 → 图上是水平台阶，每碰一次抬升 v₀/2

· 小球只受重力 → 图上是一族平行斜线，斜率都是 g

· 碰撞就是斜线与台阶之间的竖直跳变，跳变前后两线间距都是 v₀

· 质心是一条笔直的斜线，斜率 g/4，穿过整个图形

· 两线相交即共速，此时相距最远；三角形的面积就是最远距离
