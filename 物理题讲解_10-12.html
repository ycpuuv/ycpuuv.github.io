第10题：车厢中的相对运动

汽车匀加速直线运动，甲、乙从车厢中间分别向前后壁移动，同时到达。

原题呈现

一辆汽车在平直公路上做匀加速直线运动，车厢内甲、乙两名乘客分别从车厢正中间同时向车头和车尾走去，恰好同时到达车头和车尾，则：

A. 甲对地的位移大于乙对地的位移

B. 乙对地的平均速度大于甲对地的平均速度

C. 甲对地的平均速度大于乙对地的平均速度 ✓

D. 甲对地的平均速度等于乙对地的平均速度

核心分析（地面参考系）：

设汽车在时间 t 内前进距离为 d，车厢半长为 L。

甲向车头走：对地位移 = d + L（与车同向，叠加）

乙向车尾走：对地位移 = d − L（与车反向，抵消）

∵ d + L > d − L，且时间相同 t

∴ 甲对地的平均速度 > 乙对地的平均速度，选项C正确 ✓

第11题：地球仪上的位移与平均速度

小虫从P点沿0°经线向南到南极点，再沿90°E经线向北到Q点。

原题呈现

如图所示，地球仪的半径为R，P点位于赤道与本初子午线的交点。一只小虫从P点出发，沿0°经线向南爬行到达南极点，再沿90°E经线向北爬行到达赤道上的Q点。小虫从P到南极点的时间为t，从南极点到Q的时间也为t。则：

A. 位移大小为πR

B. 位移大小为2R

C. P到南极点的平均速度大于南极点到Q的平均速度

D. P到南极点的平均速度是南极点到Q的2倍 ✓

位移分析：位移是初位置指向末位置的有向线段，与路径无关。

建立三维坐标系（球心为原点）：P = (R, 0, 0)，Q = (0, R, 0)

位移大小 = |PQ| = √[(R−0)² + (0−R)²] = R√2

注意：路程为 πR，位移为 R√2，两者不同。选项A(πR)、B(2R)均错误。

平均速度计算

P→南极：位移大小 = R√2，时间 = t，平均速度 v₁ = R√2 / t

南极→Q：位移大小 = R√2，时间 = t，平均速度 v₂ = R√2 / t

P→Q全程：位移大小 = R√2，时间 = 2t，平均速度 v全 = R√2 / (2t)

∴ v₁ = v₂ = 2·v全，选项D正确 ✓

选项C说"大于"不准确，实际是"等于"，C错误。

第12题：超声波测速系统（重点：C、D选项分析）

发射器A在运动物体上，同时发射红外线和超声波；接收器B固定。

原题呈现

如图所示，发射器A固定在运动物体上，接收器B固定不动。A同时发射红外线和超声波脉冲，B接收到红外线时开始计时，接收到超声波时停止计时。系统通过 s = v₀·Δt 计算A与B之间的距离（v₀为超声波速度），通过两次测距差计算物体速度v。已知红外线传播速度为c。则：

A. 该系统可以精确测量A到B的距离

B. 红外线从A到B的传播时间不可忽略

C. 该测量产生的误差属于偶然误差

D. 系统算出的速度大于物体的实际速度 ✓

测量原理：红外先到B → 启动计时；超声后到B → 停止计时。

系统认为：红外传播时间≈0，故 Δt = 超声从A传到B的时间，s = v₀·Δt。

但实际上红外以光速c传播需时间 tᵢᵣ = d/c，此间A已移动 → 产生系统误差。

误差来源：忽略红外传播时间

红外以光速c传播，从A到B需时间 tᵢᵣ = d/c。

在这段时间内，A已移动 Δx = v·tᵢᵣ。

→ A靠近B：超声传播距离变短 → 测距偏小

→ A远离B：超声传播距离变长 → 测距偏大

误差方向固定（非随机）→ 属于系统误差。

选项C："该误差属于偶然误差" —— ❌ 错误！

系统误差：由仪器原理或测量方法的固有缺陷导致，方向确定（总偏大或总偏小），具有重现性。

偶然误差：由随机不可控因素导致，方向不确定（时大时小），服从正态分布。

忽略红外传播时间 → 误差方向由运动方向唯一确定 → 系统误差，不是偶然误差。

选项D："系统算出的速度大于物体实际速度" —— ✓ 正确

以A远离B为例：每次测距 s测 = d·(1+v/c)，偏大。

两次测距求速度：v测 = (s₂测 − s₁测)/T = v·(1+v/c)

∵ v/c > 0，∴ v测 = v(1+v/c) > v ✓
