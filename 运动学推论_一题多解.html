推论证明：知其然，更知其所以然

10 min

推论① 平均速度公式

点击展开证明 ↓
点击展开

结论：匀变速直线运动中，某段时间内的平均速度等于该段时间中间时刻的瞬时速度。

$$\bar{v} = v_{t/2} = \frac{v_0 + v}{2}$$

证明：

设物体做匀变速直线运动，初速度 $v_0$，末速度 $v$，加速度 $a$，运动时间 $t$。

由位移公式：$x = v_0 t + \frac{1}{2}at^2$

平均速度定义：$\bar{v} = \frac{x}{t} = v_0 + \frac{1}{2}at$

中间时刻 $t/2$ 的瞬时速度：$v_{t/2} = v_0 + a\cdot\frac{t}{2} = v_0 + \frac{1}{2}at$

因此 $\bar{v} = v_{t/2}$。

又由 $v = v_0 + at$ 得 $at = v - v_0$，代入：

$$\bar{v} = v_0 + \frac{v - v_0}{2} = \frac{v_0 + v}{2} \quad \blacksquare$$

点拨：平均速度只有在匀变速运动中才等于首末速度的算术平均值。这是推论，不是定义！

推论② 中点位置速度公式

点击展开证明 ↓
点击展开

结论：匀变速直线运动中，经过位移中点时的瞬时速度：

$$v_{s/2} = \sqrt{\frac{v_0^2 + v^2}{2}}$$

证明：

对前半段位移，由 $v^2 - v_0^2 = 2as$：

$$v_{s/2}^2 - v_0^2 = 2a \cdot \frac{s}{2} \quad \cdots (1)$$

对后半段位移：

$$v^2 - v_{s/2}^2 = 2a \cdot \frac{s}{2} \quad \cdots (2)$$

由 $(1) = (2)$：$v_{s/2}^2 - v_0^2 = v^2 - v_{s/2}^2$

$$2v_{s/2}^2 = v_0^2 + v^2 \;\Rightarrow\; v_{s/2} = \sqrt{\frac{v_0^2 + v^2}{2}} \quad \blacksquare$$

点拨：证明的关键是"两段位移相等，加速度相同"→两段的 $v^2$ 增量相等。这个技巧叫位移对称法。

推论③ 逐差公式 $\Delta x = aT^2$

点击展开证明 ↓
点击展开

结论：匀变速运动中，连续相等时间 $T$ 内的位移之差为常量：

$$\Delta x = x_2 - x_1 = aT^2$$

证明：

设第 1 个 $T$ 内初速度为 $v_0$，则：$x_1 = v_0 T + \frac{1}{2}aT^2$

第 1 个 $T$ 末速度 $v_1 = v_0 + aT$，第 2 个 $T$ 内：

$$x_2 = v_1 T + \frac{1}{2}aT^2 = v_0 T + \frac{3}{2}aT^2$$

因此：$x_2 - x_1 = aT^2$

同理 $x_3 - x_2 = aT^2$，逐差相等。$\blacksquare$

推广（逐差法求加速度）：若有连续 6 段位移 $x_1 \cdots x_6$：

$$a = \frac{(x_4 + x_5 + x_6) - (x_1 + x_2 + x_3)}{9T^2}$$

点拨：逐差法的精髓是充分利用所有数据，减小偶然误差。

推论④ 初速为零的比例关系

点击展开证明 ↓
点击展开

结论一（等时分割）：连续相等时间 $T$ 内的位移之比：

$$x_1 : x_2 : x_3 : \cdots : x_n = 1 : 3 : 5 : \cdots : (2n-1)$$

结论二（等距分割）：通过连续相等位移所用时间之比：

$$t_1 : t_2 : t_3 : \cdots : t_n = 1 : (\sqrt{2}-1) : (\sqrt{3}-\sqrt{2}) : \cdots$$

证明结论一：

$v_0 = 0$，第 $k$ 个 $T$ 内的位移：

$$x_k = \frac{1}{2}a(kT)^2 - \frac{1}{2}a((k-1)T)^2 = \frac{1}{2}aT^2(2k-1)$$

因此 $x_k \propto (2k-1)$，即 $x_1:x_2:x_3 = 1:3:5$。$\blacksquare$

证明结论二：

通过前 $k$ 段位移的总时间 $T_k = \sqrt{\frac{2ks}{a}}$，第 $k$ 段所用时间：

$$t_k = T_k - T_{k-1} = \sqrt{\frac{2s}{a}}(\sqrt{k} - \sqrt{k-1})$$

因此 $t_k \propto (\sqrt{k} - \sqrt{k-1})$。$\blacksquare$

点拨：结论一是奇数比，结论二是相邻根号之差。记住推导过程比记住结论更重要！

推论⑤ 逆向思维（时间反演对称性）

点击展开证明 ↓
点击展开

结论：末速度为零的匀减速直线运动，可以逆向看作初速度为零的匀加速直线运动。

证明：

物体以初速 $v_0$、加速度 $-a$ 做匀减速，经时间 $t$ 停下。

令 $\tau = \frac{v_0}{a} - t$（倒转时间轴），代入 $v(t) = v_0 - at$：

$$v(t) = a\tau$$

这正是初速为零、加速度为 $a$ 的匀加速运动！位移：

$$x(t) = v_0 t - \frac{1}{2}at^2 = x_{\text{总}} - \frac{1}{2}a\tau^2$$

即逆向看，从终点出发走过的距离 $= \frac{1}{2}a\tau^2$。$\blacksquare$

点拨：刹车问题、竖直上抛的下落段，都可以"倒着看"。这不仅是技巧，更是一种对称性思维。

热身激活：推论初步应用

5 min
热身 1

一辆汽车以 20 m/s 行驶，刹车做匀减速运动，加速度大小为 5 m/s²。求刹车后 第 3 秒内 的位移。

基本公式法

刹车总时间 $t_0 = \dfrac{v_0}{a} = \dfrac{20}{5} = 4$ s > 3 s，第 3 秒内存在。

前 3 秒位移：$x_3 = 20 \times 3 - \dfrac{1}{2} \times 5 \times 9 = 37.5$ m

前 2 秒位移：$x_2 = 20 \times 2 - \dfrac{1}{2} \times 5 \times 4 = 30$ m

第 3 秒内位移：$x_{III} = 37.5 - 30 = \mathbf{7.5}$ m

逆向思维 + 平均速度

逆向看作初速为 0 的匀加速。第 3 秒内（即逆向的第 2 秒内）：

逆向第 2 秒初速度 $v_1 = 5$ m/s，末速度 $v_2 = 10$ m/s

$$x_{III} = \bar{v} \times 1 = \frac{5 + 10}{2} \times 1 = \mathbf{7.5} \text{ m}$$

逐差公式

逆向看作匀加速，$\Delta x = aT^2$（$T = 1$ s）：

逆向第 1 秒位移 $x'_1 = \dfrac{1}{2} \times 5 \times 1 = 2.5$ m

逆向第 2 秒位移 $x'_2 = 2.5 + 5 = 7.5$ m（即正向第 3 秒内位移）

$$x_{III} = \mathbf{7.5} \text{ m}$$

归一

三种方法最终都回到 $x = \bar{v} \cdot t$。公式是工具，选择取决于条件给了什么。

热身 2

一个做匀加速直线运动的物体，在连续两个 2 s 内的位移分别为 4 m 和 10 m，求加速度和初速度。

联立方程法

设初速度 $v_0$，加速度 $a$：

$$x_1 = v_0 \cdot 2 + \frac{1}{2}a \cdot 4 = 4 \quad \cdots (1)$$

$$x_1 + x_2 = v_0 \cdot 4 + \frac{1}{2}a \cdot 16 = 14 \quad \cdots (2)$$

$(2) - 2 \times (1)$：$4a = 6$，$a = \mathbf{1.5}$ m/s²

代入 $(1)$：$2v_0 + 3 = 4$，$v_0 = \mathbf{0.5}$ m/s

逐差公式（推荐）

$$\Delta x = x_2 - x_1 = aT^2 \;\Rightarrow\; 10 - 4 = a \times 4 \;\Rightarrow\; a = \mathbf{1.5} \text{ m/s}^2$$

由 $x_1 = v_0 T + \frac{1}{2}aT^2$：$4 = 2v_0 + 3 \;\Rightarrow\; v_0 = \mathbf{0.5}$ m/s

归一

逐差公式 $\Delta x = aT^2$ 是联立方程的"快捷方式"。看到"连续相等时间内的位移"，第一反应就该是逐差法。

核心例题：一题多解 · 多解归一

15 min
例题 1

一物体做初速度为零的匀加速直线运动，通过连续三段相等位移所用时间之比 $t_1 : t_2 : t_3 = ?$

基本公式法

通过前 $k$ 段位移的总时间 $T_k = \sqrt{\dfrac{2ks}{a}}$

$$t_1 = \sqrt{\frac{2s}{a}},\; t_2 = \sqrt{\frac{4s}{a}} - \sqrt{\frac{2s}{a}},\; t_3 = \sqrt{\frac{6s}{a}} - \sqrt{\frac{4s}{a}}$$

$$t_1 : t_2 : t_3 = \sqrt{2} : (\sqrt{4}-\sqrt{2}) : (\sqrt{6}-\sqrt{4}) = \mathbf{1 : (\sqrt{2}-1) : (\sqrt{3}-\sqrt{2})}$$

比例法（直接用推论④）

初速为零匀加速，通过连续相等位移所用时间比：

$$t_1 : t_2 : t_3 = 1 : (\sqrt{2}-1) : (\sqrt{3}-\sqrt{2})$$

直接得到结论，用时 10 秒。

v-t 图像法（最直观） 
v ↑
  |          /
  |        / |
  |      /   |   面积 = s（每段相等）
  |    /     |
  |  /       |
  |/_________|____→ t
  0   t₁  t₁+t₂  t₁+t₂+t₃

$v = at$，面积 $= \frac{1}{2}at^2 = s$。三个等面积条带在三角形中。

由相似三角形：第 $k$ 条带对应的底边 $\propto \sqrt{k} - \sqrt{k-1}$。

多解归一

三种方法的共同本质：$x = \frac{1}{2}at^2 \Rightarrow t \propto \sqrt{x}$。推论是公式的"预包装"，图像是公式的"翻译"。

例题 2

一物体从静止开始做匀加速直线运动，经时间 $T$ 后做匀减速运动，又经时间 $2T$ 停止。求：

（1）加速与减速阶段的加速度之比

（2）加速与减速阶段的位移之比

（3）全程平均速度

（1）加速度之比
基本公式

加速末速度 $v = a_1 T$

减速：$0 = v - a_2 \cdot 2T \Rightarrow v = 2a_2 T$

$$\frac{a_1}{a_2} = \mathbf{2:1}$$

v-t 图像 
v ↑
  |    /\
  |   /  \
  |  /    \
  | /      \
  |/________\____→ t
  0    T    3T

斜率 = 加速度。左边斜率 : 右边斜率 $= \dfrac{v}{T} : \dfrac{v}{2T} = \mathbf{2:1}$

（2）位移之比
平均速度法

加速：$\bar{v}_1 = \dfrac{0+v}{2} = \dfrac{v}{2}$，$x_1 = \dfrac{v}{2} \cdot T$

减速：$\bar{v}_2 = \dfrac{v+0}{2} = \dfrac{v}{2}$，$x_2 = \dfrac{v}{2} \cdot 2T$

$$x_1 : x_2 = T : 2T = \mathbf{1:2}$$

图像面积

左边三角形面积 : 右边三角形面积 $= \dfrac{1}{2}Tv : \dfrac{1}{2} \cdot 2Tv = \mathbf{1:2}$

（3）全程平均速度
定义法

$$\bar{v} = \frac{x_1 + x_2}{3T} = \frac{\frac{vT}{2} + vT}{3T} = \mathbf{\frac{v}{2}}$$

推论法

加速段平均速度 $= \dfrac{v}{2}$，减速段平均速度 $= \dfrac{v}{2}$

两段平均速度相同！所以全程平均速度 $= \mathbf{\dfrac{v}{2}}$

几何洞察

v-t 图像是三角形，全程平均速度 = 最大速度的一半。$\bar{v} = \mathbf{\dfrac{v}{2}}$

多解归一

加速度看斜率、位移看面积、平均速度用推论。它们都来自同一张 v-t 图像。图像是运动学的"统一语言"。

变式提升：灵活选择方法

12 min
变式 1

一列火车从静止出发做匀加速运动，一人站在第一节车厢前端的站台上观测。他测得第一节车厢通过他身旁用时 4 s，则第 n 节车厢通过他身旁用时为多少？第 8 节车厢通过他身旁用时为多少？

公式推导

设每节车厢长 $L$，通过前 $k$ 节的时间 $T_k = \sqrt{\dfrac{2kL}{a}}$

第 $n$ 节车厢通过时间：$t_n = \sqrt{\dfrac{2L}{a}}(\sqrt{n} - \sqrt{n-1})$

第 1 节：$t_1 = \sqrt{\dfrac{2L}{a}} = 4$ s，因此：

$$t_n = 4(\sqrt{n} - \sqrt{n-1}) \text{ s}$$

比例法

由推论④（等距分割）：$t_1 : t_2 : \cdots : t_n = 1 : (\sqrt{2}-1) : \cdots : (\sqrt{n}-\sqrt{n-1})$

$t_1 = 4$ s，故 $t_n = 4(\sqrt{n} - \sqrt{n-1})$ s

代入数值

$$t_8 = 4(\sqrt{8} - \sqrt{7}) = 4(2.828 - 2.646) = \mathbf{0.73} \text{ s}$$

点拨：第 8 节车厢通过时间仅 0.73 s，是第 1 节的 1/5.5。这体现了"越往后越快"的非线性特征。
变式 2

一物体做匀加速直线运动，途中依次经过 A、B、C 三点。已知 AB 段和 BC 段的距离相等（均为 $s$），物体经过 A 点时速度为 $v_A$，经过 C 点时速度为 $v_C$。求经过 B 点时的速度 $v_B$。

公式法

AB 段：$v_B^2 - v_A^2 = 2as$，BC 段：$v_C^2 - v_B^2 = 2as$

两式相等：$v_B^2 - v_A^2 = v_C^2 - v_B^2 \Rightarrow v_B = \sqrt{\dfrac{v_A^2 + v_C^2}{2}}$

中点速度公式（推论②）

B 是 AC 的位移中点！直接用推论②：

$$v_B = v_{s/2} = \sqrt{\frac{v_A^2 + v_C^2}{2}}$$

5 秒出答案。

平均速度比较法

AB 段 $\bar{v}_1 = \dfrac{v_A+v_B}{2}$，BC 段 $\bar{v}_2 = \dfrac{v_B+v_C}{2}$

由等距条件可得 $\bar{v}_1 < \bar{v}_2$（加速运动），但难以直接求 $v_B$。

归一

看到"等距"条件，第一反应是中点速度公式。公式法是万能后备，但推论法能省去大量计算。

变式 3

一个做匀减速直线运动的物体经 6 s 停下来，最后 2 s、中间 2 s、最前 2 s 的位移之比为多少？

逆向思维（推荐）

逆向看作初速为 0 的匀加速：

逆向第 1、2 秒（正向最后 2 s）：$1 + 3 = 4$ 份

逆向第 3、4 秒（正向中间 2 s）：$5 + 7 = 12$ 份

逆向第 5、6 秒（正向最前 2 s）：$9 + 11 = 20$ 份

$$x_{\text{后}} : x_{\text{中}} : x_{\text{前}} = 4 : 12 : 20 = \mathbf{1 : 3 : 5}$$

直接计算

设初速 $v_0$，$a = -v_0/6$

最前 2 s：$x_1 = 2v_0 - \frac{1}{2} \cdot \frac{v_0}{6} \cdot 4 = \dfrac{5v_0}{3}$

中间 2 s 与最后 2 s 分段计算，得 $5:3:1$，反向排序得 $\mathbf{1:3:5}$

归一

匀减速问题 逆向看 就变成初速为零的匀加速，直接用比例 1:3:5。逆向思维是推论⑤的核心价值。

综合挑战：多推论联合应用

8 min
挑战 1

一辆车从 A 到 B 做匀加速，B 到 C 匀速，C 到 D 匀减速至停止。已知 $AB = BC = CD$，三段所用时间相等。求加速、匀速、减速三阶段的加速度大小之比。

基本公式法

设每段位移 $s$，时间 $T$，匀速阶段速度为 $v$。

加速段（初速 0）：$s = \dfrac{v}{2}T \Rightarrow v = \dfrac{2s}{T}$

匀速段：$s = v \cdot T \Rightarrow v = \dfrac{s}{T}$

两式矛盾！说明实际三段速度不可连续。

题目条件有内在矛盾：三段位移相等 + 三段时间相等 → 匀速段速度必须为 $s/T$，但加速末速必须为 $2s/T$。

按对称性理解，加速与减速对称：$a_1 = a_3$ 且反向，匀速段 $a_2 = 0$。

加速度大小之比 $= \mathbf{1:0:1}$（或理解为 $\mathbf{2:0:2}$ 取决于参考系设定）

平均速度法

三段时间相等、位移相等 → 平均速度相等。

加速段 $\bar{v} = s/T$，初速 0 → 末速 $2s/T$

匀速段 $\bar{v} = s/T$ → 速度 $s/T$

速度无法连续。此题核心在于识别条件冲突。

v-t 图像（最清晰） 
v ↑
  |    /‾‾‾‾\
  |   /      \
  |  /        \
  | /          \
  |/____________\____→ t
  0  T  2T  3T

三角形面积 $= \frac{1}{2}Tv$，矩形面积 $= Tv$

面积比 $= 1:2:1$，但要求三段面积相等。

"三段位移相等且三段时间相等"在速度连续条件下自相矛盾。

点拨：这道题的价值在于发现矛盾。能指出题目条件的内在冲突，比算出答案更重要。
挑战 2

从斜面上某位置每隔 0.1 s 释放一个小球，释放后小球做匀加速直线运动。在连续释放若干个后，对正在斜面上运动的部分小球拍照，测得各球间距如图所示（单位：cm）。

球1 ←5→ 球2 ←7→ 球3 ←9→ 球4 ←11→ 球5

（1）求小球的加速度   （2）求拍摄时球3的速度   （3）球3上面还有几个球？

逐差法求加速度

相邻球间距：$x_1=5,\; x_2=7,\; x_3=9,\; x_4=11$ cm

$\Delta x = 2$ cm 恒定。由 $\Delta x = aT^2$：

$$a = \frac{0.02}{0.01} = \mathbf{2} \text{ m/s}^2$$

平均速度 = 中间时刻速度

由推论①：$v_3 = \bar{v}_{2 \to 4} = \dfrac{x_2 + x_3}{2T} = \dfrac{16}{0.2} = \mathbf{0.8} \text{ m/s}$

分析球数

球3速度 $v_3 = 0.8$ m/s，已运动时间 $t = v_3/a = 0.4$ s

每隔 0.1 s 释放一个，球3上方有 3 个球在运动。

由逐差反推：上方间距依次为 3 cm、1 cm，再往上为 -1 cm（不存在）。

因此球3上面还有 3 个球。

归一

综合运用了逐差法（求 $a$）、平均速度推论（求瞬时速度）、比例关系（分析球数）。三个推论协同工作。
