频闪观测转动圆盘

一次闪光 = 一张快照。当闪光频率与转速相差很小时，快照之间的"错位"会让转盘看起来慢慢地倒着转。先动手把参数拉一拉，再回头看推导。

原题

如图 6-9 所示，带有一白点的黑色圆盘，绕过其中心且垂直于盘面的轴沿顺时针方向匀速转动，转速 n = 20 r/s。 在暗室中用每秒闪光 21 次的频闪光源照射圆盘，求观察到白点转动的方向和转动的周期。
真实转向：顺时针 转速 n = 20 r/s 频闪频率 f = 21 次/秒 环境：暗室

动手实验：把参数拉一拉，亲眼看看白点怎么"倒转"

三步法解本题

1

两次闪光之间，圆盘转了多少？

频闪周期 Δt = 1/f = 1/21 s ≈ 0.0476 s。

这段时间圆盘转过的圈数 r = n·Δt = 20/21 ≈ 0.952 圈（顺时针），

换成角度就是 r × 360° ≈ 342.9°（顺时针）——差一点点就是整整一圈。

2

把"多出来的接近一整圈"折掉

眼睛每次只看到一张快照，它分不清白点是转过了 342.9° 还是 -17.1°（二者只差整整一圈，终点位置相同）。

习惯上取"转得最少"的那个：342.9° - 360° = -17.1°，即视觉上白点每次闪光逆时针移动 360°/21 = 1/21 圈。

3

定方向、算周期

方向：每闪一次白点逆时针挪 1/21 圈，所以观察到白点逆时针转动。

周期：逆时针挪满一整圈需要 21 次闪光，用时 T = 21 × (1/21) s = 1 s。

也可直接用公式：T = 1/(f - n) = 1/(21 - 20) s = 1 s。

答：观察到白点沿 逆时针 方向转动，转动周期为 1 s。

这类题的通用方法（一套公式打天下）

设圆盘真实转速为 n（r/s，方向已知），频闪频率为 f（次/s），则：

① r = n / f ← 每闪一次，圆盘转过的圈数
② k = 最接近 r 的整数 ← 把"整数圈"折掉
③ n' = n - k·f ← 等效（视觉）转速，带符号，单位 r/s
④ T' = 1 / |n'| ← 观察到的周期，单位 s
等效转速 n' 的情况观察到的现象典型例子
n' = 0白点看起来完全静止不动n=20, f=10 → k=2
n' 与 n 同号与真实方向相同（看起来正常正转）n=22, f=21 → 顺时针，T'=1 s
n' 与 n 异号与真实方向相反（看起来倒转）n=20, f=21 → 逆时针，T'=1 s
|r - k| ≈ 0.5半圈临界：两个亮点交替闪，方向不可判定n=20, f=40

四个高频易错点

  • 别只看"20 圈"和"21 次"就断言"太快看不清"。20 与 21 只差 1，恰好构成"低频差拍"，肉眼能清清楚楚地看到 1 r/s 的慢速反向转动——这正是本题的巧妙之处。
  • 别忘了"折整数圈"。当 r = n/f 大于 1 时要先减掉整数圈。例如 n = 50 r/s、f = 21 次/s 时 r ≈ 2.38，等效转速是 50 - 2×21 = 8 r/s（顺时针），而不是 50 - 21 = 29 r/s。页面里点一下 n=50 那个预设，能直接看出差别。
  • 注意"半圈临界"。当 n/f 的小数部分约为 0.5 时（如 n = 20 r/s、f = 40 次/s），相邻两张快照相差半圈，白点在两个直径相对的位置交替出现，看起来像两个亮点轮流闪，此时没有确定的转动方向。
  • 单位要统一。若转速给的是 r/min（转/分），先除以 60 化成 r/s 再代入公式；另外"每秒闪光 f 次"指的是闪光频率，闪光周期是 1/f。

变式训练（点标题展开答案）

变式 1　把频闪频率改为 19 次/秒，其他条件不变，观察到白点向哪个方向转？周期多大？

r = n/f = 20/19 ≈ 1.053 圈，取 k = 1。

等效转速 n' = n - k·f = 20 - 19 = 1 r/s，为正，说明与真实方向相同。

答：白点顺时针转动，周期 T' = 1/1 = 1 s。

对比原题：f 只从 21 变到 19，方向立刻反过来。可见"看到的方向"取决于 n 与 k·f 谁大谁小，而不是单纯看 n 和 f 谁大谁小。

变式 2　把圆盘转速改为 22 r/s（仍顺时针），频闪仍为 21 次/秒，结果如何？

r = 22/21 ≈ 1.048 圈，取 k = 1。

n' = 22 - 21 = 1 r/s > 0，与真实方向同号。

答：白点顺时针转动（正转），周期 T' = 1 s。

n 比 k·f 大一点 → 正转；n 比 k·f 小一点 → 倒转。这就是"车轮倒转"现象的分界线。

变式 3　若频闪频率改为 40 次/秒，转速仍为 20 r/s，能看到什么？

r = 20/40 = 0.5 圈，正好是半圈。

两次闪光之间白点转过半圈，于是白点在两个直径相对的位置上交替出现，看起来像两个亮点轮流闪。

答：此时 n' = ±20 r/s，"正转"与"倒转"在视觉上完全等价，无法判定出确定的转动方向。

在页面里点"f=40（半圈临界）"预设，可以亲眼看到两个亮点交替出现的效果。

变式 4　若转速为 20 r/s、频闪频率改为 10 次/秒，又看到什么？

r = 20/10 = 2 圈，取 k = 2，n' = 20 - 2×10 = 0。

每次闪光时白点都恰好转回原来的位置。

答：白点看起来静止不动，与真实转向无关。

延伸：如果圆盘上不止一个白点，而是画成有花纹的图案，那"静止"就可能被打破——利用盘上多个标记可以消除这种多解性，这也是工程上用"打标记法"测转速的思路。

一句话总结

频闪观察，本质是把连续转动切成一串离散快照。每两次快照之间圆盘转过的圈数 r = n/f 里，整数圈是"看不见的"， 只有剩下的那一点点（r 减去最近的整数）才是白点看起来的位移——它决定了观察到的方向，而补满这一圈所需的时间就是观察到的周期。
