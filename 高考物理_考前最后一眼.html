🌡️气体实验定律 · 完整版
三大定律
玻意耳等温 pV=C → p₁V₁=p₂V₂（温度不变）
查理等容 p/T=C → p₁/T₁=p₂/T₂（体积不变）
盖-吕萨克等压 V/T=C → V₁/T₁=V₂/T₂（压强不变）
理想气体pV=nRT，R=8.31，T用开尔文（+273！）
★三个定律中T都必须用开尔文（热力学温标）
微观解释 气体压强的两个公式 · 每个字母详解
—公式①：p = ⅓ n·m·v̄²
其中：
n = 分子数密度（单位：个/m³），n=N/V，即单位体积内的分子个数
m = 一个气体分子的质量（单位：kg），不是摩尔质量！
v̄² = 分子速率平方的平均值（单位：m²/s²）
v̄² ≠ (v̄)²！先平方再平均，不是先平均再平方
√v̄²叫做方均根速率，是分子热运动剧烈程度的度量
—公式②：p = ⅔ n·Ēₖ（更常用、更简洁）
其中：
Ēₖ = 分子的平均动能（单位：J）
Ēₖ = ½ m·v̄²（分子的平均平动动能）
代入公式①：p = ⅓ n·m·v̄² = ⅔ n·(½ m·v̄²) = ⅔ n·Ēₖ
两个公式本质是等价的
—温度与平均动能的关系：Ēₖ = ³⁄₂ kT
其中：
k = 玻尔兹曼常量 = 1.38×10⁻²³ J/K
T = 热力学温度（开尔文K），T = t℃ + 273
所以 p = ⅔ n·³⁄₂ kT = n k T（理想气体的另一种状态方程！）
→温度↑ → Ēₖ↑ → p↑（体积不变时，分子撞壁更猛）
→体积↓ → n↑ → p↑（温度不变时，单位体积分子更多→撞壁更频繁）
p-V图像 面积 = 做功  |  绝热过程 Q=0
•p-V图曲线下面积 = 气体做的功
•V增大（向右）→ 气体对外做功（W<0，输出能量）
•V减小（向左）→ 外界对气体做功（W>0，获得能量）
•等温线是双曲线（pV=C），曲线越高、跨度越大→做功越多
•p-T图：等容线过原点，斜率∝1/V
•V-T图：等压线过原点，斜率∝1/p
•图像题步骤：先确定谁不变→再看变化方向→列方程
绝热过程Q=0，ΔU = W
•关键词："快速"、"很短"、"来不及传热"→绝热
•压缩→W>0→ΔU>0→温度升高
•膨胀→W<0→ΔU<0→温度降低
•p-V图上绝热线比等温线更陡
•绝热方程：pV^γ = C，γ=cₚ/cᵥ（空气γ≈1.4）
液柱 · 活塞 · 变质量
液柱p₀+ρgh = pᵢ，h是竖直高度（不是斜管长度！）
活塞pS = p₀S + mg（画受力分析图！）
变质量不能用pV/T=C，用克拉珀龙 pV=nRT
⚛️原子核物理 · 详细版
核力与核结构
•核力：原子核内质子与质子、质子与中子、中子与中子之间的强相互作用
— 核力是短程力，只在相邻核子间起作用（~10⁻¹⁵m范围）
— 核力远大于库仑斥力（质子之间的电磁斥力），所以能把核子紧紧束缚在一起
•原子核的组成：Z个质子 + (A-Z)个中子，统称核子
— ₁¹H：1个质子，0个中子（最简单的原子核）
— ₉₂²³⁵U：92个质子，143个中子（铀-235）
质量亏损 & 比结合能 ★★★必考
—质量亏损 Δm：核子结合成原子核后，质量减少的那一部分
Δm = Z·mₚ + (A-Z)·mₙ - m_核
其中：Z=质子数，mₚ=质子质量，mₙ=中子质量，m_核=原子核质量
注意：题目给的通常是原子质量（含电子），用时要减去Z个电子的质量
—结合能 E_b：核子结合成原子核时释放的能量
E_b = Δm·c²（爱因斯坦质能方程）
c=3×10⁸m/s，Δm单位kg→E单位J；Δm单位u→E单位MeV
1u = 1.66×10⁻²⁷kg，1u对应931.5MeV的能量
—比结合能（平均结合能）：结合能÷核子数
比结合能 = E_b / A（A=质量数=核子总数）
比结合能越大 → 原子核越稳定（把核子拆散所需的平均能量越大）
—比结合能曲线（铁Fe附近最高）
— 中等质量核（A≈50~60）的比结合能最大，约8.7MeV/核子
— 轻核（如²H，³He）的比结合能小，容易发生聚变
— 重核（如²³⁵U）的比结合能也较小，容易发生裂变
— 无论是轻核聚变还是重核裂变，都是从比结合能小的核→比结合能大的核
— → 都释放能量（因为生成物更稳定了）
核裂变 · 核聚变
裂变重核分裂成中等质量核，例：₉₂²³⁵U+₀¹n→₅₆¹⁴⁴Ba+₃₆⁸⁹Kr+3₀¹n
— 链式反应：每次裂变产生2-3个中子，每个中子又能引发新的裂变
— 链式反应的条件：铀块体积≥临界体积
— 应用：原子弹（瞬间释放）、核电站（可控链式反应）
聚变轻核结合成较重核，例：₁²H+₁³H→₂⁴He+₀¹n
— 热核反应：需要极高温度（上亿度）才能克服核间库仑斥力
— 太阳内部就是持续的聚变反应（质子-质子链）
— 应用：氢弹、受控热核聚变（人造太阳，尚未商用）
★聚变释放的能量比裂变大得多（同质量下）
衰变 & 核反应专题
α衰变质量数-4，电荷数-2   ₈₄²¹⁰Po→₈₂²⁰⁶Pb+₂⁴He
β衰变中子→质子+电子   ₉₂²³⁸U→₉₃²³⁸Np+₋₁⁰e+ν̄ₑ
γ衰变激发态→基态，放出光子（伴随α/β衰变，不单独发生）
半衰期N=N₀(½)^(t/T)，τ=ln2/λ   与外界条件无关（温度/压强不影响）
人工核反应₄⁹Be+₂⁴He→₆¹²C+₀¹n（α粒子轰击铍→发现中子）
质能方程E=mc²   1u=931.5MeV   计算步骤：
①求质量亏损Δm   ②E=Δm×931.5MeV
光电效应 & 能级
光电效应hν = W₀ + Eₖ（爱因斯坦方程）
— h=6.63×10⁻³⁴J·s   ν=入射光频率   W₀=逸出功（逸出金属所需最小能量）
— 截止频率：ν₀=W₀/h——低于这个频率，再强的光也打不出电子
— 遏止电压：eU₀ = Eₖ → 通过U₀可以测出光电子最大动能
— 光强↑→光子数↑→光电子数↑→饱和电流↑（但不影响每个光电子的动能）
— 频率↑→每个光子能量↑→光电子动能↑→遏止电压↑
能级跃迁Eₙ = -13.6/n² eV  （n=1时E₁=-13.6eV）
— 从n跃迁到m（n>m）：ΔE=Eₙ-Eₘ=hν，放出一个光子
— 从n能级向下跃迁：最多发出C²ₙ=n(n-1)/2种光子
— 电离：给电子能量≥|Eₙ|，电子脱离原子→离子
🔦光学 · 详细版
光的本质 · 电磁波谱
•光的波粒二象性：光既有波动性（干涉、衍射、偏振）又有粒子性（光电效应）
•电磁波谱（频率从低到高，波长从长到短）：
无线电波 → 微波 → 红外线 → 可见光（红橙黄绿蓝靛紫）→ 紫外线 → X射线 → γ射线
— 红光：频率最小、波长最长、n最小、在同介质中速度最大
— 紫光：频率最大、波长最短、n最大、在同介质中速度最小
•真空中所有电磁波速度相同：c = 3×10⁸ m/s
折射 · 全反射 · 色散
折射n₁sinθ₁ = n₂sinθ₂（θ是光线与法线的夹角，不是与界面的）
— n = c/v（光在真空中的速度÷在介质中的速度）
— 频率↑→n↑→在介质中速度v↓→折射越明显
— 光路可逆：从A到B的路径，从B到A也是这条路径
全反射条件：①光从光密→光疏（n大→n小）②入射角≥临界角C
— sinC = 1/n（n是光密介质的折射率）
— 应用：光纤通信（光导纤维）、全反射棱镜
色散白光通过三棱镜→红到紫散开（紫光偏折最大，红光最小）
干涉 · 衍射 · 偏振
双缝干涉Δx = λL/d（λ=波长，L=缝到屏，d=双缝间距）
— 明纹条件：路程差Δr = kλ  （k=0,1,2…）中央是明纹
— 暗纹条件：路程差Δr = (2k+1)λ/2
— 白光→中央白色，两边彩色（内紫外红）
— 波长↑→条纹间距↑；缝距d↓→条纹间距↑
薄膜干涉光在薄膜上下表面反射后叠加（肥皂泡彩色条纹、油膜）
衍射光绕过障碍物继续传播。明显衍射的条件：缝宽/障碍物≤波长
偏振光波是横波，偏振片只让特定方向的光通过
— 自然光：各方向振动都有（太阳光、灯光）
— 偏振光：只在特定方向振动（经过偏振片后的光）
— 马吕斯定律：I = I₀·cos²θ（θ=两偏振片透光轴间的夹角）
— 应用：偏光眼镜（防眩光）、3D电影、液晶显示
— 横波才有偏振现象→证明光是横波
〰️机械振动与波 · 详细版
简谐振动 · 能量 · 图像
基本公式x = A·sin(ωt+φ₀)  v = Aω·cos(ωt+φ₀)
— A=振幅，ω=2π/T=2πf=角频率，φ₀=初相
弹簧振子T = 2π√(m/k)——与振幅A无关！
单摆T = 2π√(L/g)——与振幅、摆球质量无关！
— 适用条件：摆角<5°（小角度近似sinθ≈θ）
—简谐运动的能量：E = ½kA²
— 总能量与振幅的平方成正比（A越大→能量越大）
— 平衡位置：动能最大（½mv²），势能最小（0）
— 最大位移处：动能=0，势能最大（½kA²）
— 理想简谐振动：系统机械能守恒（动能+势能=常数）
阻尼振动振幅逐渐减小的振动（能量逐渐耗散）
受迫振动在周期性驱动力作用下的振动，稳定后频率=驱动力频率
共振驱动力频率 = 系统固有频率时，振幅达到最大
— 应用：乐器、桥梁设计要避开共振频率
机械波 · 干涉 · 衍射 · 多普勒
波速v = λf = λ/T——波速由介质决定，频率由波源决定
— 波从一种介质进入另一种介质：频率f不变，v和λ改变
波的传播"上下坡法"：上坡点向下振，下坡点向上振（横波）
— 质点只在平衡位置附近振动，不随波迁移
—波的叠加原理：两列波相遇时，位移=各自位移的矢量和
干涉条件：两列波频率相同、相位差恒定
— 加强点：路程差Δr = kλ（k=0,±1,±2…）→振幅最大
— 减弱点：路程差Δr = (2k+1)λ/2 → 振幅最小（可能为0）
— 干涉是波的特有现象，证明波具有波动性
衍射波绕过障碍物继续传播。障碍物尺寸≈波长时衍射最明显
驻波两列振幅相同、方向相反的波叠加（波节=不动点，波腹=振动最大点）
多普勒波源靠近→接收频率↑（音调变高）；远离→频率↓（变低）
— 应用：雷达测速、彩超、天文红移
💥动量 · 碰撞
动量定理Ft = Δp = mv₂ - mv₁——冲量=动量变化
动量守恒m₁v₁+m₂v₂ = m₁v₁'+m₂v₂'——合外力为0时用
碰撞弹性→动量+机械能都守恒；非弹性→只动量守恒
人船m₁x₁ = m₂x₂，x₁+x₂=L
