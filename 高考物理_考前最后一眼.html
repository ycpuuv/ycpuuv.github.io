🔬实验仪器读数 · 有效数字（必考！）
📏 刻度尺 / 毫米刻度尺
•最小分度 1mm → 估读到 0.1mm（即读到毫米小数点后1位）
•例：3.25cm（3.2cm是准确值，0.05cm是估读值）
⏱ 游标卡尺（不估读！）
•10分度：精度0.1mm，读数=主尺(mm)+游标对齐格数×0.1
•20分度：精度0.05mm，读数=主尺(mm)+游标对齐格数×0.05
•50分度：精度0.02mm，读数=主尺(mm)+游标对齐格数×0.02
•关键：看游标上哪条线与主尺对齐，不是看数字！最后一位0不能省略
•例：50分度，主尺11mm，游标第24条对齐 → 11+24×0.02=11.48mm
🔩 螺旋测微器（千分尺）
•精度 0.01mm，估读到0.001mm（三位小数）
•读数=主尺(mm)+半毫米刻度(0.5mm)+可动刻度×0.01
•注意：半毫米刻度线有没有露出！经常有人漏了0.5mm
•例：主尺5.5露出，可动刻度25.0 → 5.5+25.0×0.01=5.750mm
⚡ 电流表 / 电压表
•3A量程：分度值0.1A，估读到0.01A
•0.6A量程：分度值0.02A，估读到0.01A
•3V量程：分度值0.1V，估读到0.01V
•15V量程：分度值0.5V，估读到0.1V
•规则：看分度值是1、0.1、0.01 → 估读到下一位；分度值是2、0.5等 → 估读到本位
⏲ 打点计时器 / 秒表
•打点计时器：50Hz → 0.02s/点，中间隔4个点=0.1s
•秒表：分度值通常0.1s，估读或不估读看题目要求
•有效数字：结果保留几位看题目要求，一般保留2-3位
•读数的最后一位0不能省略（2.50cm ≠ 2.5cm，精度不同）
🌡️气体实验定律
公式 三个基本定律
玻意耳等温：pV = C  →  p₁V₁ = p₂V₂
查理等容：p/T = C  →  p₁/T₁ = p₂/T₂
盖-吕萨克等压：V/T = C  →  V₁/T₁ = V₂/T₂
理想气体pV = nRT  （R=8.31 J/mol·K，T用开尔文！）
微观 压强的微观解释
①p = (1/3)n·mv̄²（n:分子密度，m:分子质量，v̄²:速度平方平均）
②p = (2/3)n·Ēₖ（Ēₖ:分子平均动能）——更常用！
→温度T越高 → 平均动能Ēₖ越大 → 压强p越大（体积不变时）
→体积V减小 → 分子密度n增大 → 压强p增大（温度不变时）
•微观本质：压强=分子对器壁碰撞的平均冲击力×单位时间碰撞次数
图像 p-V图、p-T图、V-T图
•p-V图：等温线是双曲线（pV=C），曲线下方围成的面积=气体对外做功
— 体积增大→气体对外做功（W<0，系统对外输出能量）
— 体积减小→外界对气体做功（W>0，系统获得能量）
— 面积大小对比：曲线越高（p越大）、跨度越大，做功越多
•p-T图：等容线是过原点的直线（斜率∝1/V）
•V-T图：等压线是过原点的直线（斜率∝1/p）
•注意：原点处T=0K（-273℃），画图时要把直线延长到原点附近
绝热 做工时间很短 → 绝热过程
•绝热过程：Q=0，系统与外界无热交换
— 常见场景：气体被快速压缩/膨胀（打气筒、内燃机）
— 关键词："快速"、"很短时间"、"来不及传热" → 按绝热处理
•热力学第一定律：ΔU = Q + W  （Q是吸热，W是做功）
— 绝热 Q=0 → ΔU = W（做功完全转化为内能变化）
— 压缩气体 → W>0 → ΔU>0 → 温度升高
— 气体膨胀 → W<0 → ΔU<0 → 温度降低
•绝热线比等温线更陡：在p-V图上，同一气体绝热线斜率大于等温线
•pVᵞ = C（γ=cp/cv，空气γ≈1.4）——绝热过程方程
模型 液柱/活塞/变质量气体
液柱压强相等：p₀ + ρgh = pᵢ（注意h是竖直高度，不是斜长）
活塞平衡：p·S = p₀·S + mg（受力分析！）
变质量理想气体状态方程不能用，用克拉珀龙方程：pV = nRT
⚛️原子物理
核反应 四种衰变
α衰变₈₄²¹⁰Po → ₈₂²⁰⁶Pb + ₂⁴He  （质量数减4，电荷数减2）
β衰变₉₂²³⁸U → ₉₃²³⁸Np + ₋₁⁰e + ν̄ₑ  （一个中子变质子+电子）
γ衰变伴随α或β衰变，放出光子（原子核从激发态→基态）
半衰期τ = ln2/λ，N = N₀(½)^(t/T)，半衰期与外界条件无关
光电效应 爱因斯坦方程
•hν = W₀ + Eₖ（光子能量=逸出功+光电子动能）
•截止频率：ν₀ = W₀/h    ＜ν₀怎么照都没光电子
•I-U图：饱和电流(光强)→遏止电压(频率)→反向截止
能级 氢原子跃迁
•Eₙ = -13.6/n² eV   基态E₁=-13.6eV
•从n→m：ΔE = Eₙ - Eₘ = hν（放出一个光子）
•能发射的光子种类：Cₙ² = n(n-1)/2（从n能级向下跃迁）
🔦光学
折射 折射定律 + 全反射
•n₁sinθ₁ = n₂sinθ₂  （注意光路可逆）
•全反射条件：光从光密→光疏，且入射角≥临界角C
•sinC = 1/n  （n是光密介质折射率）
•n = c/v   频率越高→n越大→在介质中速度越慢
干涉 双缝干涉 + 薄膜干涉
•明纹：Δx = kλL/d    暗纹：Δx = (2k+1)λL/2d
•条纹间距：Δx = λL/d（d是缝距，L是缝到屏距）
•用白光→中央白色，两边彩色（紫到红）
衍射 明显衍射条件
•缝宽/障碍物尺寸 ≤ 波长 才明显衍射
•光的波长越短（紫光），衍射越不明显
〰️机械振动与波
简谐振动 基本公式
•x = A·sin(ωt+φ₀)   v = Aω·cos(ωt+φ₀)
•弹簧振子：T = 2π√(m/k)  （与振幅无关！）
•单摆：T = 2π√(L/g)  （与振幅、摆球质量无关！）
•回复力：F = -kx（注意负号，方向与位移相反）
机械波 波速 · 波长 · 频率
•v = λf = λ/T（波速由介质决定，频率由波源决定）
•波传到各质点：振动方向与传播方向的关系（横波⊥，纵波∥）
•判断波的传播方向与质点振动方向的关系："上下坡法"或"同侧法"
•多普勒效应：波源靠近→频率变高（音调变高），远离→频率变低
💥动量 · 碰撞
公式 动量守恒 + 冲量定理
•动量定理：Ft = Δp = mv₂ - mv₁（冲量=动量变化）
•动量守恒：m₁v₁+m₂v₂ = m₁v₁'+m₂v₂'（合外力为零时用）
•碰撞类型：弹性的→动量守恒+机械能守恒；非弹性的→动量守恒+机械能不守恒
•人船模型：m₁x₁ = m₂x₂（人是m₁，船是m₂，x₁+x₂=L）

⏰ 时间分配建议
0-30min选择题（单选+多选），平均2min/题，不会的先跳过
30-50min实验题，先写简单的读数/读数类，再写分析类

✏️ 大题得分法则
①写公式就有分！不会算也要把相关公式写上去，每题第一问通常代公式就能做
②设未知量要写"设……"，并把已知条件标在图上
③分步计算，中间结果写清楚（即使最后算错也有步骤分）
④答案带单位，用科学计数法保持有效数字一致
⑤不会做的题：能把哪个量求出来就求出来，写上去
