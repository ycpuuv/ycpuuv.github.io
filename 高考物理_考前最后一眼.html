📏 刻度尺  |  ⏱ 打点计时器  |  ⏲ 秒表
•毫米刻度尺：分度1mm，估读到0.1mm（mm小数点后1位）
•例：3.25cm（3.2准确+0.05估读）
•打点计时器：50Hz→0.02s/点，间隔4个点=0.1s
•秒表：分度值通常0.1s
🔩 游标卡尺（不估读！）
10分度精度0.1mm：读数=主尺+游标对齐格数×0.1
20分度精度0.05mm：读数=主尺+游标对齐格数×0.05
50分度精度0.02mm：读数=主尺+游标对齐格数×0.02
★看哪条线对齐！0不能省！ 例：50分度，主尺11mm，24条对齐→11.48mm
🔩 螺旋测微器（千分尺）
•精度0.01mm，估读到0.001mm（三位小数！）
•读数=主尺+半毫米刻度(0.5)+可动刻度×0.01
★注意半毫米线有没有露出！经常有人漏了+0.5
•例：主尺5.5露出，可动25.0→5.5+25.0×0.01=5.750mm
⚡ 电流表 / 电压表 读数规则
•分度值是1/0.1/0.01→估读到下一位
•分度值是2/5/0.5/0.2→估读到本位

🎯蒙题技巧 · 不会做怎么选
选择题 选项特征
•三长一短选最短，三短一长选最长——有一定的统计学依据
•量纲法：看选项的单位对不对！比方说求力，选项里出现m/s的直接排除
•特殊值法：取θ=0°或θ=90°代入，看哪个选项结果合理
•极端法：让某个参数→0或→∞，看哪个选项符合物理直觉
•两个选项长得很像→答案大概率在其中一个
•四个选项中有两个意思相反→答案大概率在这两个之中
•"以上都不对"当答案的概率很低，别轻易选
多选题 策略
•选1个得1分，选错全扣3分——不确定的打死不选
•能确定2个对的→就选2个，不贪第三個
•一般情况下多选题选2个的占大多数，选3个的较少
•实在不会→选那个最长的选项+一个最短的（不保证对但比不选强）

🌡️气体实验定律 · 完整版
三大定律
玻意耳等温 pV=C → p₁V₁=p₂V₂（温度不变）
查理等容 p/T=C → p₁/T₁=p₂/T₂（体积不变）
盖-吕萨克等压 V/T=C → V₁/T₁=V₂/T₂（压强不变）
理想气体pV=nRT，R=8.31 J/(mol·K)，T用开尔文！+273
微观解释 压强的两个表达式
①p = ⅓ n·mv̄²（n：分子数密度，m：分子质量，v̄²：速度平方平均）
②p = ⅔ n·Ēₖ（更常用！Ēₖ：分子平均动能）
→温度T↑ → Ēₖ↑ → p↑（V不变时）
→体积V↓ → n↑ → p↑（T不变时）
→本质：压强=分子对器壁碰撞的平均冲击力×单位时间碰撞次数
p-V图像 围成的面积 = 做功
•曲线下方围成的面积 = 气体对外做功（或外界对气体做功）
•体积增大（向右）→ W<0，气体对外输出能量
•体积减小（向左）→ W>0，外界对气体做功
•等温线是双曲线（pV=C），曲线越高、跨度越大→做功越多
p-T图等容线过原点，斜率∝1/V
V-T图等压线过原点，斜率∝1/p
•图像题：先确定哪个量不变，再看变化方向
绝热过程 做工时间很短 → Q=0
•ΔU = W（Q=0，做功完全转化为内能变化）
•关键词："快速"、"很短时间"、"来不及传热"→按绝热处理
•压缩→W>0→ΔU>0→温度升高
•膨胀→W<0→ΔU<0→温度降低
•在p-V图上绝热线比等温线更陡
•绝热过程方程：pV^γ = C（γ=cₚ/cᵥ，空气γ≈1.4）
液柱 · 活塞 · 变质量
液柱p₀+ρgh = pᵢ（h是竖直高度！不是斜长！）
活塞pS = p₀S + mg（受力分析画图！）
变质量不能用pV/T=C，用克拉珀龙 pV=nRT
⚛️原子物理
α衰变质量数-4，电荷数-2 → ₈₄²¹⁰Po→₈₂²⁰⁶Pb+₂⁴He
β衰变中子→质子+电子 → ₉₂²³⁸U→₉₃²³⁸Np+₋₁⁰e+ν̄ₑ
γ衰变激发态→基态，放出光子（伴随α/β衰变）
半衰期N=N₀(½)^(t/T)，与外界条件无关！
光电效应hν = W₀ + Eₖ，截止频率ν₀=W₀/h
能级跃迁Eₙ=-13.6/n² eV，ΔE=hν，光子数=Cₙ²=n(n-1)/2
🔦光学
折射n₁sinθ₁=n₂sinθ₂，光路可逆
全反射光密→光疏，i≥C，sinC=1/n
双缝干涉Δx=λL/d（明纹Δx=kλL/d，暗纹Δx=(2k+1)λL/2d）
衍射缝宽/障碍物≤波长才明显
〰️机械振动与波
弹簧振子T=2π√(m/k)，与振幅无关
单摆T=2π√(L/g)，与振幅、质量无关
波速v=λf=λ/T，波速由介质决定，频率由波源决定
振动方向"上下坡法"或"同侧法"判断
多普勒靠近→频率↑，远离→频率↓
💥动量 · 碰撞
动量定理Ft=Δp=mv₂-mv₁（冲量=动量变化）
动量守恒m₁v₁+m₂v₂=m₁v₁'+m₂v₂'（合外力=0时用）
弹性碰撞动量守恒+机械能守恒；非弹性→动量守恒
人船m₁x₁=m₂x₂，x₁+x₂=L
