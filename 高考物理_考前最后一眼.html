🌡️气体实验定律 · 热力学必考1道
🧊 核心公式 闭眼能写
PV = nRT   →   PV/T = C
等温：P₁V₁ = P₂V₂  |  等容：P₁/T₁ = P₂/T₂  |  等压：V₁/T₁ = V₂/T₂
热力学第一定律：ΔU = Q + W
ΔU↑吸热升温   Q>0吸热   W>0外界压缩气体
🔥 气体考点·必杀技
①液柱/活塞问题——关键找压强关系！活塞内外侧压强相等，液柱底部压强=大气压+ρgh。画受力分析图！
②变质量气体——用理想气体状态方程推导，充气/漏气问题把前后状态写清楚再用
③p-V图——等温线是双曲线（PV=常数），等容线竖直，等压线水平。图线围的面积 = 做功大小
④分子动理论——温度=分子平均动能的标志，体积=分子间距离→影响分子势能
⚡ 陷阱："缓慢"=可视为等温过程（热交换充分）；"绝热"=Q=0，用ΔU=W；"理想气体"=忽略分子间作用力，内能只与温度有关
📌 典型模型·手到擒来
模型突破口注意
U形管两边液面等高→压强相等高度差=ΔP
气缸活塞受力平衡求压强别忘了大气压
充气/打气总摩尔数不变分状态列方程
漏气/放气剩余气体+漏出气体总质量守恒
⚛️原子物理 · 核反应必考1~2道
🧬 必记衰变类型 选择常考
衰变通式本质穿透力
α衰变ₐᵐX → ₐ₋₂ᵐ⁻⁴Y + ₂⁴He2质子+2中子飞出最弱（一张纸）
β衰变ₐᵐX → ₐ₊₁ᵐY + ₋₁⁰e中子→质子+电子中等（几mm铝）
γ衰变伴随α/β放出光子激发态→基态最强（几cm铅）
⚡ 口诀：α衰变质量数减4电荷减2，β衰变质量数不变电荷加1，γ衰变是能量释放没有核子变化
☢️ 核反应四大类型
类型例子特点
α衰变²³⁸U → ²³⁴Th + α自发
β衰变²³⁴Th → ²³⁴Pa + β自发
人工核反应¹⁴N + α → ¹⁷O + p人为轰击
裂变²³⁵U + n → ¹⁴¹Ba + ⁹²Kr + 3n重核分裂
聚变²H + ³H → ⁴He + n轻核结合
📊 半衰期与质量亏损
N = N₀·(½)^(t/T)    m = m₀·(½)^(t/T)
T=半衰期，t=经过时间。半衰期由原子核内部决定，与温度/压强/化合态无关！
ΔE = Δm·c²    质量亏损↓ 结合能↑ 核越稳
⚡ 比结合能：铁（⁵⁶Fe）附近比结合能最大，核最稳定。裂变和聚变都是比结合能小的变成大的，释放能量。
🔬 波粒二象性·光电效应
E = hν = hc/λ    p = h/λ
光电效应：Eₖ = hν - W₀
h=6.63×10⁻³⁴J·s   c=3×10⁸m/s   1eV=1.6×10⁻¹⁹J
⚡ 光电效应规律：①存在截止频率ν₀（ν₀=W₀/h）②光强只影响光电子数不影响动能③瞬时性（<10⁻⁹s）④Eₖ随ν增大线性增大
🎯 氢原子能级 必考1题
Eₙ = -13.6/n² eV
①从高能级→低能级：放出光子，E = Eᵢ - Eⱼ = hν
②从低能级→高能级：吸收光子，光子能量必须精确等于能级差
③从n能级到基态：最多发出 C²ₙ = n(n-1)/2 种不同频率的光
④电离能 = 13.6/n² eV（从n能级到无穷远）
⚡ 陷阱：入射光子能量大于能级差但不足以上一能级→不会吸收（只能精确吸收）。但如果是实物粒子（电子）碰撞→能量给一部分也行！
🔦几何光学 · 物理光学必考1道
📐 折射定律·全反射 大题可能考
n = sinθ₁/sinθ₂ = c/v
全反射：sinC = 1/n
⚡ 全反射条件：①光密→光疏（n₁>n₂）②入射角≥临界角C。C满足sinC=n₂/n₁。光导纤维用的就是这个原理！
常见介质折射率：空气≈1，水=4/3≈1.33，玻璃≈1.5，钻石≈2.4
🌈 光的干涉·衍射·偏振
① 双缝干涉——Δx = λL/d（λ波长，L缝到屏距离，d双缝间距）亮纹：光程差=kλ，暗纹：光程差=(2k+1)λ/2
② 薄膜干涉——肥皂泡彩色条纹、油膜。上下表面反射光干涉
③ 单缝衍射——缝越小衍射越明显。中央亮纹最宽最亮，两侧对称减弱
④ 偏振——横波特有。自然光→偏振片→偏振光。3D电影、偏光太阳镜
⚡ 区分：干涉是两列相干波叠加（等间距），衍射是一列波绕过障碍（中央宽两侧窄）。条纹间距越大→λ越大→频率越小→折射率越小！
💡 光 vs 机械波
性质光（电磁波）机械波
介质不需要需要（固/液/气）
速度c=3×10⁸m/s（真空中）v=λf（介质决定）
快慢规律n越大v越慢固>液>气
偏振能偏振（横波）横波能，纵波不能
〰️机械振动 · 机械波必考1道
🎵 简谐振动核心
F = -kx    a = -kx/m    T = 2π√(m/k)
单摆：T = 2π√(L/g)
①对称性：从最大位移到平衡位置，动能↑势能↓，机械能守恒。质点在两端速度=0加速度最大，平衡位置速度最大加速度=0
②单摆周期T与摆球质量m无关！与振幅振幅无关（小角度条件下）
③受迫振动：驱动力频率=系统固有频率→共振（振幅最大）
🌊 机械波
v = λf = λ/T  （波速仅取决于介质，与频率无关！）
①振动与波的关系：振动是质点的运动，波是振动形式的传播。质点不随波迁移！
②波形图vs振动图：波形图横轴x（谁在振动），振动图横轴t（什么时候振动）。波形图看波长λ，振动图看周期T
③波的叠加：两列波相遇——位移=各自位移的矢量和。干涉条件：频率相同、相位差恒定
④多普勒效应：波源靠近→频率变高（声音变尖），远离→频率变低（声音变沉）
⚡ 判断质点振动方向："上坡下振，下坡上振"——波形图向上走时质点向下振动，反之向上。或者用"同侧法"。多画图！
📏 波的干涉·加强减弱
加强：Δr = nλ  （n=0,±1,±2……）
减弱：Δr = (2n+1)λ/2
加强点振幅 = A₁ + A₂（振动最剧烈）
减弱点振幅 = |A₁ - A₂|（可能完全不振动）
注意：加强点不是一直处于波峰，而是振幅更大！
💥动量 · 碰撞 · 能量常考
⚡ 动量守恒·三种碰撞
m₁v₁ + m₂v₂ = m₁v₁' + m₂v₂'
碰撞类型动量动能特点
弹性守恒✓守恒✓不粘在一起，如台球
非弹性守恒✓减少一般碰撞
完全非弹性守恒✓损失最大粘在一起运动
⚡ 爆炸/反冲：动量也守恒（内力远大于外力）。人船模型、火箭发射、原子核衰变反冲都是典型！
📐 人船模型（必会）
m₁x₁ = m₂x₂   x₁ + x₂ = L（相对位移）
人在船上走→船向反方向移动。系统质心位置不变。
适用于：人在船上、大炮发射、劈上滑块等——所有"系统内一部分运动带动另一部分"的问题！
🔬必看实验实验题15分
📊 力学&电学实验要点
实验关键操作误差来源
测重力加速度g单摆测L和T，T≥5次取平均摆角过大、空气阻力
验证动量守恒气垫导轨水平、碰前碰后各测一次摩擦力、测距误差
测折射率插大头针，画入射/出射光线针不垂直、画线偏移
伏安法测电阻大内小外电表内阻影响
⚡ 大内小外：大电阻用内接法（电流表内接），小电阻用外接法（电流表外接）。"大"指电阻远大于电流表内阻，"小"指电阻远小于电压表内阻。
🔢 读数·有效数字·仪器使用
① 游标卡尺——不用估读！主尺mm+游标对齐格数×精度（10分度0.1，20分度0.05，50分度0.02）
② 螺旋测微器——要估读！主尺mm+半刻度(0.5)+转筒读数×0.01mm，结果保留3位小数
③ 多用电表——欧姆档：指针在中央附近最准（选合适倍率）；每次换档要调零！不测电阻时断开电源！
④ 打点计时器——先通电后放纸带，50Hz→T=0.02s，Δx=aT²求加速度，中间时刻速度=平均速度
🎯选择题蒙题·得分技巧临场救命
🧠 实在不会的题怎么蒙？
①单位检验法：看选项的单位对不对。物理题单位不对一定错！
②极端值法：把变量推到0或无穷大，看结果是否合理
③量级排除法：核反应能量≈MeV，可见光波长≈几百nm，分子直径≈10⁻¹⁰m
④对称性：题目对称→答案往往也对称（左右对称结构选对称选项）
⑤多选保守策略：不确定的坚决不选！3分到手比0分强

⏰ 时间分配建议
0-30min选择题（单选+多选），平均2min/题，不会的先跳过

✏️ 大题得分法则
①写公式就有分！不会算也要把相关公式写上去，每题第一问通常代公式就能做
②设未知量要写"设……"，并把已知条件标在图上
③分步计算，中间结果写清楚（即使最后算错也有步骤分）
④答案带单位，用科学计数法保持有效数字一致
⑤不会做的题：能把哪个量求出来就求出来，写上去
