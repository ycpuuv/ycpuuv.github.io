四法串讲 · 一题多解

同母题，四种方法逐一突破，体会不同思路的优劣。

方法一：公式法（位移相等列方程）

核心思想：追上时两车位移相等，直接列运动学方程求解。

第（1）问：何时追上？
1
写出两车位移表达式
超车位移：x₁ = v₀t = 20t
警车位移：x₂ = ½at² = ½ × 2 × t² = t²
2
列追及条件：位移相等
x₁ = x₂ → 20t = t²
3
解方程
t² − 20t = 0 → t(t − 20) = 0
t = 0（出发时刻，舍去）或 t = 20 s
4
求追上位置
x = 20 × 20 = 400 m
警车在 20s 后、距出发点 400m 处追上超速车。
第（2）问：最大距离
5
写出间距表达式
Δx = x₁ − x₂ = 20t − t²
6
求极值：间距最大时，两车速度相等
为什么？当警车速度 < 超速车速度时，间距在增大；当警车速度 > 超速车速度时，间距在缩小。所以速度相等是间距取最大值的临界条件。
v₂ = at = 2t = 20 → t = 10 s
7
代入求最大距离
Δx_max = 20×10 − 10² = 200 − 100 = 100 m
公式法小结：直接列位移方程，思路清晰直观。追及问题中"位移相等"是列方程的核心依据。求最大距离时，"速度相等"是极值条件。
方法二：v-t 图像法

核心思想：画出两车的 v-t 图像，利用"面积差 = 间距"来分析。

画出 v-t 图像
分析过程
1
画 v-t 图：超速车 v₁=20（水平线），警车 v₂=2t（过原点斜线）
2
找交点：v₁ = v₂ → 20 = 2t → t = 10s（速度相等时刻）
3
面积分析间距
0~10s：超速车面积 > 警车面积（S₁ 区域），间距增大
10~20s：警车面积 > 超速车面积（S₂ 区域），间距缩小
4
最大距离 = S₁ 面积
Δx_max = ½ × 10 × 20 = 100 m
5
追上条件：两面积相等（S₁ = S₂）
由几何关系：S₁ = ½ × 10 × 20 = 100
S₂ = ½ × (t追−10) × (2t追−20)
令 S₁ = S₂，解得 t追 = 20s
图像法小结：v-t 图最直观！面积差就是两车间距。交点（速度相等）对应间距最大；两块面积相等时对应追上。看图就能"看到"整个追及过程。
方法三：判别式法（Δ 判断能否追上）

核心思想：将追及条件转化为二次方程，用判别式 Δ 判断解的情况。

建立间距方程
1
写出间距关于时间的函数
Δx(t) = x₁ − x₂ = 20t − t² = −t² + 20t
2
追上时 Δx = 0，列方程
−t² + 20t = 0 → t² − 20t = 0
用判别式分析
3
对于一般追及问题，设间距为 d，则追及条件为：
−t² + 20t = d → t² − 20t + d = 0

判别式：Δ = 400 − 4d
Δ 的值方程解物理含义
Δ > 0（d < 100）两个正根能追上（且有两次"相遇"，但第二次是反超）
Δ = 0（d = 100）唯一解恰好追上（最近距离 = 0，即"恰好不相撞"的临界）
Δ < 0（d > 100）无实数解追不上（最小距离 = d − 100）
4
本题中 d = 0（同时同地出发）
Δ = 400 > 0，有解 → 能追上。
最大间距对应 Δ = 0 时的 d 值：d_max = 100 m
判别式法小结：特别适合判断"能否追上"以及"最近/最远距离"的问题。Δ=0 是"恰好追上"的临界条件，在刹车追及、安全距离等问题中非常实用。
方法四：相对运动法（变换参考系）

核心思想：以超速车为参考系，将两体问题简化为单体问题。

转换参考系
1
以超速车为参考系
在超速车看来，警车的运动是：
物理量地面参考系超速车参考系
初速度v₂₀ = 0v'₂₀ = 0 − 20 = −20 m/s（向后）
加速度a₂ = 2 m/s²a'₂ = 2 m/s²（不变）
初始距离d₀ = 0d'₀ = 0
在超速车参考系中分析
2
相对位移表达式
x' = v'₂₀ · t + ½a'₂ · t² = −20t + t²
x' < 0 表示警车在超速车后面，x' = 0 表示追上。
3
求最大距离（相对速度为零时）
v' = −20 + 2t = 0 → t = 10 s
此时 x' = −20×10 + 100 = −100 m
即警车落后 100 m（最大距离）。
4
求追上时刻
x' = 0 → −20t + t² = 0 → t(t−20) = 0
t = 20 s（与公式法一致）
相对运动法小结：变换参考系后，两体问题变成"一个物体做匀变速运动追赶一个静止目标"，问题大大简化。特别适合处理两车都在变速运动的复杂情形。
第二母题 · 匀减速追匀速 · 一题四法
第二母题

乙车以 v₂ = 40m/s 在甲车后方 d = 50m 处同向行驶，甲车匀速 v₁ = 30m/s。乙车开始以 a = 4m/s² 匀减速刹车。问：乙车能否追上甲车？若追不上，最近距离是多少？

方法一：公式法（位移相等列方程）

核心思想：追上时乙车位移 = 甲车位移 + 初始间距，直接列方程求解。

1
写出两车位移表达式
甲车位移：x₁ = 30t（从乙车开始刹车计时）
乙车位移：x₂ = 40t − ½×4×t² = 40t − 2t²
初始间距：d = 50m
2
列追及条件
追上时：x₂ = x₁ + d
40t − 2t² = 30t + 50
整理：2t² − 10t + 50 = 0 → t² − 5t + 25 = 0
3
求解方程
Δ = 25 − 100 = −75 < 0
无实数解 → 追不上！
4
求最近距离（速度相等时距离最近）
速度相等：v₂ = v₁ → 40 − 4t = 30 → t = 2.5s
代入间距公式：
Δxmin = x₁ + d − x₂ = 30(2.5) + 50 − (40×2.5 − 2×2.5²)
= 75 + 50 − (100 − 12.5) = 125 − 87.5 = 37.5 m
5
验证刹车时间
tstop = 40/4 = 10s > 2.5s ✓（乙车还没停，计算有效）
公式法要点：当判别式 Δ<0 时追不上，此时求最近距离的方法是令速度相等。
方法二：v-t 图像法

核心思想：画出两车的 v-t 图像，利用"面积差 = 间距变化量"来分析。

画出 v-t 图像
分析过程
1
画 v-t 图：甲 v₁=30（水平线），乙 v₂=40−4t（下降直线）
2
找交点：v₁=v₂ → t=2.5s（速度相等时刻）
3
面积差 = 间距变化量
0~2.5s 内乙比甲多走的距离 = 三角形面积
S = ½ × 2.5 × (40−30) = ½ × 2.5 × 10 = 12.5m
4
判断能否追上
初始间距 50m，只缩小了 12.5m → 最近距离 = 50 − 12.5 = 37.5m
追不上！
图像法小结：图像法一目了然！面积差<初始间距 → 追不上。面积差=初始间距 → 恰好追上。面积差>初始间距 → 能追上。
方法三：判别式法（Δ 判断能否追上）

核心思想：写出间距函数，用判别式 Δ 判断方程是否有解。

建立间距函数
1
写出间距关于时间的函数
Δx(t) = (x₁+d) − x₂ = 30t+50 − (40t−2t²) = 2t² − 10t + 50
这是开口向上的抛物线（系数 2>0）。
2
令 Δx = 0，判断能否追上
2t² − 10t + 50 = 0 → t² − 5t + 25 = 0
Δ = 25 − 100 = −75 < 0 → 无解，追不上
3
求最小间距（代入顶点公式）
最小值在 t = −b/(2a) = 10/(2×2) = 5/2 = 2.5s 处
Δxmin = 2(2.5)² − 10(2.5) + 50 = 12.5 − 25 + 50 = 37.5m
判别式分析总表
Δ 的值 含义
Δ > 0 能追上（两个解 = 两次相遇）
Δ = 0 恰好追上（临界，一次相遇）
Δ < 0 追不上（最小距离 = 代入顶点公式）
判别式法小结：判别式法最适合判断"能否追上"。本题 Δ<0，直接得出追不上的结论。
方法四：相对运动法（变换参考系）

核心思想：以甲车为参考系，将两体问题简化为单体匀减速运动。

转换参考系
1
以甲车为参考系，乙车的相对运动
物理量数值
相对初速度v'₀ = 40 − 30 = 10 m/s（向前）
相对加速度a' = −4 − 0 = −4 m/s²
初始距离乙落后 50m
相对运动分析
2
相对位移表达式
x' = 10t − 2t²
3
追上条件
x' = 50 → 2t² − 10t + 50 = 0 → Δ < 0 → 追不上！
4
最大相对位移（最接近时）
v' = 0 → 10 − 4t = 0 → t = 2.5s
x'max = 10(2.5) − 2(2.5)² = 25 − 12.5 = 12.5m < 50m → 追不上
最近距离 = 50 − 12.5 = 37.5m
相对运动法小结：相对运动法把追及问题变成单体匀减速运动，只需要分析一个物体的运动，思路最简洁。
专题 · 判断相遇几次

高考常考"两物体相遇几次"的问题。核心方法有两种：方程法和图像法。

方法一 — 方程法（数解的个数）
1
列位移方程：令两物体位移相等（考虑初始间距），得到关于 t 的方程。
2
化简为标准二次方程：at² + bt + c = 0
3
计算判别式：Δ = b² − 4ac
4
数正实数解的个数：
判别式解的情况相遇次数
Δ > 0 且两根为正两个正实数根相遇 2 次
Δ = 0唯一解相遇 1 次（恰好追上）
Δ < 0无实数解相遇 0 次（追不上）
5
验证：解出的时间是否在物理有效范围内（是否超过刹车时间？）
方法二 — x-t 图像法（数交点个数）
1
在同一坐标系中画出两物体的 x-t 图。
2
数两条曲线的交点个数 = 相遇次数。
3
交点的横坐标 = 相遇时刻，纵坐标 = 相遇位置。
方法三 — 间距函数法
1
写出间距函数：Δx(t) = |x₁(t) − x₂(t)|
2
令 Δx(t) = 0，数解的个数。
3
或者画出 Δx(t) 的图像，看它与 t 轴交几次。
练习 · 判断相遇几次

7相遇 0 次

匀减速追匀速 — 追不上

甲匀速 v₁=10m/s，乙在甲后方 60m 处以 v₂=20m/s、a=−2m/s² 匀减速追赶。乙车最多能追上甲车吗？相遇几次？

列方程：

x₁ = 10t，x₂ = 20t − t²，d = 60

追上条件：20t − t² = 10t + 60 → t² − 10t + 60 = 0

Δ = 100 − 240 = −140 < 0

相遇 0 次（追不上）

验证刹车时间：tstop = 20/2 = 10s（即使不停也追不上）

最近距离：t = 5s 时，
Δx = 10(5)+60−(20×5−25) = 50+60−75 = 35m

8相遇 1 次 — 恰好追上

匀减速追匀速 — 临界条件

甲匀速 v₁=10m/s，乙在甲后方 d 处以 v₂=20m/s、a=−2m/s² 匀减速追赶。要使乙恰好追上甲，d 应为多少？

列方程：

追上条件：20t − t² = 10t + d → t² − 10t + d = 0

恰好追上 → Δ = 0
100 − 4d = 0 → d = 25m

此时 t = 10/2 = 5s

验证刹车：tstop = 10s > 5s ✓

d = 25m 时恰好追上 1 次。

9相遇 2 次

匀减速追匀速 — 两次相遇

甲匀速 v₁=8m/s，乙在甲后方 10m 处以 v₂=16m/s、a=−2m/s² 匀减速追赶。两车相遇几次？分别在什么时刻？

列方程：

追上条件：16t − t² = 8t + 10 → t² − 8t + 10 = 0

Δ = 64 − 40 = 24 > 0 → 两个正根 → 相遇 2 次！

t₁ = (8−√24)/2 = 4−√6 ≈ 1.55s（第一次追上，乙超过甲）

t₂ = (8+√24)/2 = 4+√6 ≈ 6.45s（第二次相遇，甲反超乙）

验证刹车：tstop = 16/2 = 8s > 6.45s ✓

物理过程：乙先超过甲（第1次相遇），之后乙减速变慢，甲又追上乙（第2次相遇）。

核心结论：相遇次数 = 方程正实数解的个数。Δ>0 两次，Δ=0 一次，Δ<0 零次。但一定要验证刹车时间！如果解出的 t 超过刹车时间，那个解无效。
特别注意：第二次相遇（甲反超乙）在物理上是真实的——乙虽然先超过了甲，但因为一直在减速，最终被匀速的甲又追了回来。
核心规律总结
追上条件
两车位移相等（同一时刻到达同一位置）
间距最大
两车速度相等时，间距取极值
能否追上
列方程看判别式：Δ≥0 能追上，Δ<0 追不上
选方法
定量计算→公式法；直观分析→图像法；判断能否追→判别式；两体都变速→相对运动
特别注意：如果是减速物体追匀速物体，一定要先判断减速物体是否会先停下来（刹车问题），不能直接套公式！

变式训练 · 做一题通一类

在母题基础上变化条件，训练灵活运用四种方法的能力。

1基础变式

变化条件：警车晚出发 3s

超速车仍以 v₀=20m/s 匀速行驶，经过警车时警车不启动，3s 后警车才以 a=2m/s² 匀加速追赶。求：

（1）警车出发后多久追上超速车？

（2）追上前两车的最大距离。

分析：超速车多走了 3s，设警车出发后时间为 t。

超车位移：x₁ = 20(t+3) = 20t + 60

警车位移：x₂ = ½ × 2 × t² = t²

（1）追上条件：x₁ = x₂

t² = 20t + 60 → t² − 20t − 60 = 0

Δ = 400 + 240 = 640 → t = (20+√640)/2 = 10 + 4√10 ≈ 22.6 s

（2）最大距离：速度相等时间距最大

v₂ = 2t = 20 → t = 10s（警车出发后 10s）

Δx = 20(10+3) − 10² = 260 − 100 = 160 m

比母题多了 60m（正好是超速车 3s 的位移），体会时间差对结果的影响。

2进阶变式

变化条件：刹车追及（注意先停）

甲车以 v₁=20m/s 匀速行驶，乙车在甲车前方 d=48m 处以 v₂=24m/s 同向匀速行驶。某时刻乙车开始以 a=2m/s² 匀减速刹车。问：

（1）甲车能否追上乙车？

（2）若追不上，最近距离是多少？

关键：先判断乙车刹车到停止的时间

t_stop = v₂/a = 24/2 = 12s

用判别式法：设从刹车开始经过时间 t 后甲追上乙：

甲位移：x₁ = 20t

乙位移：x₂ = 24t − t²（t ≤ 12s 时有效）

追及条件：x₁ = x₂ + 48

20t = 24t − t² + 48 → t² − 4t − 48 = 0

Δ = 16 + 192 = 208 → t = (4+√208)/2 ≈ 9.2s < 12s

（1）能追上，在乙车停下前就追上了，t ≈ 9.2s

（2）此问不适用（因为能追上，最近距离为 0）。

易错提醒：如果算出 t > 12s，则乙车已经停下来了，不能再用 x₂=24t−t² 计算，而应该用乙车的停止位置 x₂=24²/(2×2)=144m 来重新判断。

3挑战变式

变化条件：双车追及（两车都变速）

甲车从静止开始以 a₁=3m/s² 匀加速启动，同时乙车在甲车前方 75m 处以 v₂=15m/s、a₂=−1m/s² 做匀减速运动（两车同向行驶）。求：

（1）甲车出发后多久追上乙车？

（2）追上前两车的最大距离。

用相对运动法最简洁！

以乙车为参考系，甲车的相对运动：

相对初速度：v'₀ = 0 − 15 = −15 m/s（甲相对乙向后）

相对加速度：a' = 3 − (−1) = 4 m/s²

初始相对位置：甲落后 75m

（1）追上条件：相对位移 = 75m

x' = v'₀·t + ½a'·t² = −15t + 2t² = 75

2t² − 15t − 75 = 0

Δ = 225 + 600 = 825 → t = (15+√825)/4 ≈ 10.9 s

需验证乙车此时是否已停：t_stop = 15/1 = 15s > 10.9s ✓

（2）最大距离：相对速度为零时

v' = −15 + 4t = 0 → t = 3.75s

此时相对位移 x' = −15×3.75 + 2×3.75² = −56.25 + 28.125 = −28.125m

实际距离 = 75 + 28.125 = 103.125 m

方法对比：两车都在变速运动时，相对运动法优势明显——只需要分析一个物体的运动，避免了复杂的联立方程。

① 匀加速追匀速 匀速 v₀ 匀加速 a 一定能追上 速度相等时间距最大
② 匀速追匀减速 匀减速 a 匀速 v₀ 一定能追上 前车先停则用停止位置算
③ 匀减速追匀速 匀速 v₀ 匀减速 a 不一定追上 Δ<0追不上，Δ=0恰好追上
④ 匀加速追匀减速 匀减速 匀加速 一定能追上 两车都在变，相对运动法最简
⑤ 匀减速追匀加速 匀加速 匀减速 不一定追上 后车先停需特别注意
⑥ 匀速追匀速 匀速 v₁ 匀速 v₂ v₂>v₁ 能追上 最简单，直接 Δv·t = Δx₀
记忆口诀："加速追匀速，一定能追上；减速追匀速，未必追得上；匀速追减速，前车可能先停下。"判断能否追上的核心是看后车速度能否大于前车速度。
通用解题六步法

无论哪种模型，按以下六步走，思路清晰不遗漏。

1
画过程 —— 画出运动示意图，标注初速度、加速度方向。运动过程一目了然。
2
判类型 —— 判断属于六种模型中的哪一种。不同模型决定不同的解题策略。
3
找条件 —— 追上条件（位移相等）或极值条件（速度相等）。这是列方程的依据。
4
查刹车 —— 减速物体先算停车时间 tstop = v/a，判断是否在停车前追上。这是最容易丢分的一步！
5
列方程 —— 根据条件列位移方程（可配合判别式 Δ）。选择合适的解法（公式法、图像法、判别式法、相对运动法）。
6
验结果 —— 验证时间是否合理（正值？是否超过停车时间？）。排除不合理解。
特别提醒：第④步"查刹车"是高考高频陷阱。凡是涉及减速运动的问题，必须先算停车时间，再判断追上发生在停车前还是停车后，两种情况的方程完全不同。
补充练习 · 覆盖更多模型

以下三道题分别对应模型②③⑥及相遇问题，用六步法逐一突破。

4模型② 匀速追匀减速

匀速追匀减速 —— 刹车陷阱典型

甲车以 v₁=10m/s 匀速行驶，前方乙车以 v₂=20m/s 同向行驶并开始以 a=4m/s² 刹车。初始间距 d=20m。问甲车能否追上乙车？若能，何时追上？

第一步：查刹车 —— 先算乙车停车时间

tstop = v₂/a = 20/4 = 5s

乙车停车位置：x₂ = v₂²/(2a) = 20²/(2×4) = 50m

第二步：列方程（假设 t ≤ 5s 时追上）

甲位移：x₁ = 10t

乙位移：x₂ = 20t − ½×4×t² = 20t − 2t²

追及条件：x₁ = x₂ + d → 10t = 20t − 2t² + 20

整理：2t² − 10t − 20 = 0

Δ = 100 + 160 = 260 > 0

t = (10+√260)/4 ≈ 6.6s

第三步：验结果 —— 发现陷阱！

t ≈ 6.6s > tstop = 5s → 乙车已经停下！不能再用运动学公式。

第四步：改用停止位置重新计算

乙车已停在 x₂ = 50m 处，甲车需要走过的距离：

10t = 50 + 20 = 70 → t = 7s ✓（> 5s，确认乙车已停）

答案：能追上，t = 7s（此时乙车已停）。

易错提醒：本题的陷阱在于直接用公式算出 t≈6.6s 就结束了，没有验证乙车是否已停。记住：凡是有减速的一方，必须先算停车时间！

5模型③ 匀减速追匀速（追不上）

匀减速追匀速 —— 判别式法判断追不上

甲车以 v₁=24m/s 匀速行驶，乙车在甲车后方 d=40m 处以 v₂=30m/s、a=−2m/s² 做匀减速追赶。问乙车能否追上甲车？若追不上，最近距离是多少？

第一步：判类型 —— 模型③，匀减速追匀速，不一定追上。

第二步：用判别式法列间距方程

甲位移：x₁ = 24t

乙位移：x₂ = 30t − t²

间距：Δx = x₁ + d − x₂ = 24t + 40 − (30t − t²) = t² − 6t + 40

第三步：追上条件 Δx = 0

t² − 6t + 40 = 0

Δ = 36 − 160 = −124 < 0

追不上！方程无实数解。

第四步：求最近距离（速度相等时）

速度相等：v₂ = v₁ → 30 − 2t = 24 → t = 3s

代入间距公式：Δxmin = 3² − 6×3 + 40 = 9 − 18 + 40 = 31m

第五步：验结果

乙车停车时间 tstop = 30/2 = 15s > 3s ✓（速度相等时乙车还在运动）

答案：追不上。最近距离为 31m（此时两车速度相等，均为 24m/s）。

判别式法在此类"判断能否追上"的问题中一步到位，非常高效。

6相遇问题（双向奔赴）

相向运动 —— 相遇问题

甲乙两车相距 d=100m，甲车以 v₁=15m/s 向乙车方向匀速行驶，乙车同时以 v₂=10m/s 向甲车方向匀速行驶。求：

（1）两车何时相遇？

（2）若乙车做匀加速 a=2m/s²（初速度仍为 10m/s），何时相遇？

关键：相向运动时，位移之和等于初始间距。

（1）两车匀速相向运动

相遇条件：x₁ + x₂ = d

15t + 10t = 100

25t = 100 → t = 4s

（2）乙车改为匀加速

甲位移：x₁ = 15t

乙位移：x₂ = 10t + ½×2×t² = 10t + t²

相遇条件：x₁ + x₂ = d

15t + 10t + t² = 100

t² + 25t − 100 = 0

Δ = 625 + 400 = 1025

t = (−25 + √1025)/2 ≈ (−25 + 32.02)/2 ≈ 3.5s

答案：（1）t = 4s；（2）t ≈ 3.5s（乙车加速后相遇更快）。

对比追及与相遇：追及问题（同向）用位移之差等于初始间距；相遇问题（相向）用位移之和等于初始间距。本质都是"同一时刻到达同一位置"。

高三一轮复习 · 追及问题全景图

用一张知识全景图，把追及相遇问题的完整体系串起来。

追及相遇问题
├── 追及问题（同向运动）
├── 后车能追上（模型 ①②④⑥）
└── 关键：求追上时间和位置
├── 后车追不上（模型 ③⑤）
└── 关键：求最近距离（速度相等时取极值）
└── 刹车陷阱
└── 先算停车时间 tstop = v/a，再判断追上发生在停车前还是后
└── 相遇问题（相向运动）
└── 位移之和 = 初始间距（x₁ + x₂ = d）
追及（同向）核心等式
x后 = x前 + d₀（位移之差等于初始间距）
相遇（相向）核心等式
x₁ + x₂ = d₀（位移之和等于初始间距）
极值条件（万能钥匙）
速度相等时，间距取极值（最大或最小）
刹车检查（必做步骤）
凡有减速运动，先算 tstop = v/a，再列方程
追及相遇的本质就一句话：同一时刻、同一位置。无论什么模型，列位移方程、找等量关系，就是解题的核心。速度相等是极值的万能钥匙。
