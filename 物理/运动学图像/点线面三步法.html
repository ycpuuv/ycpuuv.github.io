运动学图像 · 点线面三步法

一套方法通杀所有运动学图像题

看图三步法

任何运动学图像，三步搞定：

📍
一看点
截距→初始值
交点→相等量
拐点→转折处
极值→临界态
📈
二看线
斜率→导数量
升降→增减趋势
直弯→匀变/非匀变
正负→方向判断
🟦
三看面
有无面积意义？
正负→方向
代数和→净变化
绝对值和→总量
方法详解：三步法怎么用
第一步：看点
看四个关键位置：
位置含义举例
截距初始状态的值v-t 图纵截距 = 初速度 v₀
交点两物体某物理量相等x-t 图交点 = 相遇；v-t 图交点 = 速度相等
拐点运动状态发生转折加速变减速、正方向变反方向
极值点临界状态x-t 图顶点 = 折返（v=0）
第二步：看线
线告诉你"怎么变"：
看什么结论
斜率 = ？x-t 斜率→速度 v；v-t 斜率→加速度 a；a-t 斜率→a 的变化率
线是直是弯？直线→均匀变化（匀变速）；曲线→非均匀变化（变加速）
上升还是下降？上升→该量在增大；下降→该量在减小；水平→不变
在轴上方还是下方？上方→正值；下方→负值（反方向）
第三步：看面
面积 = 积分 = 累积效果：
图像面积含义注意
v-t 图面积 = 位移 Δx轴上为正，轴下为负；代数和=净位移
a-t 图面积 = 速度变化量 ΔvΔv = v末 − v初，不是速度本身！
x-t 图面积无物理意义不要硬凑！

口诀：v-t 面积是位移，a-t 面积是变速，x-t 面积不要算。

实战一：x-t 图像
例题 1 中等

甲、乙同时同地出发做直线运动，x-t 图如下：甲为直线，乙为开口向上的抛物线，t₁ 时刻两线相切。判断各选项：

A. t₁ 时刻甲乙速度相等   B. t₁ 时刻甲乙相距最远
C. 0~t₁ 内乙速度一直增大   D. 0~t₁ 内甲的位移大于乙

第一步：看点

截距：都从原点出发 → 初位置都是 0
交点（切点）：t₁ 时刻甲乙在同一位置 → 位移相等

第二步：看线

甲是直线 → 斜率恒定 → 甲匀速运动
乙是曲线（抛物线）→ 斜率在变化 → 乙做变速运动
乙的切线越来越陡 → 斜率越来越大 → 乙速度在增大
相切 = 斜率相等 → t₁ 时刻 甲乙速度相等 → A ✓

第三步：看面

x-t 图面积无意义 → 不看面积。
间距 = |x甲 − x乙|，0~t₁ 内甲一直在乙前面（甲直线在乙抛物线上方），t₁ 时刻恰好相遇。

答案：AB
A ✓（相切=斜率相等=速度相等）
B ✓（t₁前甲速度>乙速度，间距增大；t₁后乙速度>甲速度，间距缩小。t₁ 恰好是最大间距时刻）
C ✗（若乙初速度为负，则先减速再加速，不一定"一直增大"）
D ✗（t₁ 时刻位移相等）

实战二：v-t 图像
例题 2 中等

物体沿直线运动的 v-t 图如下：0~2s 从 v=0 匀加到 8m/s，2~5s 为曲线（速度继续增大但越来越慢，最终稳定 12m/s）。判断：

A. 0~2s 加速度 4m/s²   B. 2~5s 做匀减速
C. 2~5s 加速度减小但速度增大   D. 5s 后物体静止

第一步：看点

截距：t=0 时 v=0 → 从静止出发
拐点：t=2s 处直线变曲线 → 运动性质改变（匀变速→变加速）
t=5s 后曲线变水平 → 速度不再变化

第二步：看线

0~2s 是直线 → 斜率恒定 = 8/2 = 4m/s² → A ✓
2~5s 是曲线 → 非匀变速 → B ✗（不是匀减速）
曲线仍在上升 → 速度仍在增大
但切线越来越平 → 斜率在减小 → 加速度在减小 → C ✓
5s 后水平线 → v=12m/s ≠ 0 → 匀速运动 → D ✗（不是静止）

第三步：看面

v-t 面积 = 位移（本题无需计算面积，但面积法可以求各段位移大小）

答案：AC

核心区分：加速度减小 ≠ 速度减小！只要 a 和 v 同向（a>0 且 v>0），即使 a 在变小，速度仍在增大。只是增大得越来越慢了。
实战三：特殊图像快速套

同样的三步法，换一种图像一样用。

例题 3：a-t 图 基础

物体初速度 v₀=0，a-t 图如下：0~2s 加速度 a=3m/s²，2~4s 加速度 a=0，4~6s 加速度 a=−2m/s²。求 t=6s 时的速度。

一看点：截距 a(0)=3 → 初始加速度 3m/s²；拐点 t=2s 和 t=4s → 加速度突变

二看线：三段水平线 → 各段加速度恒定（分段匀变速）

三看面：a-t 面积 = Δv（速度变化量）

Δv = S₁ + 0 + S₂ = 3×2 + 0 + (−2)×2 = 6 − 4 = 2 m/s

v(6) = v₀ + Δv = 0 + 2 = 2 m/s

例题 4：v²-x 图 中等

某物体做匀变速直线运动，v²-x 图像为直线，过 (0, 4) 和 (8, 36)。求初速度、加速度，以及 v=4m/s 时的位移。

一看点：截距 v²(0)=4 → v₀²=4 → v₀=2m/s

二看线：直线 → 斜率恒定 → 匀变速
斜率 k=(36−4)/(8−0)=4，由 v²=v₀²+2ax 知斜率=2a → a=2m/s²

三看面：v²-x 图面积无物理意义，不看。

当 v=4m/s：v²=16，代入 16=4+4x → x=3m

例题 5：x/t-t 图 中等

匀变速直线运动，x/t-t 图为直线，过 (0, 10) 和 (5, 0)（x/t 单位 m/s，t 单位 s）。求初速度、加速度和速度为零的时刻。

一看点：截距 x/t(0)=10 → 初速度方向的平均速度为 10m/s

二看线：由 x/t = v₀ + ½at，斜率 = ½a
k=(0−10)/(5−0)=−2 → ½a=−2 → a=−4m/s²
t=0 时 x/t=v₀ → v₀=10m/s

三看面：x/t-t 图面积无直接物理意义。

v=v₀+at=10−4t=0 → t=2.5s 时速度为零

易混点：x/t-t 图斜率=½a，不是 a！和 v-t 图斜率=a 要区分开。
方法速查表
图像 📍 点（截距/交点/拐点） 📈 线（斜率含义） 🟦 面（面积含义）
x-t 截距=初位置；交点=相遇 斜率 = 速度 v 无意义
v-t 截距=初速度；交点=速度相等 斜率 = 加速度 a 面积 = 位移 Δx
a-t 截距=初加速度；拐点=a 突变 斜率 = a 的变化率 面积 = 速度变化 Δv
v²-x 截距 = v₀² 斜率 = 2a 无意义
x/t-t 截距 = v₀ 斜率 = ½a 无意义
记忆口诀：x-t 斜率是速度，v-t 斜率加速度；v-t 面积是位移，a-t 面积算变速；v²-x 斜率 2a，x/t-t 斜率半个 a。
图像转换 · 三步法架桥

已知一种图像，如何画出另一种？用三步法做"翻译"。

转换三步法
第一步：用点线面从已知图提取运动信息（各阶段 v₀、a、运动类型）
第二步：根据运动信息画出目标图的骨架（分段画线）
第三步：用量验证（面积、斜率等是否吻合）
例题 6（转换题）进阶

物体的 v-t 图如下：0~2s 从 0 匀加速到 6m/s，2~4s 匀速 6m/s，4~6s 匀减速至 0。
画出 x-t 图和 a-t 图。

已知：v-t 图

第一步：从 v-t 图提取运动信息

阶段时间v₀v末a（斜率）运动类型Δx（面积）
①0~2s06 m/s+3 m/s²匀加速6 m
②2~4s6 m/s6 m/s0匀速12 m
③4~6s6 m/s0−3 m/s²匀减速6 m

第二步：画 x-t 图

x(0)=0；x(2)=6m；x(4)=18m；x(6)=24m

① 匀加速 → 抛物线（开口向上）
② 匀速 → 直线
③ 匀减速 → 抛物线（开口向下，趋于平缓）

目标：x-t 图

第三步：画 a-t 图

a 在各段为常数 → 三段水平线（阶跃函数）

目标：a-t 图

第三步验证：

a-t 面积：3×2 + 0×2 + (−3)×2 = 6 − 6 = 0 = Δv ✓（v 从 0 回到 0）
v-t 面积：½×2×6 + 2×6 + ½×2×6 = 6+12+6 = 24m = x(6) ✓

变式训练 · 反复套用三步法

1基础 关于运动学图像，正确的是：

A. x-t 图是物体的运动轨迹
B. v-t 图面积表示路程
C. v-t 图斜率表示加速度
D. x-t 图中曲线表示曲线运动

答案：C

用三步法逐项检验：
A ✗（x-t 图不是轨迹，只是位移随时间变化）
B ✗（面积=位移，有正负，不是路程）
C ✓（v-t 斜率=a，速查表可查）
D ✗（x-t 图的曲线只说明速度在变，物体仍做直线运动）

2基础 v-t 图如下：0~3s 内 v 从 12m/s 匀减到 0，3~5s 内 v 从 0 反向匀增到 −8m/s。求 0~5s 内的位移和路程。

三步法：

一看点：截距 v₀=12；拐点 t=3s 速度为零（折返）；t=5s 时 v=−8

二看线：两段直线 → 匀变速；第一段下降（减速），第二段在轴下（反向加速）

三看面：面积=位移

S₁ = ½×3×12 = 18 m（正位移）
S₂ = ½×2×(−8) = −8 m（负位移）
位移 = 18+(−8) = 10 m
路程 = 18+8 = 26 m

3中等 物体做匀变速直线运动，x-t 图为抛物线。t=0 时 x=0，t=2s 时 x=12m，t=4s 时 x=16m。求 v₀ 和 a。

三步法：

一看点：截距 x(0)=0；已知两个点的坐标

二看线：抛物线 → 匀变速运动，x=v₀t+½at²

三看面：x-t 面积无意义

列方程：t=2: 12=2v₀+2a → v₀+a=6 ...①
t=4: 16=4v₀+8a → v₀+2a=4 ...②
②−①: a=−2 → a=−2m/s²
代入①: v₀=8m/s

4中等 a-t 图如下：0~2s a=3m/s²，2~4s a=0，4~6s a=−2m/s²。初速度 v₀=2m/s。求：

（1）t=4s 时的速度
（2）0~6s 速度的变化量

三步法：看面（a-t 面积=Δv）

S₁=3×2=6；S₂=0；S₃=(−2)×2=−4

（1）v(4) = v₀+S₁+S₂ = 2+6+0 = 8m/s
（2）Δv = 6+0+(−4) = 2m/s（速度净增 2m/s）
v(6) = 2+2 = 4m/s

5进阶 某物体 v-t 图如下：0~4s 内图线为半圆弧（从 v=0 上升到 v=6m/s 再回到 v=0）。求 0~4s 内的位移。

三步法：

一看点：截距 v₀=0；t=2s 时 v_max=6；t=4s 时 v=0

二看线：曲线 → 非匀变速；先升后降 → 先加速后减速

三看面：面积=位移，半椭圆面积 = ½πab

t 轴半轴 a=2s，v 轴半轴 b=6m/s
S = ½π×2×6 = 6π ≈ 18.85m

技巧：遇到半圆/半椭圆，面积公式 S=½πab（a、b 为两个半轴长，注意单位不同要直接代入物理量数值）。

6进阶 x/t-t 图为直线，t=0 时 x/t=10m/s，t=5s 时 x/t=0。求：

（1）v₀ 和 a  （2）速度为零的时刻  （3）0~5s 位移

三步法：

一看点：截距 x/t(0)=10

二看线：直线 → 斜率=½a；k=(0−10)/(5−0)=−2 → a=−4m/s²
x/t=v₀+½at → t=0: v₀=10m/s

三看面：x/t-t 面积无直接意义

（2）v=v₀+at=10−4t=0 → t=2.5s
（3）x = v₀t+½at² = 10×5+½×(−4)×25 = 50−50 = 0
（t=5s 时 x/t=0 → x=0，也验证了这一点。物体先正向后运动，5s 时恰好回到出发点。）

7进阶·综合 甲乙两车同时同地出发。甲的 x-t 图是过原点直线，乙的是过原点抛物线。t₁ 时刻两图线相交（非相切）。则：

A. t₁ 时刻速度相等   B. t₁ 时刻位移相等
C. t₁ 之前某时刻相距最远   D. 乙在 t₁ 后会超过甲

三步法：

一看点：都过原点→同时同地出发；交点→t₁ 时刻同一位置（位移相等 B ✓）

二看线：甲直线→匀速 v₀；乙抛物线→匀加速（初速为0，x=½at²）
交点处乙的切线斜率 > 甲斜率 → 乙速度 > 甲速度 → A ✗

乙从静止加速，甲匀速 v₀。当乙速度=v₀ 时间距最大 → C ✓
t₁ 后乙速度 > 甲速度 → 乙会超过甲 → D ✓

答案：BCD

常见陷阱 · 易错点辨析

以下错误在考试中反复出现，务必逐条核对！

陷阱一：x-t 图的曲线 ≠ 曲线运动

✗ 错误："x-t 图是曲线，所以物体做曲线运动"

✓ 正确：x-t 图只描述位移随时间的变化，曲线只说明速度在变，物体始终做直线运动。x-t 图根本不是运动轨迹！

陷阱二：v-t 图面积 ≠ 路程

✗ 错误："v-t 图面积就是路程"

✓ 正确：v-t 图的面积有正负之分，代数和 = 位移（净变化）。路程 = 各段面积的绝对值之和。当物体有折返（v 变号）时，位移 ≠ 路程。

陷阱三：加速度减小 ≠ 速度减小

✗ 错误："加速度在减小，所以速度也在减小"

✓ 正确：速度增大还是减小，取决于 a 和 v 的方向关系。当 a 和 v 同向（同为正或同为负）时，即使 a 在减小，速度仍在增大——只是增大得越来越慢了。只有当 a 和 v 反向时，速度才在减小。

陷阱四：x/t-t 图斜率 = ½a，不是 a

✗ 错误："x/t-t 图的斜率就是加速度 a"

✓ 正确：由 x/t = v₀ + ½at 可知，x/t-t 图的斜率 = ½a，需要乘以 2 才是加速度。这和 v-t 图斜率 = a 不同，极易混淆！

陷阱五：两线相交 ≠ 两线相切

✗ 错误：把交点和切点混为一谈

✓ 正确：在 x-t 图中：交点 = 两物体位置相同（相遇）；切点 = 两图线斜率相等（速度相同）。相交时速度一般不等，相切时位移恰好相等。一字之差，含义完全不同。

非常规图像 · 高考新趋势

近年高考越来越爱考非常规图像。别怕！三步法一样用，关键是搞清楚纵轴和横轴的物理含义，再用公式推导斜率和面积的含义。

非常规图像破解口诀：先看轴（纵轴是什么？横轴是什么？），再推线（用公式推出斜率含义），最后算（代入数据求解）。
例题 7：1/v - x 图 中等

某物体做匀加速直线运动，其 1/v 关于 x 的图像为直线，过 (0, 0.5) 和 (6, 0.1)（1/v 单位 s/m，x 单位 m）。求初速度 v₀ 和加速度 a。

一看点

截距：x=0 时 1/v = 0.5 → v₀ = 1/0.5 = 2 m/s
另一端点：x=6 时 1/v = 0.1 → v = 1/0.1 = 10 m/s

二看线

图像为直线 → 1/v 与 x 成线性关系：1/v = kx + b
斜率 k = (0.1−0.5)/(6−0) = −0.4/6 = −1/15
由 v² = v₀² + 2ax → 10² = 2² + 2a×6
100 = 4 + 12a → a = 96/12 = 8 m/s²

三看面

1/v-x 图面积无物理意义，不看。

答案：v₀ = 2 m/s，a = 8 m/s²

注意：1/v-x 图为直线，不代表 v-x 图也是直线。遇到倒数轴，一定要先用公式推导出纵轴和横轴的函数关系。
例题 8：x-v 图 进阶

一物体做匀减速直线运动至停止，其 x-v 图像为抛物线，过点 (20, 0) 和 (0, 50)（横轴为 v/m·s⁻¹，纵轴为 x/m）。求初速度 v₀ 和加速度 a。

一看点

(20, 0) → v = 20 m/s 时 x = 0 → 这是起点，初速度 v₀ = 20 m/s
(0, 50) → v = 0 时 x = 50 m → 停止时位移 50 m

二看线

由 v² = v₀² + 2ax（匀减速，a < 0），变形得：
x = (v₀² − v²) / (2|a|)
这是关于 v 的二次函数 → x-v 图为抛物线 ✓
代入 v=0, x=50：50 = v₀² / (2|a|) = 400 / (2|a|)
→ 2|a| = 8 → a = −4 m/s²

三看面

x-v 图面积无直接物理意义，不看。

答案：v₀ = 20 m/s，a = −4 m/s²

易错点：看清哪个是横轴！本题横轴是 v 而不是 x。x-v 图和 v-x 图横纵轴相反，读题时务必确认。
例题 9：a-x 图 进阶

一物体从静止开始沿直线运动，其加速度 a 随位移 x 变化的图像为一条从 (0, 6) 到 (12, 0) 的直线（a 单位 m/s²，x 单位 m）。求物体运动到 x = 12 m 时的速度。

一看点

截距 a(0) = 6 m/s² → 初始加速度
a(12) = 0 → 运动到 x = 12 m 时加速度为零

二看线

直线 → a 随 x 线性减小：a(x) = 6 − 0.5x
加速度在变 → 非匀变速运动

三看面

a-x 面积 = Δ(v²/2)（这是关键！）

推导：由 v·dv = a·dx，两边积分得 ½v² = ∫a·dx
即 a-x 图面积 = ½v² − ½v₀²

面积 S = ½ × 12 × 6 = 36（三角形面积）
½v² − ½×0² = 36 → v² = 72
v = √72 = 6√2 ≈ 8.49 m/s

核心公式：a-x 图面积 = Δ(v²/2)，因为 v·dv = a·dx，两边积分得 ½v² = ∫a·dx。这是非匀变速运动中非常重要的结论！
例题 10：a-v 图 进阶

物体沿直线运动，加速度 a 与速度 v 的关系为 a = 6 − v（a 单位 m/s²，v 单位 m/s）。物体从 v = 0 开始运动。求：

（1）最大速度 vmax  （2）当 v = 4 m/s 时的加速度

一看点

截距：v=0 时 a=6 → 初始加速度 6 m/s²
a=0 时 v=6 → 加速度为零时速度最大

二看线

直线 a = 6 − v → a 随 v 增大而线性减小
v < 6 时 a > 0 → 仍在加速（速度增大 → a 减小）
v = 6 时 a = 0 → 加速停止，达到最大速度

三看面

a-v 图面积无直接物理意义（不像 a-x 图），不看。

（1）最大速度：a = 0 时 0 = 6 − v → vmax = 6 m/s
（2）v = 4 m/s 时：a = 6 − 4 = 2 m/s²

物理分析：物体从 v=0 开始，a=6 很大 → 快速加速 → v 增大 → a 减小 → 加速越来越慢 → 最终 a=0 做匀速运动。这是一种"阻尼加速"模型，在高考中常以不同形式出现。
非常规图像速查
图像类型 斜率含义 面积含义 关键公式
1/v - x 需由公式推导 无 v² = v₀² + 2ax
x - v 需由公式推导 无 v² = v₀² + 2ax
a - x a 随 x 的变化率 ∫a·dx = Δ(v²/2) v·dv = a·dx
a - v a 随 v 的变化率 需推导 由题给函数关系
F - x（力学） 力的变化率 面积 = 功 W W = ∫F·dx
记住：不管图像多奇怪，三步法永远有效——看点、看线、看面。先用公式推导斜率和面积的物理含义，再套方法。遇到没见过的图像，不要慌，从"纵轴是什么、横轴是什么"开始分析就对了。
非常规图像 · 认知冲突专题

以下每道题都会先给你一个"直觉答案"——看起来很对，其实是错的。先想想你的答案是什么，再看解析，看看你是不是掉进了陷阱。认知冲突是最好的老师！

例题 11：t-x 图（注意：纵轴是 t！） 陷阱

下图是某物体的 t-x 图像（注意：纵轴为 t，横轴为 x），图线为过原点的直线，斜率为正。以下说法正确的是：

A. 物体做匀速运动   B. 斜率表示速度
C. 斜率越大，速度越大   D. 斜率越大，速度越小

直觉陷阱：很多人会选 ABC，以为斜率=速度。看到直线就想到"匀速运动"，看到斜率就想到"速度"——但这次轴是反的！

正确分析：

纵轴是 t，横轴是 x → 斜率 = dt/dx = 1/v（速度的倒数），不是 v！

逐项判断：

斜率为正且恒定 → 1/v 恒定 → v 恒定 → 确实是匀速 → A ✓
但斜率 = 1/v，不是 v → B ✗
斜率越大 → 1/v 越大 → v 越小 → C ✗，D ✓

答案：AD

认知冲击：同样的直线，换个轴就完全不同！x-t 图斜率 = v，但 t-x 图斜率 = 1/v。看到图像第一件事永远是：确认哪个轴是什么！
例题 12：速率图 |v|-t vs 速度图 v-t 陷阱

下图是某物体的速率（|v|）随时间变化的图像：0~2s 从 10 匀减到 0，2~4s 从 0 匀增到 10。以下说法正确的是：

A. 物体做往复运动   B. 0~4s 内位移为零
C. 0~4s 内路程为 20m   D. 物体一直在同一方向运动

直觉陷阱：看到 V 字形，很多人觉得物体先减速到零再反向加速（往复运动），于是选 ABC。但这是速率图，不是速度图！

正确分析：

|v|-t 图只反映速率大小，完全不反映方向！

逐项判断：

A 不确定 — 可能是先正向减速到零再反向加速（往复），也可能是减速到零后同方向再加速。单凭 |v|-t 图无法判断方向。
B 不确定 — 位移取决于方向，两种情况的位移不同。
C ✓ — 路程 = ∫|v|dt = 两个三角形面积 = ½×2×10 + ½×2×10 = 10 + 10 = 20m（无论方向如何，路程都是面积之和）。
D 不确定 — 理由同 A。

答案：只有 C 一定正确

认知冲击：速率图和速度图形状可以一模一样，但速率图丢失了方向信息！看到 |v| 就要警惕：方向未知，很多结论不能下。
例题 13：a 减小 ≠ v 减小（经典认知陷阱） 陷阱

一物体做直线运动，其 a-t 图如下：a 从 8m/s² 线性减小到 2m/s²（0~4s 内），初速度 v₀=0。以下说法正确的是：

A. 4s 内物体速度一直在减小
B. 4s 末的速度为 20m/s
C. 4s 末的速度比 2s 末的速度大
D. 物体的加速度在减小，所以速度也在减小

直觉陷阱：很多人选 AD——"加速度在减小，所以速度也应该在减小吧？"这是最经典的认知错误！

正确分析：

a > 0 且 v₀ = 0 → 物体从静止开始，a 和 v 始终同向 → v 一直在增大！（只是增大得越来越慢）

计算速度：

v(t) = v₀ + ∫₀ᵗ a·dt = 0 + a-t 图面积（梯形）

2s 末：a(2) = 8 − (8−2)/4 × 2 = 5 m/s²
v(2) = ½×(8+5)×2 = 13 m/s

4s 末：a(4) = 2 m/s²
v(4) = ½×(8+2)×4 = 20 m/s

逐项判断：

A ✗ — v 一直在增大（a>0，速度方向为正）
B ✓ — v(4) = ½×(8+2)×4 = 20 m/s
C ✓ — v(4)=20 > v(2)=13
D ✗ — 经典错误！a 减小 ≠ v 减小

答案：BC

认知冲击：a 减小只说明速度增加得变慢了，好比"工资涨幅变小"不等于"工资在降"！只要 a > 0 且和 v 同向，速度就一直在涨。
例题 14：x-t² 图（不是抛物线！） 陷阱

某物体做初速度为零的匀加速直线运动，画出 x 关于 t² 的图像。以下说法正确的是：

A. x-t² 图为过原点的直线
B. 该直线的斜率等于加速度 a
C. 该直线的斜率等于 ½a
D. 若 x-t² 图不是直线，则物体不做匀加速运动

直觉陷阱：很多同学把 x-t 图和 x-t² 图混为一谈，以为"匀加速运动的图像就是抛物线"，忘记了换轴之后的变化。

正确分析：

初速度为零的匀加速运动：x = ½at²

令 u = t²，则 x = ½a · u
这是关于 u=t² 的一次函数！

逐项判断：

x-t² 图是直线，过原点（t²=0 时 x=0） → A ✓
斜率 = ½a，不是 a → B ✗，C ✓
如果 x-t² 不是直线 → ½a 不是常数 → a 不是常数 → 不是匀加速 → D ✓

答案：ACD

认知冲击：x-t 图是抛物线，但 x-t² 图变成了直线！这就是"线性化"的威力——通过选择合适的变量，把曲线变成直线，更容易分析。考试中常用这种手法！
例题 15：面积陷阱（别忘了初速度！） 陷阱

a-t 图如下：0~2s 内 a=6m/s²，2~4s 内 a=−3m/s²。初速度 v₀=0。4s 末物体的速度为多少？运动方向如何？

A. v=6m/s，正方向   B. v=3m/s，正方向
C. v=6m/s，负方向   D. v=0

直觉陷阱：有人看到后面一段 a<0，就以为速度会变成负数（反方向运动）。还有人只看面积差，忘了加上初速度！

正确分析：

分段计算速度：

v(2) = v₀ + a₁×t₁ = 0 + 6×2 = 12 m/s（正方向）
v(4) = v(2) + a₂×t₂ = 12 + (−3)×2 = 12 − 6 = 6 m/s

关键：虽然 2~4s 加速度为负（减速），但速度从 12m/s 减了 6m/s，还剩 6m/s，始终为正，没有反向！

逐项判断：

A ✓ — v(4) = 6m/s，方向为正
B ✗ — 3m/s 不对
C ✗ — 速度为正，不是负方向
D ✗ — 速度不为零

答案：A

认知冲击：a < 0 不代表 v < 0！减速只是速度在变小，方向没变。好比你在往前跑，虽然越跑越慢，但还是在往前跑！一定要用 v = v₀ + Δv 算出具体数值再判断。
认知冲突清单（反复回顾！）

1. 轴换了，含义就换：t-x 图的斜率 = 1/v，不是 v

2. 速率图 ≠ 速度图：|v|-t 丢失方向信息，很多结论无法确定

3. a 减小 ≠ v 减小：a 和 v 同向时 v 仍在增大

4. x-t² 图直线化：斜率 = ½a，不是 a

5. a < 0 不等于 v < 0：减速不等于反向

每道题的陷阱都是你的思维惯性造成的。打破惯性，才能进步！
