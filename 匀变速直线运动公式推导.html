匀变速直线运动基本公式

公式法 + 图像法 全程推导 · 两类减速运动辨析 · 方程组例题

一、五个基本公式 · 全程推导

匀变速直线运动的五个物理量：初速度 v₀、末速度 v、加速度 a、时间 t、位移 x。
五个公式任意两个独立，已知三个可求另外两个（知三求二）。但有些题只给两个条件——这就是知二求三，需要列方程组。

① 速度公式 v = v₀ + at

📐 公式法推导
v = v₀ + at
由加速度定义：
a = Δv / t = (v − v₀) / t
→ at = v − v₀
→ v = v₀ + at
📊 图像法推导
在 v−t 图中，匀变速运动是一条直线。
• 纵截距 = v₀（初速度）
• 斜率 k = Δv/Δt = a（加速度）
• 直线上任意一点：v = v₀ + at

② 位移公式 x = v₀t + ½at²

📐 公式法推导
x = v₀t + ½at²
由平均速度求位移：
x = v̄·t
匀变速平均速度 v̄ = (v₀+v)/2
代入 v = v₀+at：
v̄ = (v₀+v₀+at)/2 = v₀ + ½at
x = (v₀+½at)·t = v₀t + ½at²
📊 图像法推导
v−t 图下的面积 = 位移。
图形为直角梯形：
• 上底 = v₀（t=0时速度）
• 下底 = v（t时刻速度）
• 高 = t
梯形面积 = ½(v₀+v)·t
= ½[v₀+(v₀+at)]·t
= v₀t + ½at²

③ 速度位移公式 v² − v₀² = 2ax

📐 公式法推导
v² − v₀² = 2ax
由①②消去时间 t：
由 ①：t = (v−v₀)/a
代入 ②：x = v₀·(v−v₀)/a + ½a·(v−v₀)²/a²
= (v₀v−v₀²)/a + (v²−2vv₀+v₀²)/(2a)
通分：= (2v₀v−2v₀²+v²−2vv₀+v₀²)/(2a)
= (v²−v₀²)/(2a)
→ v² − v₀² = 2ax
📊 图像法推导
v−t 图面积 = x = ½(v₀+v)·t
又 t = (v−v₀)/a
x = ½(v₀+v)·(v−v₀)/a
= (v²−v₀²)/(2a)
→ v² − v₀² = 2ax

④ 平均速度公式 x = (v₀+v)·t / 2

📐 公式法推导
x = (v₀+v)·t / 2
直接由匀变速的定义：
匀变速运动中，
平均速度 v̄ = (v₀+v)/2
x = v̄·t = (v₀+v)t/2
★ 注意：只对匀变速成立！
📊 图像法推导
v−t 图梯形面积：
• 梯形面积 = ½(上底+下底)×高
• 上底 = v₀，下底 = v，高 = t
S = ½(v₀+v)·t = x

⑤ 逆向公式 x = vt − ½at²

📐 公式法推导
x = vt − ½at²
将 v₀ 用 v 和 a 表示：
由 ①：v₀ = v − at
代入 ②：x = (v−at)·t + ½at²
= vt − at² + ½at²
= vt − ½at²
📊 图像法推导
逆向思维——把时间倒流：
末速度 v 看作"逆向初速度"
加速度 a 方向不变但作用相反
在 t 时间内倒退：x = vt − ½at²
★ 对刹车问题求最后一段位移特别好用
💡 五个公式的关系速记

①②独立 → ③由①②消去t得到
④直接由v-t图面积得到，是②的另一种形式
⑤把v₀换成v（逆向思维），与②对称
核心口诀：知三求二，无t用③，无v用⑤

📊 交互式 v−t 图像 · 面积 = 位移

拖拽滑块改变加速度和末速度，观察面积（位移）变化。梯形面积 = ½(v₀+v)×t 为位移公式的几何直观。

二、两类减速运动必须辨析

类型Ⅰ：刹车问题（单向减速）

🚗 特点
• 减速到 v=0 后停止不动，不会反向
• 实际运动时间 ≤ 理论停止时间
• 位移不能用完整公式代入过大t
⚠️ 核心陷阱
必须先算停止时间 t₀ = v₀/a
如果题目给的 t > t₀：
• ❌ 直接代入 t 算位移 → 错误！
• ✅ 用 t₀ 代替 t 计算位移
或直接用 v²=2ax 求总位移

类型Ⅱ：竖直上抛类（双向减速）

🎯 特点
• 减速到 v=0 后反向加速
• 全程加速度恒定不变
• 位移、速度全程用统一公式
• 只需注意正负号代入
✨ 重要性质
对称性
• 上升时间 = 下降时间
• 同一高度速度大小相等，方向相反
• 上升段是匀减速，下降段是匀加速
★ 全程用 v=v₀−gt 时：
v>0 表示向上，v<0 表示向下
🚨 两类减速运动对比——必考易错
对比维度刹车类竖直上抛类
停止后静止不动反向加速
加速度方向与速度反向恒定向下（重力g）
时间陷阱t > t₀时必须用t₀t 可以任意代入公式
典型例子汽车刹车、滑块在粗糙面竖直上抛、光滑斜面上滑
对称性无上升=下降时间
💡 判断方法

看物体停下来后，有没有让它反向的力。
汽车刹车→摩擦力消失→停下不动。
竖直上抛→重力始终存在→停下后接着拉下来。
光滑斜面上滑→重力下滑分量始终存在→到顶后下滑。

三、例题精讲 · 方程组解法

【例1 · 知二求三】 一辆汽车做匀加速直线运动，测得第2秒内的位移为6m，第4秒内的位移为10m。求：汽车的初速度v₀、加速度a和第3秒末的速度v₃。 知二求三
🔍 分析
题中只给了两个位移条件（第2s内、第4s内），要解出三个未知量（v₀、a、v₃），必须列方程组。
这里的技巧是将"第N秒内位移"表示为"前N秒位移 − 前(N−1)秒位移"。
📝 解：设初速度 v₀，加速度 a
第2秒内位移 = 6m：
前1s：x₁ = v₀·1 + ½a·1² = v₀ + 0.5a
前2s：x₂ = v₀·2 + ½a·2² = 2v₀ + 2a
第2s内：Δx₂ = x₂ − x₁ = (2v₀+2a) − (v₀+0.5a) = v₀ + 1.5a = 6 ……① 第4秒内位移 = 10m：
前3s：x₃ = v₀·3 + ½a·3² = 3v₀ + 4.5a
前4s：x₄ = v₀·4 + ½a·4² = 4v₀ + 8a
第4s内：Δx₄ = x₄ − x₃ = (4v₀+8a) − (3v₀+4.5a) = v₀ + 3.5a = 10 ……② 解方程组：
② − ①：2a = 4 → a = 2 m/s²
代入①：v₀ + 3 = 6 → v₀ = 3 m/s
v₃ = v₀ + 3a = 3 + 3×2 = 9 m/s
✅ 验证
第2s内：Δx₂ = v₀ + 1.5a = 3 + 3 = 6m ✓
第4s内：Δx₄ = v₀ + 3.5a = 3 + 7 = 10m ✓
📌 知二求三的套路：当只知道两个条件要解三个物理量时，关键是找到两个独立的方程。
常用方法：①用位移差公式（逐差法）②用两段位移分别列式③用平均速度找中间时刻速度
【例2 · 方程组 + 刹车陷阱】 一物体做匀变速直线运动，通过A、B两点用时2s，AB=8m；通过B、C两点用时3s，BC=15m。已知物体做的是减速运动。
求：(1) 加速度 a   (2) 经过A点时的速度 v_A   (3) 物体停止前总共走了多远？ 刹车判断
🔍 分析
已知两段位移和对应时间，要求加速度和初速度——列方程组。
⚠️ 需要先判断这是哪种减速运动：题中只说"减速"，需算停止时间看是否在停止前就通过了BC段。
📝 解：(1)(2) 列方程组
设v_A = v₀，加速度为a（注意减速，a应为负值） AB段：t₁ = 2s，x₁ = 8m
x₁ = v₀t₁ + ½at₁² → 2v₀ + 2a = 8 ……① AC段（全程）：t = 5s，x = 8+15 = 23m
x = v₀t + ½at² → 5v₀ + 12.5a = 23 ……② 由①：v₀ = 4 − a，代入②：
5(4−a) + 12.5a = 20 − 5a + 12.5a = 20 + 7.5a = 23
→ 7.5a = 3 → a = 0.4 m/s² 但是……a = +0.4是正值，而物体是减速运动！
说明我们设的加速方向错了——实际加速度为a = −0.4 m/s² 代入①：2v₀ + 2(−0.4) = 8 → 2v₀ − 0.8 = 8 → v₀ = 4.4
v_A = 4.4 m/s     a = −0.4 m/s²
📝 (3) 刹车判断 + 总位移
停止时间：t₀ = |v₀/a| = 4.4/0.4 = 11s 由于物体通过BC用了3s（总时间5s），而停止时间11s远大于5s，说明物体在BC段尚未停止，两个位移数据都有效。 总位移（减速到零）：x_max = v₀²/(2|a|) = 4.4²/(2×0.4) = 19.36/0.8 = 24.2 m
⚠️ 此题两个陷阱：
① 列方程解的a为正，要结合"减速"条件判断正负号方向
② 要先算停止时间确认物体在BC段是否已停止，否则求出的v₀就是错的

📋 课时小结

五个公式核心：
v = v₀ + at  →  知时间求速度
x = v₀t + ½at²  →  知时间求位移
v² − v₀² = 2ax  →  无时间优先用
x = (v₀+v)t/2  →  平均速度巧解
x = vt − ½at²  →  逆向思维求刹车最后一段
两类减速辨析：
🚗 刹车类 → 先算停止时间 t₀，t > t₀ 时用 t₀
🎯 竖抛类 → 全程用统一公式，注意正负号即可
知二求三方法论：
① 把已知量写成表达式（如"第N秒内位移"展开）
② 列独立方程组（两个条件→两个方程→两个未知量）
③ 解出后再求第三个量
