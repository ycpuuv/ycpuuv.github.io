一、五个基本公式 · 全程推导

107| 108|

109|匀变速直线运动的五个物理量：初速度 v₀、末速度 v、加速度 a、时间 t、位移 x。
110|五个公式任意两个独立，已知三个可求另外两个（知三求二）。但有些题只给两个条件——这就是知二求三，需要列方程组。 111|

112| 113| 114|

① 速度公式 v = v₀ + at

115|
116|
117|
📐 公式法推导
118|
v = v₀ + at
119|
120|由加速度定义：
121|
a = Δv / t = (v − v₀) / t
122|
→ at = v − v₀
123|
→ v = v₀ + at
124|
125|
126|
127|
📊 图像法推导
128|
129|在 v−t 图中，匀变速运动是一条直线。 130|
• 纵截距 = v₀（初速度）
131|
• 斜率 k = Δv/Δt = a（加速度）
132|
• 直线上任意一点：v = v₀ + at
133|
134|
135|
136| 137| 138|

② 位移公式 x = v₀t + ½at²

139|
140|
141|
📐 公式法推导
142|
x = v₀t + ½at²
143|
144|由平均速度求位移： 145|
x = v̄·t
146|
匀变速平均速度 v̄ = (v₀+v)/2
147|
代入 v = v₀+at：
148|
v̄ = (v₀+v₀+at)/2 = v₀ + ½at
149|
x = (v₀+½at)·t = v₀t + ½at²
150|
151|
152|
153|
📊 图像法推导
154|
155|v−t 图下的面积 = 位移。
156|图形为直角梯形： 157|
• 上底 = v₀（t=0时速度）
158|
• 下底 = v（t时刻速度）
159|
• 高 = t
160|
梯形面积 = ½(v₀+v)·t
161|
= ½[v₀+(v₀+at)]·t
162|
= v₀t + ½at²
163|
164|
165|
166| 167| 168|

③ 速度位移公式 v² − v₀² = 2ax

169|
170|
171|
📐 公式法推导
172|
v² − v₀² = 2ax
173|
174|由①②消去时间 t： 175|
由 ①：t = (v−v₀)/a
176|
代入 ②：x = v₀·(v−v₀)/a + ½a·(v−v₀)²/a²
177|
= (v₀v−v₀²)/a + (v²−2vv₀+v₀²)/(2a)
178|
通分：= (2v₀v−2v₀²+v²−2vv₀+v₀²)/(2a)
179|
= (v²−v₀²)/(2a)
180|
→ v² − v₀² = 2ax
181|
182|
183|
184|
📊 图像法推导
185|
186|v−t 图面积 = x = ½(v₀+v)·t
187|又 t = (v−v₀)/a 188|
x = ½(v₀+v)·(v−v₀)/a
189|
= (v²−v₀²)/(2a)
190|
→ v² − v₀² = 2ax

④ 平均速度公式 x = (v₀+v)·t / 2

197|
198|
199|
📐 公式法推导
200|
x = (v₀+v)·t / 2
201|
202|直接由匀变速的定义： 203|
匀变速运动中，
204|
平均速度 v̄ = (v₀+v)/2
205|
x = v̄·t = (v₀+v)t/2
206|
★ 注意：只对匀变速成立！
207|
208|
209|
210|
📊 图像法推导
211|
212|v−t 图梯形面积： 213|
• 梯形面积 = ½(上底+下底)×高
214|
• 上底 = v₀，下底 = v，高 = t
215|
S = ½(v₀+v)·t = x

⑤ 逆向公式 x = vt − ½at²

222|
223|
224|
📐 公式法推导
225|
x = vt − ½at²
226|
227|将 v₀ 用 v 和 a 表示： 228|
由 ①：v₀ = v − at
229|
代入 ②：x = (v−at)·t + ½at²
230|
= vt − at² + ½at²
231|
= vt − ½at²
232|
233|
234|
235|
📊 图像法推导
236|
237|逆向思维——把时间倒流： 238|
末速度 v 看作"逆向初速度"
239|
加速度 a 方向不变但作用相反
240|
在 t 时间内倒退：x = vt − ½at²
241|
★ 对刹车问题求最后一段位移特别好用
242|
243|
244|
245| 246|
247|
💡 五个公式的关系速记
248|

249|①②独立 → ③由①②消去t得到
250|④直接由v-t图面积得到，是②的另一种形式
251|⑤把v₀换成v（逆向思维），与②对称
252|核心口诀：知三求二，无t用③，无v用⑤ 253|

📊 交互式 v−t 图像 · 面积 = 位移

260|

拖拽滑块改变加速度和末速度，观察面积（位移）变化。梯形面积 = ½(v₀+v)×t 为位移公式的几何直观。

二、两类减速运动必须辨析

267| 268|

类型Ⅰ：刹车问题（单向减速）

269|
270|
271|
🚗 特点
272|
273|
• 减速到 v=0 后停止不动，不会反向
274|
• 实际运动时间 ≤ 理论停止时间
275|
• 位移不能用完整公式代入过大t

如果题目给的 t > t₀：
283|
• ❌ 直接代入 t 算位移 → 错误！
284|
• ✅ 用 t₀ 代替 t 计算位移
285|
或直接用 v²=2ax 求总位移

类型Ⅱ：竖直上抛类（双向减速）

291|

🎯 特点
294|
295|
• 减速到 v=0 后反向加速
296|
• 全程加速度恒定不变

• 位移、速度全程用统一公式

303|

• 上升时间 = 下降时间
306|
• 同一高度速度大小相等，方向相反
307|
• 上升段是匀减速，下降段是匀加速
308|
★ 全程用 v=v₀−gt 时：
309|
v>0 表示向上，v<0 表示向下

🚨 两类减速运动对比——必考易错
316| 317| 318| 319| 320| 321| 322| 323|
对比维度刹车类竖直上抛类
停止后静止不动反向加速
加速度方向与速度反向恒定向下（重力g）
时间陷阱t > t₀时必须用t₀t 可以任意代入公式
典型例子汽车刹车、滑块在粗糙面竖直上抛、光滑斜面上滑
对称性无上升=下降时间

💡 判断方法
328|

331|竖直上抛→重力始终存在→停下后接着拉下来。
332|光滑斜面上滑→重力下滑分量始终存在→到顶后下滑。 333|

三、例题精讲 · 方程组解法

340| 341| 342|
343|
344|【例1 · 知二求三】 345|一辆汽车做匀加速直线运动，测得第2秒内的位移为6m，第4秒内的位移为10m。求：汽车的初速度v₀、加速度a和第3秒末的速度v₃。 346|知二求三 347|
348|
349|
🔍 分析
350|题中只给了两个位移条件（第2s内、第4s内），要解出三个未知量（v₀、a、v₃），必须列方程组。
351|这里的技巧是将"第N秒内位移"表示为"前N秒位移 − 前(N−1)秒位移"。 352| 353|
📝 解：设初速度 v₀，加速度 a
354| 355|第2秒内位移 = 6m：
356|前1s：x₁ = v₀·1 + ½a·1² = v₀ + 0.5a
357|前2s：x₂ = v₀·2 + ½a·2² = 2v₀ + 2a
358|第2s内：Δx₂ = x₂ − x₁ = (2v₀+2a) − (v₀+0.5a) = v₀ + 1.5a = 6 ……① 359| 360|第4秒内位移 = 10m：
361|前3s：x₃ = v₀·3 + ½a·3² = 3v₀ + 4.5a
362|前4s：x₄ = v₀·4 + ½a·4² = 4v₀ + 8a
363|第4s内：Δx₄ = x₄ − x₃ = (4v₀+8a) − (3v₀+4.5a) = v₀ + 3.5a = 10 ……② 364| 365|解方程组：
366|② − ①：2a = 4 → a = 2 m/s²
367|代入①：v₀ + 3 = 6 → v₀ = 3 m/s
368|v₃ = v₀ + 3a = 3 + 3×2 = 9 m/s 369| 370|
✅ 验证
371|第2s内：Δx₂ = v₀ + 1.5a = 3 + 3 = 6m ✓
372|第4s内：Δx₄ = v₀ + 3.5a = 3 + 7 = 10m ✓ 373| 374|
375|📌 知二求三的套路：当只知道两个条件要解三个物理量时，关键是找到两个独立的方程。
376|常用方法：①用位移差公式（逐差法）②用两段位移分别列式③用平均速度找中间时刻速度 377|
378|

384|【例2 · 方程组 + 刹车陷阱】 385|一物体做匀变速直线运动，通过A、B两点用时2s，AB=8m；通过B、C两点用时3s，BC=15m。已知物体做的是减速运动。
386|求：(1) 加速度 a   (2) 经过A点时的速度 v_A   (3) 物体停止前总共走了多远？ 387|刹车判断 388|
389|
390|
🔍 分析
391|已知两段位移和对应时间，要求加速度和初速度——列方程组。
392|⚠️ 需要先判断这是哪种减速运动：题中只说"减速"，需算停止时间看是否在停止前就通过了BC段。 393| 394|
📝 解：(1)(2) 列方程组
395|设v_A = v₀，加速度为a（注意减速，a应为负值） 396| 397|AB段：t₁ = 2s，x₁ = 8m
398|x₁ = v₀t₁ + ½at₁² → 2v₀ + 2a = 8 ……① 399| 400|AC段（全程）：t = 5s，x = 8+15 = 23m
401|x = v₀t + ½at² → 5v₀ + 12.5a = 23 ……② 402| 403|由①：v₀ = 4 − a，代入②：
404|5(4−a) + 12.5a = 20 − 5a + 12.5a = 20 + 7.5a = 23
405|→ 7.5a = 3 → a = 0.4 m/s² 406| 407|但是……a = +0.4是正值，而物体是减速运动！
408|说明我们设的加速方向错了——实际加速度为a = −0.4 m/s² 409| 410|代入①：2v₀ + 2(−0.4) = 8 → 2v₀ − 0.8 = 8 → v₀ = 4.4
411|v_A = 4.4 m/s     a = −0.4 m/s² 412| 413|
📝 (3) 刹车判断 + 总位移
414|停止时间：t₀ = |v₀/a| = 4.4/0.4 = 11s 415| 416|由于物体通过BC用了3s（总时间5s），而停止时间11s远大于5s，说明物体在BC段尚未停止，两个位移数据都有效。 417| 418|总位移（减速到零）：x_max = v₀²/(2|a|) = 4.4²/(2×0.4) = 19.36/0.8 = 24.2 m 419| 420|
421|⚠️ 此题两个陷阱：
422|① 列方程解的a为正，要结合"减速"条件判断正负号方向
423|② 要先算停止时间确认物体在BC段是否已停止，否则求出的v₀就是错的 424|
