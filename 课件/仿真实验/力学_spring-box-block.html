重点分析选项 C：木箱第一次到达最右端时，物块速度是否为零？

📝 原题

如图所示，弹簧一端固定，另一端与光滑水平面上的木箱相连，箱内放置一小物块，物块与木箱之间有摩擦。压缩弹簧并由静止释放，释放后物块在木箱上有滑动，滑动过程中不与木箱前后壁发生碰撞，不计空气阻力，则（　　）

C. 木箱第一次到达最右端时，物块速度为零

📌 高考标准答案

正确答案：D（物块和木箱的速度第一次相同前，物块受到的摩擦力不变）

选项 C 不一定正确。若二者在木箱第一次到达最右端之前已经共速并“粘连”一起振动，则 C 成立；否则木箱到达最右端时物块仍在滑动，速度不为零。本仿真可通过调节参数观察这两种情形。

🔍 对选项 C 的物理分析

核心结论：选项 C 是否成立取决于参数（摩擦是否足以让二者“粘连”）。高考标准答案不选 C，选 D。

关于“相对静止”：本仿真会用绿色高亮标注“相对静止（共速/粘连）”阶段——图像上出现绿色阴影带，动画中物块变绿并显示“相对静止”，状态栏也提示“相对静止”。这是判断选项 B（最终是否仍有相对运动）和选项 C 的关键。

两种典型运动情形：

  1. 摩擦足够大 → 一开始就相对静止，一起做简谐运动（C 成立）。若最大静摩擦力足以提供物块随整体一起振动所需的回复力（即 k|x|/(M+m) ≤ μg），二者从释放起就“粘连”成整体 (M+m)。整体到达最右端时二者速度同时为零，此时 C 成立、B 不成立。
  2. 摩擦不足 → 以打滑为主，但“块与槽速度相同”的瞬间仍会发生（C 不成立）。若摩擦不足以从一开始就粘连，二者主要相对滑动；但木箱经过平衡位置后会减速、而物块靠摩擦仍向前加速，于是物块会一次次“追上”木箱——速度相同的瞬间反复出现（速度曲线上用红色“⊙”标出每一次，第一次出现即对应选项 D 的“第一次速度相同”）。只是这几次“同速”往往只是擦肩而过、随即再次分离，并未真正“粘连”成整体；木箱第一次到达最右端时物块通常仍在滑动，速度不为零，故 C 不成立。只有当摩擦足够大，第一次“同速”后才能真正粘连、一起振动，C 才成立。

👉 想看“始终相对静止”就点 典型：C 成立（相对静止） 或 物块较重情形；想看“以打滑为主、速度相同只是擦肩而过”（C 不成立）就点 典型：C 不成立。也可直接拖动摩擦力 μ 滑块：μ 从小到大越过临界值时，会看到系统从“几乎全程打滑、同速瞬间一闪而过”突变为“一开始就相对静止、一起振动”。

木箱从静止到第一次最右端的过程中，对其速度积分得：
∫₀^{t₁} a_箱 dt = 0 ⇒ ∫₀^{t₁} (−kx + F_f) dt = 0
对物块用动量定理：m v'_₁ = ∫₀^{t₁} (−F_f) dt = −k ∫₀^{t₁} x dt
因此 v'_₁ = −(k/m) ∫₀^{t₁} x dt。该积分一般不为零，故物块速度一般不为零。

📐 运动方程

设 x 为木箱相对弹簧原长的位移（向右为正），x' 为物块位置，相对位置 Δx = x' − x，相对速度 u = ẋ' − ẋ，滑动摩擦力大小 f = μmg。

滑动时（u ≠ 0）：
Mẍ = −kx + f·sgn(u)     mẍ' = −f·sgn(u)

共速粘连时（u = 0 且所需静摩擦 f_req = m|kx|/(M+m) ≤ μmg）：
(M+m)ẍ = −kx，即 ẍ = −kx/(M+m)

为什么 D 一定正确？ 在物块与木箱第一次达到共同速度之前，二者始终沿同一方向相对滑动（物块相对木箱的滑动方向不变），因此物块受到的滑动摩擦力大小恒为 μmg、方向不变。故 D 正确。
