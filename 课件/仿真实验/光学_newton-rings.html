🌈 牛顿环 · 等厚干涉

光程差 Δ = 2d + λ/2   
暗纹: 2d = mλ  
明纹: 2d = (m+1/2)λ  

平凸透镜 与平面玻璃间形成空气薄层，曲率半径 R 变化时凸面动态贴合玻璃板。
白光模式 呈现彩色牛顿环；单色模式 可调波长观察疏密变化。
