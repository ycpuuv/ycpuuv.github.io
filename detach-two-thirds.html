📊 实时数值 θ₀=0° 静止释放

① cosθ = 2/3 推出来的一串数 sinθ* = √5/3 ≈ 0.7454
tanθ* = √5/2 ≈ 1.1180
θ* = 48.19°
下滑高度 = R/3（恒在顶点下方）
脱离点离球心高度 = 2R/3
脱离速度 v = √(2gR/3) ≈ 0.8165√(gR)
② 真正的母式（要背的是它） cosθ* = (2/3)cosθ₀ + v₀²/(3gR)
θ₀ = 0、v₀ = 0 → 才退化成 2/3
v₀ = √(gR) → cosθ* = 1 → 顶点即脱离
凹面（碗内壁）永不脱离：
N = mg·cosθ + mv²/R > 0 恒成立
③ 本质：系数比 2 : 1 两条曲线一联立就出 2/3：
1 − cosθ = (1/2)·cosθ
系数 2 来自动能前的 ½。
凡"能量守恒 + 某法向力归零 +
圆周(或定轴转动)约束"的题，答案都是这个形状。
⚠️ 六个高频错解
  • θ 量错方向 —— 必须是与竖直方向的夹角，不是与水平面。方向错则数值全错。
  • 从 θ₀ 释放还套 2/3 —— 应该用 cosθ* = (2/3)cosθ₀。背 2/3 的学生在这里全军覆没。
  • 给初速度的题仍用 2/3 —— 必须带 v₀²/(3gR) 那一项。
  • 把脱离点当最高点 —— 脱离点在顶点下方，脱离瞬间即进入斜抛。
  • 忘了 N = 0 的物理含义 —— 是"刚要脱离"的临界，此时向心力只由重力的法向分量提供。
  • 碗内壁（凹面）也套 2/3 —— 凹面 N 恒正，永远不会脱离，方向反了。
