小球穿金属管 · 两个视角

球自由落体，管竖直上抛。两者都只受重力，加速度完全相同 —— 所以换到球上看，管是匀速的。
① 地面参考系：球自由落体，管竖直上抛
② 小球参考系：球不动，管以 v₀ 匀速向上滑过

此刻

为什么换参考系就变匀速

管加速度 g（向下），球加速度也 g（向下）。
管相对球的加速度 = g − g = 0。
加速度为零 → 相对速度保持不变，永远等于 v₀。
所以球相对管要走的总距离就是管长 L，用时 L/v₀，与 H 无关。
t相遇 = (H−L)/v₀ = 7/12 = 0.583 s
t穿出 = H/v₀ = 10/12 = 0.833 s
穿过用时 = L/v₀ = 3/12 = 0.250 s

不用相对运动，怎么算（点一步走一步）

什么时候必须硬算

加速度不同时，½(…)t² 消不掉，就变成一元二次方程：
½(a₁−a₂)t² − v₀t + (H−L) = 0
例：a₁=−10（球）、a₂=−4（管受很大阻尼）→ 相遇 t ≈ 0.517 s
a₂=0（管匀速上升，比如挂在气球上）→ t ≈ 0.485 s
高一不考这种，但边界要说清：消得掉就是相对运动，消不掉才必须硬算。

第三种：v–t 图（不用公式）

两条 v–t 线斜率都是 −g → 完全平行 → 竖直间距恒等于 v₀。
位移 = 线下面积 → 位移差 = 两条线之间那块面积 = v₀·Δt。
而位移差 = H − (H−L) = L。
→ Δt = L/v₀。黑板上画两条平行线，学生一眼就懂。

选项对照

A ✓t=(H−L)/v₀ 对
B ✓穿过时间 L/v₀ 对 ← 你漏了这个
C ✓v₀>√(gH) 时在上升阶段穿过
D ✗增大 H 时间不变，不会变短
答案 ABC

第三种看法（等价）

也可以拿管做参考系：管静止不动，球以 v₀ 匀速向下穿过它 —— 同样一眼看出 L/v₀。
三个视角（地面／球／管）算出的时间必须一致，这就是相对运动的用处：挑最省事的那个。
