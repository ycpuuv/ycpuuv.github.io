选项逐项判定（答案：AC）
A 对垂直杆方向：F⊥ = k·PQ = 16 N 恒定，N = 16 − mg·cos53° = 16 − 6 = 10 N 恒定，故 f = μN = 1.6 N 始终不变（滑动过程中）。
B 错冲量是矢量：下滑时摩擦力沿杆向上，上滑时沿杆向下，方向相反，冲量不可能相同。
C 对下滑 1.28 m 到最低点，再上滑 0.64 m，恰停在 d = 0.64 m 处（此处 8 − 6.4 = 1.6 N = 最大静摩擦，临界平衡），位移大小 0.64 m。
D 错总路程 = 1.28 + 0.64 = 1.92 m，W克摩 = 1.6 × 1.92 = 3.072 J，不是 2.56 J。
关键推理链
① 绳总长 = OQ + QP，原长 = OQ ⇒ 伸长量 x = QP，F = k·QP，方向 P→Q；
② F 沿杆分量 = k·QP·(d/QP) = k·d ⇒ 等效于"锚在 H 点、原长为 0、劲度系数 k 的弹簧"；垂直杆分量恒为 k·PQ = 16 N；
③ 垂直杆方向平衡：N = 16 − mg·cos53° = 10 N（恒）⇒ f = μN = 1.6 N（恒，A 对）；
④ 下滑 a = 6.4 − 10d，v=0 时 6.4D = 5D² ⇒ 最低点 D = 1.28 m；
⑤ 上滑 a = 10d − 9.6，由能量守恒（计摩擦）得上滑 0.64 m，停在 d = 0.64 m，恰为最大静摩擦的临界位置，此后不再运动（C 对）；
⑥ 全程路程 1.92 m，3.072 J 机械能转化为内能（D 错）。
